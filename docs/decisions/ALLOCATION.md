# Number allocation

The four allocation registries, kept in one document because each is read AS A
TABLE: `CI-06f`, `CI-06h` and `CI-06p` call one shared parser over the first cell of
every row. A table split into a file per row is not a table, which is the same reason
`DELTA_MANIFEST` stays single under [ADR-043](ADR-043.md).

**Every table here carries two columns and no third.** The number, and who took it.
The State column that used to sit beside them is deleted, on [ADR-034](ADR-034.md)'s
own remedy, and the ruling is [below](#the-state-column-is-deleted-on-adr-034s-own-remedy).

## Number allocation, and why this table exists

**An ADR number is claimed here before it is written.** Two branches forking from the same `main` both read the registry, both find the same maximum, and both take the next integer. Neither is wrong locally; the corpus is broken the moment the second merges. **[ADR-034](ADR-034.md) rules the allocation, and [CI-06f](../testing/STRATEGY.md) enforces it.**
