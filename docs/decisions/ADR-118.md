## ADR-118: a section headed by a date or a session number is a RECORD, and ADR-034's count rule does not reach it  (2026-08-26, status: proposed)

**[ADR-034](ADR-034.md) ruled that no document states a quantity a script can derive, and deferred the sweep that would find them: _"The sweep is the gate's first run and is not done here"_. `CI-06g` has carried that debt in its own `covers` line ever since, in these words: _"the corpus-wide sweep for bare numerals adjacent to a registry noun needs the generator and is NOT run here."_ The generator exists. The sweep is written now, and writing it forced a question ADR-034 never had to answer: WHICH documents the rule reaches.**

- **Origin:** session **230**, the two gates named as owed. The number was RESERVED before dispatch and **conditionally**: the expected outcome was two gates and no entry. It is written because the sweep cannot be built without deciding what a document is allowed to say, and that decision is a ruling rather than an implementation detail. It belongs where a future session can argue with it, not inside a `covers` string.

- **Context:** the receipt is recorded in [STATE](../STATE.md) at the session 204 integration. `schema.ts`'s header sentence states how many registered tables carry a later column. **Tranche A raised it to NINE for `payout_requests`. Tranche B raised it to NINE for `promotional_credit_grants`.** Two branches reached the SAME NUMBER FOR DIFFERENT REASONS, so git saw no conflict to resolve: each copy read NINE, named nine tables, was internally consistent, and was wrong by one. The answer was **TEN**, and it was derived by replaying every `ALTER TABLE`. [ADR-042](ADR-042.md) had already ruled that prose is not a control; this is what that costs when nobody enforces it.

### 1. What the corpus actually contains, measured before anything was ruled

Measured over every markdown file under `docs/` with the reader that shipped, so the comparison is between RULES and not between parsers. A cardinal must GOVERN the noun: one run of whitespace, no window.

| Candidate rule | Sites in live prose | Sites excluded by shape | What the live sites are |
|---|---|---|---|
| **Any value.** A cardinal governing a registry noun, whatever it counts | **206** | 1,354 under a dated or session heading, 117 in table rows | Almost every one a LOCAL SUBSET: `1 gate`, `2 gate`, `Six deltas`, `three tables`. A gate reporting 206 findings on a clean tree is switched off in a week |
| **A totality word before the cardinal** (`all 47 migrations`) at a value the tree does not derive | **5** | 101 under a dated or session heading, 3 in table rows | **All five are false.** _"All three tables are the approved design"_ is a local set with a totality word in front of it, and so are the other four |
| **Value-anchored.** The cardinal must equal what its bound query returns on this tree | **0** | 137 under a dated or session heading, 11 in table rows | Nothing. Which is the state a clean tree should be in |

**The 206 is the number that decides this.** ADR-034's sentence, read literally over this corpus, is a rule nobody can keep, because this corpus argues in numbers and most of its numbers count something local.

### 2. The ruling

1. **ADR-034's count rule is enforced by `CI-06/derivable-counts`**, over markdown under `docs/`, and the check is value-anchored: a cardinal is a finding when it equals what its bound query returns on this tree and the noun it governs names that query's population.

2. **A SECTION UNDER A HEADING NAMING A DATE OR A SESSION NUMBER IS A RECORD, AND ADR-034 DOES NOT REACH IT.** A record states what was measured on a day. _"All 47 migrations applied in order"_ was TRUE when it was written, and a generated span over it would rewrite the record to say something it did not say, which is a worse defect than the one being repaired. [ADR-064](ADR-064.md) is why a session number stands beside a date: a session number IS a day-and-slot allocation. **137 of the 148 sites the reader sees are here.**

3. **A count in a TABLE ROW is a per-row datum and is out of scope.** ADR-034's subject is a prose sentence. A registry table's numbers belong to their rows, and the remedy for a registry table is a TABLE-VALUED span, which [ADR-088](ADR-088.md) built two of and which is a different repair from wrapping a numeral. 11 sites.

4. **The false negative is accepted in writing rather than discovered later. A COUNT THAT HAS ALREADY DRIFTED IS INVISIBLE TO THIS GATE.** On the merged tree the receipt read NINE against a truth of TEN and this gate would have been silent on it. That is where the argument lives rather than a hole in it: **on either branch alone the sentence read NINE against a derivation of NINE**, and the gate names it there, while it is still RIGHT, which is the only moment a span can be installed without anybody having to adjudicate what the truth is. A gate that fired on the drifted number would be asking a reader to decide between two branches; this one asks only that a derivable number stop being typed.

### 3. What this does NOT decide

- **Source files are out of reach and it is a scope decision, not an oversight.** `generate()` rewrites `markdownFiles()` and nothing else, so a finding in a `.ts` header would be a finding with no remedy, and a finding with no remedy is how a gate gets switched off. **Measured rather than waved at: the same reader over every `.ts`, `.tsx`, `.mjs` and `.sql` in the tree finds 17 sites, eleven under `packages/` -- four of them in [`schema.ts`](../../packages/db/src/schema.ts) and three in [`scope.ts`](../../packages/db/src/scope.ts) -- and six in the runner and its own harness.** Closing them needs the generator taught to write a comment span. **That is owed.**
- **The receipt's own number is not in the vocabulary and cannot be.** How many registered tables carry a later `ADD COLUMN` is derived by [`scoped-db.test.ts`](../../packages/db/test/scoped-db.test.ts)'s replay and by nothing in `gates.mjs`. The gate reaches the CLASS the receipt belongs to; closing that INSTANCE needs a `SPAN_QUERIES` entry reading the migrations. **That is owed too, and it is the more valuable of the two.**
- **Nothing here amends ADR-034.** Clauses 2 and 3 narrow where the rule is ENFORCED, not what it says. A record that states a derivable count is still a record of a measurement, and the reason it is left alone is that rewriting it would make it false.

### 4. The other gate this session wrote, which needs no ruling and is recorded here so the pair reads together

`CI-06/table-row-width` asserts that every markdown table row under `docs/` carries the cell count its delimiter row declares. **That is GitHub-flavoured markdown's own rule and not a Merit convention**, so it rules nothing and gets no clause. It is named here because [PR #299](https://github.com/lam2-coder/meritfutures/pull/299) is the receipt for both entries in the same week: prose silently becoming data, and prose silently claiming to be a control.

**The 17 ragged rows it registers are real and none is accepted as correct.** Six are rows of this file's own ADR allocation table carrying a fourth cell in a three-column table, which every markdown renderer DISCARDS: a whole disposition paragraph, in the registry a sibling branch reads to decide whether a number is free, invisible to anyone reading the rendered file. **This session holds one row of this file and took only that row.**

### 5. Alternatives considered

- **Enforce ADR-034 literally, over every document.** Rejected on the measurement in section 1: 206 findings on a clean tree, almost all of them local subsets. The rule would be relaxed within a month, and a relaxed gate is worse than no gate because it reads as coverage.
- **Recognise the count by its shape rather than its value** -- a totality word, or the corpus's shouted-number-word convention (`NINE`, `NINETY-FIVE`), which is the shape the receipt is written in. Rejected: the totality form gives five findings in live prose and **all five are false**, and the shouted form finds nothing in live prose at all, so it would have been a gate that asserts nothing while looking targeted.
- **Exclude the record sections by FILENAME** (`docs/sessions/`, `docs/STATE.md`). Rejected on `RI-10`'s lesson, which is the same lesson `CI-06u` states about `DIMENSION_HEADERS`: a check that needs a name-based exception is usually scoped wrong. The heading shape is the property; the filenames are a consequence of it, and an ADR is a dated record by exactly the same rule that makes a session log one.
- **Ban derivable counts outright with no exclusion and register the survivors.** Rejected: a register of 206 entries is furniture, and `CI-06u`'s register of 20 is already at the edge of what a session will maintain.

### 6. Consequences

- `scripts/corpus/gates.mjs` gains `CI-06/derivable-counts` and `CI-06/table-row-width`. **`gate_count` moves from 30 to 32** across every generated span, rewritten by `gates.mjs generate`.
- `scripts/corpus/falsify.mjs` gains two seeded violations and eleven scope cases. **`CI-06/table-row-width`'s seed REPLAYS #299's edit on the live document** rather than pasting its output, so a rewording announces itself as a stale seed instead of quietly reproducing nothing.
- **No `CI-06` letter is claimed and the letter table is untouched.** Both gates are slugs under [ADR-065](ADR-065.md)'s successor rule.
- **No STRATEGY row is written.** `CI-06p` reads letters and explicitly does not require an implemented gate to have one; nothing in the runner demands a row for a slug. The only STRATEGY change is a `gate_count` span rewritten by `generate`.

### 7. The approval line

**Founder ruling: PENDING.** Unsigned. One clause, and it is executable against this branch's files alone.

**Clause.** **The corruption [PR #299](https://github.com/lam2-coder/meritfutures/pull/299) landed, replayed on a scratch copy of the live document, is caught by `CI-06/table-row-width` and by no other gate in the runner.** Not "a gate like it would catch a fragment like it": that exact edit, on that exact table, with the other 31 gates run against the same seeded tree and reporting PASS.

**Cost if wrong.** If clause 2 is wrong -- if a dated section IS a place ADR-034 reaches -- then 131 sites go on stating counts that drift, in the documents a reader consults for what was true. That is the failure this entry accepts deliberately, and the argument against repairing them is that the repair makes them LIE rather than merely go stale. If clause 2 is right and the exclusion is later widened by shape rather than by argument, the gate quietly stops reaching live prose and reports zero for the reason that means it read nothing; the run note prints the excluded populations on every run so that is visible rather than inferred.
