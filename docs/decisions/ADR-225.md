## ADR-225: `zod at every boundary` names a mechanism this workspace has never had, so the six citations are separated from the control they claim, and the one thing zod uniquely supplies turns out not to be validation at all  (2026-08-29, status: proposed)

**[`MERIT_BUILD_MASTER_PROMPT.md:282`](../../MERIT_BUILD_MASTER_PROMPT.md) rules `zod at every boundary` among the binding `D2` application controls, and `zod` is a dependency of no `package.json` in this workspace.** [ADR-219](ADR-219.md) found the `D2-9` gap by accident; [the D2 controls audit](../reviews/2026-08-29-d2-controls-audit.md) then measured all eleven controls as a set and rowed this one `NO, NOT AS ZOD`. **This entry is what that measurement was owed, and it is not a repair of five comments.**

**THE FINDING THAT REORGANISES THE QUESTION.** Boundary validation in this tree is done. Seventeen total validators in `apps/api/src/routes` return a `Validated<T>` result, each CONSTRUCTS its value out of keys it names so an unnamed key reaches nothing, and each of the six sites that cites `zod` already names what discharges its own claim. **What zod would add at a boundary is a second way to do a thing that is done.** The one corpus claim with no hand-written substitute anywhere is not a validation claim at all: [`API_CONTRACT:37`](../architecture/API_CONTRACT.md) says the OpenAPI document is *"Generated from the same zod schemas"*, [ADR-083](ADR-083.md) ruling 3 names the zod type provider as the generator, [ADR-144:125](ADR-144.md) deferred its own response projections on exactly that sentence, **and `grep -rin "openapi\|swagger" apps packages --include=*.ts` matches three files, none of which generates anything.** So the founder's question is not "zod or hand-written validators". It is **"does Merit want a generated OpenAPI document, because that is the only thing in the corpus that zod uniquely supplies"**, and it is a `VG-12` question this session may not answer.

### 5. THE RULING

**Ruling 1. A shipped comment may QUOTE a corpus document that names a control this tree does not have. It may not ASSERT that the control exists.** The quotation must name, in the same comment, what discharges the claim here. This rules on comments and not on validation, so it amends nothing frozen, and it is the line that sorts the six in section 2: five quote and name their discharge, one asserted and is repaired.

**Ruling 2. A quotation of a zod-naming corpus line carries one dated clause anchored to this entry**, stating that no package in this workspace depends on `zod`. Five sites gained one. This is the minimum that stops a reader inferring the mechanism from the quotation, and it costs no edit to any frozen source.

**Ruling 3. [`types.ts`](../../apps/portal/src/api/types.ts)'s refusal stands and its reason is replaced.** The portal keeps `PlanRules` opaque. The reason is no longer a validator that does not exist; it is `validatePlan`, which exists, runs one transition later than the comment implied, and refuses nothing for being unknown. **The old sentence is marked as history in place rather than deleted**, so a later session cannot restore it without reading why it went.

**Ruling 4. The record of an unsupported migration comment is this entry, and a migration comment is superseded only by a later migration.** No migration is written here, and whether one is owed depends entirely on ruling 5: **if `zod` is admitted, nothing is owed at all**; if `D2-4` is amended, `0017:49` is owed a one-word correction and `0004:63` is owed a two-part one, and both belong in the next migration that has business touching those tables rather than in a migration written to carry a sentence.

**Ruling 5. THE `VG-12` ADMISSION IS NOT THIS SESSION'S TO TAKE, AND THAT IS A GATE RATHER THAN A PREFERENCE.** [`P1-SE-trading-calendar:38`](../plans/P1-SE-trading-calendar.md) states it in the corpus's own words: *"VG-12 makes a new dependency a human admission a session cannot grant itself"*. Both precedents record a grant the founder **DELEGATED** for a named slice ([ADR-116](ADR-116.md) for Playwright, [ADR-127](ADR-127.md) for Stryker). **Row `225` delegates nothing.** So the admission is refused here on the gate and not on the merits, and section 6 is a recommendation rather than a decision.
