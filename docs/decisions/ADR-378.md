### 4. ADR-370 section 9's hole, and what its real shape implies

**ADR-376 SECTION 8 IS RIGHT AND THIS ROW REACHES ITS RESULT FROM THE GRAMMARS RATHER THAN FROM SEEDS.** Read at [`test/schedule.test.ts`](../../apps/worker/test/schedule.test.ts), the two censuses are:

| function | grammar | polarity on the name |
|---|---|---|
| `unwiredPorts` | `export const (UNWIRED_[A-Z0-9_]+): <Port> =` | **INCLUDES** on the `UNWIRED_` prefix |
| `constructorsOf` | `export const (?!UNWIRED_)\w+: <Port> =` | **EXCLUDES** on the same prefix |

**SO THE HOLE IS NOT A BLIND SPOT. IT IS AN ASYMMETRY, AND THAT IS WHY [ADR-370](ADR-370.md) SECTION 9 GETS ITS OWN WEAKNESS WRONG IN BOTH HALVES.** That entry reasoned about *the census* as one thing and concluded that a refusing default named anything else is **invisible to both** and that the direction of error is **the safe one**. One name read by two functions with opposite polarity cannot have one direction of error. Dropping the prefix removes the port from the default census (**safe**: it reads as having no default) **and adds it to the constructor census in the same edit** (**unsafe**: its port reads as SERVED, a port a job could be handed a live value for).

**THIS IS ASSERTED RATHER THAN DESCRIBED, WHICH IS THE POINT.** Case `8.3` picks a real default off the tree, applies the rename to a STRING, and runs both grammars over the result. The grammars are extracted so the case runs the censuses' own regular expressions and cannot drift away from them. **No grammar was widened, no census was changed, and no checker was opened for writing.**

**AND THE HOLE THAT STAYS SILENT IS NARROWER STILL, RE-DERIVED HERE INDEPENDENTLY.** Seed 8 declares a refusing value under another name for a port that **already has a constructor** and the suite stays entirely **GREEN**, which is ADR-376's seed `10c` reproduced on a different port. **The renamed default is caught when its port has a default and no constructor, and when a case names the port by hand; `ExpiryEventPort` is the only port named by hand.**

**WHAT THE REAL SHAPE IMPLIES, STATED SO A LATER ROW DOES NOT RE-DERIVE IT.** The unsafe census is pinned only over the domain the safe census produces: `6.1` partitions `[...new Set(ports.values())]`, which is exactly the set of ports holding an `UNWIRED_` default. **The renamed-default edit removes a port from that domain and adds it to the unsafe reading at the same time**, so the two censuses are not independent witnesses and a repair that widened either grammar would still be a naming convention replacing a naming convention. **Recorded, not fixed**, on [ADR-369](ADR-369.md)'s precedent for `RI-15`'s second hole and [ADR-371](ADR-371.md)'s for `RI-35`.
