### 4. The argument that a budget is not a gate, written out because "raise the timeout" is what weakening one would also sound like

**A GATE IS A CLAIM ABOUT THE TREE THAT CAN BE FALSE. A TIMEOUT IS NOT ONE.**

What this case asserts is three sentences: `event-sink-caller` is absent over this repository, `worker-queue-door-caller` is present over it, and `RI-35` reports nothing. **Those three, their inputs, their scope, and the verdicts they compute are byte-identical either side of this diff.** The diff adds one argument to seven `test()` calls and reindents their bodies. **`git diff -w` over the code file contains not one `expect` line and not one changed `REPO_ROOT` call site**, which is the mechanical form of that claim rather than a promise about it.

**THE THING THE 5000ms BUDGET WAS CATCHING WAS THE SIZE OF THIS REPOSITORY, WHICH IS NOT A DEFECT.** The failure [ADR-465](ADR-465.md) recorded is a run in which every assertion in the case would have passed and the runner stopped waiting. Nothing about the tree was wrong in that run. **A control that reddens when the thing it watches is correct is not a control that has been weakened by being made to stop doing that.**

**THE JOB A TIMEOUT DOES DO IS BOUNDED AND IT IS STILL DONE.** It stops a hang from wedging CI forever. **30 seconds stops a hang exactly as well as 5 does**, at the cost of 25 additional seconds on a suite whose wall time is 84s, and only in the run where something is genuinely hung.

**THE HONEST COST IS NAMED RATHER THAN HIDDEN.** A raised budget stops this case from being an early warning that the scan is getting slow. **It was never deliberately serving as one**: 5000ms is a framework default, nobody in this tree chose it, and a signal nobody designed and nobody documented is not a signal anybody was reading. If the estate wants a performance regression gate over the scan, that is a check with a derived expectation and a stated tolerance, and section 10 item 3 prices it. It is not a `testTimeout`.

**THE FOUR THINGS THIS ROW REFUSED, EACH OF WHICH WOULD HAVE BEEN WEAKENING A GATE.** None was taken and each is named so a reader can check the diff for it:

1. **Skipping, disabling, quarantining or deleting the case.** The skip count is **11** before and after, and `packages/tooling/checks/skipped-tests.mjs` is untouched.
2. **Narrowing what the case scans**, for instance passing a subdirectory instead of `REPO_ROOT`. All sixteen `REPO_ROOT` call sites are unchanged.
3. **Moving the assertion to a fixture tree.** The case scans the real repository, which is the whole of what [ADR-328](ADR-328.md) and [ADR-330](ADR-330.md) built it for.
4. **Setting a GLOBAL `testTimeout`**, which would have been the smallest diff and the worst one: it moves every one of the 8,724 cases in this repository and it is out of fence besides.

### 5. The budget, its derivation, and the growth assumption it encodes

**`CORPUS_SCAN_MS = 30_000`.** Every factor below is measured on this container at this base and each is stated so a later reader can re-run it.

| Factor | Value | How it was measured |
| --- | --- | --- |
| Base | **2858ms** | the case in the full suite, no artificial load, run 2 of 2 at the base |
| Contention | **x1.61** | the same case at **4590ms** in a full-suite run with four background CPU spinners on four cores |

| Product | **29,450ms** | 2858 x 1.61 x 2.0 x 3.2 |
| **Chosen** | **30,000ms** | the product rounded up to a number a reader can hold |

**THE SCALING MEASUREMENT, IN FULL, BECAUSE IT IS THE ONLY FACTOR NOT DIRECTLY OBSERVED IN A REAL RUN.** A copy of this tree was taken outside the repository and `packages/zzclone<n>/src` directories were added from `apps/`, then the **shipped** `ri35.run` was called against that root three times per size:

| --- | --- | --- | --- | --- |

| +2 clones | 1320 | 30,669,250 | 6045ms | 206.7 |
| +4 clones | 2236 | 52,023,508 | 8180ms | 164.9 |

**THE COST IS AT WORST LINEAR IN SWEPT BYTES AND THE MEASURED PER-MEGABYTE FIGURE FALLS AS THE SCOPE GROWS**, which makes 289.5ms per swept megabyte a ceiling rather than a rate. **This measurement is contaminated in one direction and it is named rather than glossed**: the clones are identical copies, so the operating system page cache is warm for them and the finding count rises from 0 to 112, which changes the work. **THE ASSUMPTION, STATED SO IT CAN BE FALSIFIED RATHER THAN ARGUED WITH.** This budget holds until **the swept scope reaches about five times its 9,314,992 bytes, on a container twice as slow as this one and fully contended.** It does not encode an assumption about the corpus, and section 1's table is why: `docs/` is 1,495 markdown files and not one of them is in the sweep.
