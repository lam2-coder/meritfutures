## ADR-244: tier 1 is classified entire, its class C residue is ONE entry of twenty-one, and the classifier that sized it is not measuring the same object rather than measuring it wrongly  (2026-08-29, status: proposed)

**[ADR-243](ADR-243.md) moved four money-path approvals through [ADR-227](ADR-227.md)'s class B and then refused to propose a replacement residue number, on the ground that a correction running toward a smaller queue is exactly the direction a session clearing a backlog would want and that four of fifty-two is not a sample. THAT REFUSAL WAS RIGHT AND THIS ENTRY DOES NOT OVERTURN IT BY DECLARING A SMALLER NUMBER.** It removes the sampling objection instead, by reading **the whole of tier 1** rather than part of it: twenty-one entries, six carried from that entry and **fifteen read in full here**, every one classified on the shape of its central claim, with **eleven new class B approvals each earned by an assertion watched RED on the real tree and GREEN after a byte-identical restore.**

- **Origin:** [ALLOCATION](ALLOCATION.md) row `244`, session **434**, dispatched as `claude/class-b-at-scale`. The number is spent.

- **THIS ENTRY SIGNS NOTHING AND MARKS NOTHING `accepted`.** It ships `proposed` with an **UNSIGNED** approval line. **The eleven entries it moves are not marked `accepted` either** and no `status` field anywhere in this branch changes: what each gains is a recorded class B approval naming an assertion, its transcript and its limits. **The approval is the artifact and not the status field.**

- **NOT THE MONEY PATH BY FILE.** No file under any `src/` is changed and no migration is taken. **Eleven shipped source files and merged migrations were seeded with a defect and restored, each verified byte-identical by `sha256sum` and by an empty `git status --short`**, which is section 3's method and is recorded there per seed. What this branch ADDS is one invariant, its cases, and documents.

- **WHAT IS MEASURED, WHAT IS DERIVED, AND WHAT IS JUDGED.** Every count in section 2 is **MEASURED** live on `origin/main` at `52b5202`, with the commands published in [the census](../reviews/2026-08-29-class-b-tier-1-census.md). Every transcript in section 3 is **MEASURED**: a seed, a run, a restore, a run. Section 4's six entries are **MEASURED** by reading their landing diffs. Section 6's non-reproduction is **MEASURED**, twice. What is **JUDGED** is the class assigned to each of the fifteen entries read (section 3), section 7.1's argument that class C is not mechanically decidable, and section 7.3's reading of why the classifier and the rule are both right about different objects.

- **A DISPATCH PROMPT IS NOT A SOURCE.** The row's `RI-22` instruction was stale for the second consecutive wave and section 5 says so at the register rather than repeating it.

### 7. THE RESIDUE, ANSWERED

#### 7.1 No mechanical classifier can ask the rule's question, and the argument is asymmetry rather than difficulty

**CLASS B IS DEMONSTRABLE AND CLASS C IS ITS COMPLEMENT.** [ADR-227](ADR-227.md) section 6 says what a witness for class B looks like and how to exhibit one; a session that produces the transcript has settled the question, and section 3 did it eleven times. **Class C's claim is that NO assertion falsifies the central claim**, which quantifies over every assertion anybody could write. **No search establishes it and no pattern approximates it**, because the thing quantified over is not in the corpus.

**SO EVERY HONEST FIGURE FOR THE RESIDUE IS AN UPPER BOUND**, of the form `(money-path entries) minus (entries demonstrated class B) minus (entries demonstrated to land nothing)`, and **every subtrahend is a session's work.** The residue **cannot be measured more cheaply than it can be cleared**, and the procedure that answers *"is this entry class C"* just is the class B procedure returning nothing. **There is no cheaper oracle and this entry did not find one because there is not one to find.**
