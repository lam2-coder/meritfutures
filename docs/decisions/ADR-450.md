**THE DEFECT IS NOT A MISSING CHECKER. IT IS A CITATION GRAMMAR IN WHICH 89.5% OF POINTERS BIND NO NAME.** Where a name binds, `RI-15` and `RI-16` already do this work; where none binds, no check can, however written.

**WHAT IT DOES NOT FIX.** It makes drift DETECTABLE in live scopes.
