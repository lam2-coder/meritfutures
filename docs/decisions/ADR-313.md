## ADR-313: the map outlived its facts. Five sentences in the BLOCKED map and its neighbours were falsified by rulings that landed after them, and the control that counts what one purchase blocks was green with the wrong predicate  (2026-09-04, status: proposed)

**[`wiring.test.ts`](../../apps/api/test/wiring.test.ts)'s `BLOCKED` map is the artefact every dispatcher reads to learn what is still owed.** [ADR-312](ADR-312.md) sorted the thirteen doors that are not `usePayoutBackend`, found the map telling readers the opposite of the tree in two places, found [ADR-305](ADR-305.md)'s `0078` sentences and row `311`'s state cell in the same condition, and **was fenced out of repairing any of them**. Row `313` is that repair.

**EVERY REPAIR IS A QUOTATION RATHER THAN A REWRITE**, on `RI-14`'s rule that "a false sentence deleted leaves nothing for the next reader to check". The falsified sentence stays, marked as history, with what is true beside it and the ruling that made it false named with its date.

**AND THE SECOND HALF IS A PREDICATE RATHER THAN A NUMBER.** [`admin-read-constructibility.test.ts`](../../apps/api/test/admin-read-constructibility.test.ts) asserted that **six** `BLOCKED` entries sit behind the hardware-key SSO purchase, was GREEN, and its stated conclusion was wrong: it derived `use`-prefixed entries naming `principal(request)` and added two names by hand. **The set is now derived over EVERY entry by the property that defines it -- the entry reduces to `AdminSessionSource` -- and it is EIGHT, named.** The figure moves on its own the next time an entry names the port.

**NOTHING IS WIRED AND NO COUNT MOVES: TEN WIRED OF TWENTY-FOUR DECLARED, FOURTEEN BLOCKED** ([`wiring.test.ts:1524`](../../apps/api/test/wiring.test.ts)). No route behaviour changed, no port was installed, no migration was written and no number was reserved.

- **Origin:** [ALLOCATION](ALLOCATION.md) row `313`, session **504**, branch `claude/the-map-outlived-its-facts`, on [ADR-312](ADR-312.md) section 9 items 1 and 2.

- **NOT THE MONEY PATH BY DIFF, AND IT TOUCHES THE MONEY PATH'S MAP.** Three of the five repaired sentences sit on money-path entries (the affiliate commission rail, the admin liability figure, the withdrawal door). No cents are arithmetic'd anywhere in this diff and the one `src/` file it opens is a refusing port's prose and its error message. **What a wrong sentence here costs is a session dispatched at the wrong obstruction**, which is what row `312` measured and what this row exists to stop.

- **`E2` READ OWED, AND THREE ARE INHERITED** as premises: [ADR-304](ADR-304.md), [ADR-283](ADR-283.md) and [ADR-305](ADR-305.md), each `proposed` and UNSIGNED. This entry ships `proposed` with an **UNSIGNED** approval line. **Merging is not signing.**

### 2. Repair 1. The seventh class that was refused

### 10. Approval

**Status `proposed`. The approval line below is UNSIGNED and merging is not signing.**

**What a founder read adds and this entry cannot.**

**THE FIRST IS `0079`, BECAUSE IT IS THE ONE THING HERE THAT A SIBLING BRANCH CAN COLLIDE WITH.** This entry amends [ADR-305](ADR-305.md) in place to say that slice 4 spends `0079` rather than `0078`, and it does NOT add a row to [ALLOCATION](ALLOCATION.md)'s migration table, because a planning row that reserved a number for a slice it is not writing would hold that number against a session that may re-shape the slice -- which is [ADR-305](ADR-305.md)'s own stated reason and this row does not overturn it. **The consequence is that `0079` is named as free in an ADR and claimed nowhere**, and that table's own header says a claim is made in the table before the file is written. A founder who would rather the number were claimed now can say so and it is one row.

**THE SECOND IS WHETHER `useAffiliateDeps` SHOULD READ AS BLOCKED AT ALL.** The repair says the port waits on a founder act, because [ADR-304](ADR-304.md) section 10 asks for a read before `0078` is dispatched. **That is this entry's reading of a sentence written as advice**, and it is load-bearing: read the other way, `useAffiliateDeps` is ordinary Merit work that could be dispatched tomorrow and this entry has just told a dispatcher not to. **If the ruling is settled in your mind, say so and the sentence is one word different.** It is stated here rather than inside the entry, where it would read as measured.

**THE THIRD IS WHAT THE COUNT NOW COSTS TO CHANGE.** The eight are asserted by NAME, so a ninth entry naming the port turns the case red with its own name in the diff, and a session that meant it must edit the list deliberately. **The alternative was to assert nothing but the predicate and let the figure float**, which is what the dispatch asked for in its own words.
