### 2. THE RULING

#### Clause 1. The 227 blockers were unsupported, and by `ADR-072`'s own rule that makes all 227 rows nobody had looked at

[ADR-072](ADR-072.md), in bold, in its own words:

> **A BLOCKER WITH NO CITATION IS THE FINDING.** Every blocked row carries a citation that supports its blocker, naming the file and the fact. A row whose reason cannot be cited is not a blocked row; it is a row nobody has looked at, and the two have been indistinguishable for 276 rows.

**A citation that is false does not support anything, and one written 227 times cannot have been checked 227 times.** The entry that ruled prose does not scale to 276 absences produced, for the largest single group of them, a single sentence with a module name substituted into it. **That is prose with a column's punctuation, which is the alternative `ADR-072` considered and rejected**, arriving inside the artifact that rejected it. It is the same shape as the defect `ADR-072` found in [`fixtures/README`](../../packages/rules-engine/fixtures/README.md)'s held-back table, at 76 times the scale.

#### Clause 2. `no-fixture-format` names a condition that binds none of these rows, and the argument that put it there is refuted by seven counterexamples

[ADR-072](ADR-072.md) refused `no-module-code` on one prediction, quoted whole:

> **`no-module-code` was offered by the plan and is deliberately NOT in the vocabulary.** For the 229 rows it would have covered, the module's code being absent is true and is not the binding half: the fixture format is `packages/rules-engine/fixtures/GS-NNN-*.yaml`, a day stream folded through the engine, M1-shaped in every field, so **a module whose code landed tomorrow would still have nowhere to write**.

**Tomorrow came. Finding 7 is what happened.** Four modules' code landed on `main` between 2026-08-20 and today, and every one of them arrived with a suite that runs in an ordinary `pnpm exec vitest run`. Seven rows are discharged by those suites. **The number of new fixture formats written to discharge them is zero**, and the number of the seven that could have been written as an M1 day stream is also zero. The prediction was that the format half would survive the code half; it did not survive it once.

**So the condition `no-fixture-format` names, W2, is not the condition that would still hold if every other were cleared**, which is [ADR-072](ADR-072.md)'s own selection rule for which blocker a row carries. On a row whose module has no code, clearing the code clears the row's home with it. **The blocker that survives is the absent code, and the term for it is the one that was refused.**

#### Clause 3. The term is NOT retired here, and the reason is a FENCE rather than a judgment

Finding 8. `FIXTURE_BLOCKERS` is in [`gates.mjs`](../../scripts/corpus/gates.mjs), which is outside this session's fence and inside session **245**'s, and assertion 5 fails in both directions, so removing a term from the document without removing it from the runner turns `CI-06/fixture-inventory` red and removing it from the runner is an edit to a file this session may not make.

**What a successor needs is the argument, and clause 2 is the argument.** The edit it implies is three lines: drop `'no-fixture-format'` from `FIXTURE_BLOCKERS`, add `'no-module-code'`, and move the summary row. **This entry does not make it and does not pretend the reason is doubt.**

#### Clause 4. For as long as the term stands, it is a claim about the ROW and never about the corpus's format inventory

A citation on a `no-fixture-format` row states **the row's own subject** and **a measurement a second reader can repeat**. It may not state a fact about the tree's fixture formats, because clause 1 is what that produced. **The 220 rows that keep the term are recited on that rule in this session's diff**: each names the scenario it is waiting for, in the registry's own words, and the measurement that shows nothing in this tree asserts it.

This is not a smaller version of the same sentence. `GS-186`'s citation now says what `GS-186` is about and `GS-190`'s says what `GS-190` is about, so **a reader who disagrees with one row can disagree with that row**, which is the property `ADR-072` wanted the column for and which 227 identical strings could not deliver.

#### Clause 5. A row leaves the term when its assertion is EXECUTED and watched, and by no cheaper test

[ADR-076 section 1](ADR-076.md)'s rule, and section 39's own three warnings about what looks like coverage and is not. **Seven rows are moved here and every one was moved by running its citation**, not by reading it: the file, the case titles, the pass and the skip count are in section 3 and in the pull request. **Fourteen rows that a test file NAMES are not moved**, each because the suite that names it says in its own header what it does not assert.
