### 6. The derivation this row got wrong, and what caught it

**THE FIRST PASS USED A HAND-WRITTEN WALK AND IT WAS WIDER THAN THE REGISTER'S.** `scriptSources` filters out any file under a directory named `test`; the reimplementation did not, and also ignored `SKIP_DIRS`. It therefore reported a swept scope of **407** files at `de5f90b5` where `sweptSources` returns **402**, the difference being exactly the five files under a `test/` directory.

Leg 7 reported no finding at all, because that file is not in the swept scope and never was. **The mechanism ADR-417 built to check the register's arithmetic caught this row's arithmetic about the register**, which is a stronger result for leg 7 than any case this row could have written for it.

**AND THE LESSON IS THE ROW'S OWN SUBJECT ONE LEVEL UP.** ADR-417 established that a figure nothing derives is a figure nobody checks. This row establishes the companion: **a figure re-derived by a SECOND reader is a figure about the second reader**, and the only re-derivation that can falsify a register's number is one that runs the register's own code. Every figure in section 5 was re-derived that way after this was found, and section 5's method paragraph exists because of it.
