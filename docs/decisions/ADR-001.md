## ADR-001: Repo root stands in for `merit/`  (2026-08-13, status: accepted)
- Context: Section 0.5 draws the skeleton under a `merit/` directory. The git repo `meritfutures` already holds the constitution at its root.
- Decision: Treat the repo root as `merit/`; the skeleton lives directly at root.
- Alternatives considered: Nesting everything under a `merit/` subdirectory (adds a pointless path segment to every reference).
- Consequences: All constitution paths map 1:1 with the leading `merit/` dropped.

- **Founder approval: GRANTED 2026-08-21.** Given by the founder in session 95 as an **explicit delegated approval**, not as a line-by-line read. **Recorded that way deliberately**: [E2](../../MERIT_BUILD_MASTER_PROMPT.md) reserves the line-by-line read for the money path, this entry is not on it, and a signature claiming more than was actually done would put a false attestation into the record this corpus exists to be. **Safe to grant because the ruling is already load bearing and checkable**: every path in the corpus resolves under the repo root today, and `CI-06a` fails on any that does not.
