Three are weak: the path resolves, the file reaches the line, **the cited line is not blank or a bare closing brace**. **`` `start.ts:206` `` CARRIES A PATH AND A LINE AND NO NAME, BECAUSE ITS SUBJECT IS A QUOTED SENTENCE RATHER THAN A DECLARED IDENTIFIER.** So only the three weak legs applied and all three pass: the path resolves, `start.ts` is 317 lines, and line 206 is a comment. **`RI-15`'s blind spot is a citation whose subject is prose**, and no register entry would have closed it, because the check has nothing to anchor to. **This is stated as a hole and not repaired**, on ADR-369's precedent one row over, which found `RI-15`'s second hole and named it rather than widening the grammar.
