### 3. The predicate, derived from inputs, and what it misses

#### 3.1 The rule, in one sentence

**A CASE IS IN THE POPULATION WHEN ITS BODY REACHES A DIRECTORY OF THIS REPOSITORY THAT SOMETHING MIGHT ENUMERATE.** The body is the case callback plus the bodies of every file-local helper it calls, transitively, because `sourceTree()` takes no argument and walks two directories.

**THAT REACHES THE CASE IN THREE FORMS AND THE FOLD DERIVES ALL THREE**, which are [ADR-468](ADR-468.md) section 3.2's three, made mechanical:

| Form | How it is folded | Where it lives |
| --- | --- | --- |
| **W1** an imported constant, or a locally computed root, handed to a call | the expression is folded to a PATH and `statSync` decides. `REPO_ROOT`, `DECISIONS` and a root built from `import.meta.url` are all the same thing to it | 29 of the 49 pieces of evidence |
| **W2** a DEFAULT PARAMETER left at its default | the roster is derived from `packages/tooling/checks/`: a parameter whose default folds to a directory of this tree AND which flows into a directory-enumeration primitive | 16 |
| **W3** a ROOTLESS walker, which reaches a defaulted root with none of its own | every CLI `run` in this tree is one | 4 |

**NOT ONE OF THE THREE MENTIONS AN IDENTIFIER.** Form 1's constant may be spelled anything at all, and the check's own suite asserts that with a fixture whose root is called `WHEREVER`.

#### 3.2 The one fold that separates a walk from a named read, and it is on disk

**`isTreeDirectory` IS THE WHOLE DISCRIMINATION AND IT IS RESOLVED AGAINST THE TREE ON THE RUN.** A folded path is a walk root when it is absolute, inside this repository, exists, and is a DIRECTORY.

- `join(REPO_ROOT, 'apps')` resolves to a directory. **In.** `strip-comments.test.ts` walks it.
- `join(REPO_ROOT, 'docs/architecture/API_CONTRACT.md')` resolves to a file. **Out.** Its cost is the size of that file.
- `'packages/db/migrations'` is a RELATIVE literal, so it is a string a case compares against and not a root it holds. **Out**, and the requirement that a root be absolute is what makes that true rather than an accident of the process working directory. Before that rule, five `generated-column-writes` fixture cases were in the population for owning a path-shaped string.

**THE SAME ROOT, ONE EXPRESSION APART, DECIDED BY `statSync`.** The suite holds that pair open as a single case with two `test()` declarations in one fixture: a named read under the root and a walk under the root, and only the second is named.

#### 3.3 The three states, and why two would be wrong

**A PARAMETER IS `walks`, `unknown`, OR PROVABLY NEITHER, AND COLLAPSING THE MIDDLE ONE LOSES FIVE CASES IN EITHER DIRECTION.**

- `legPaths(prices, DECISIONS, {})` resolves named targets under a directory and enumerates none of it. Every call it makes with that directory is resolvable and none of them walks, so it is **provably clean** and `price-register.test.ts`'s five leg-C cases stay out.
- `findings(id, root)` hands the root to `check(id).run(root)`. Nothing static follows a property of a value, so no proof of cleanliness is available: it is **unknown**, and `repo-invariants.test.ts`'s five real-tree cases stay in.

**THE DEFAULT FOR UNKNOWN IS INCLUSION AND THAT IS A JUDGEMENT, STATED SO A FOUNDER CAN OVERTURN IT.** A missed budget is a red CI months later on a diff that did not cause it; a wrongly required budget is one line a reader can argue with today. **Both are costs and they are not symmetric.** Leg C exists so the second one cannot accumulate silently.

#### 3.4 What the predicate misses, named before anybody asks

1. **A ROOT THAT LEAVES THE EXPRESSION LANGUAGE.** A root stored in an object property, pushed through an array, or returned from a function whose body names no root. The fold follows aliasing, path composition and the branches of a choice, and nothing else.
2. **A HELPER WITH A DEFAULTED ROOT THAT ACTUALLY WALKS.** A signature default is deliberately not a use, because `transcript(checks, root = REPO_ROOT)` names the constant and scans nothing. **A helper written the same way that DID walk would be missed**, and the exclusion is a design decision rather than an oversight: six real cases depend on it and none of the missed shape exists today.
3. **AN ENUMERATION THIS FOLD DOES NOT RECOGNISE.** `ENUMERATORS` is a written register of five primitives. A walk performed by `execFileSync('git', ['ls-files'])` alone would be invisible; `dependants.mjs`'s `population` is caught only because its fallback is a `readdirSync` walk.
4. **A SEMANTIC CHANGE.** A rostered function that stops walking keeps its roster entry, because the roster is derived from a parameter reaching an enumerator rather than from a measurement of the run. Section 10 item 2 prices the measurement.
5. **EVERYTHING OUTSIDE `packages/tooling/test/`.** The fence is the dispatch's. [ADR-466](ADR-466.md) section 7's eight non-scaling cases and any suite elsewhere that walks are out of scope and section 10 item 1 prices them.
6. **A `test()` WHOSE ARGUMENTS DO NOT BALANCE** is dropped rather than guessed at. Section 4.1 is how that stays visible: the site count is asserted against the number vitest reports.
