My argument in section 4 is that the tightening available here would blind the vocabulary to occurrence 2's own sentence, whose only structural difference is a colon where the other has a backtick. **But there is a real cost I should name: two entries that assert nothing now sit in a register whose whole value is that every entry decides something**, and a reader who thinks the register should hold only claims, with false positives fixed in the sweep or accepted as noise, is making an argument about what this register IS that I cannot settle from inside it.
