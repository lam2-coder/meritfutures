### 3. The sweep: the method, and the axis that IS decidable

**The sweep is one script over one file, it lives in the session scratchpad, and nothing from it is committed**, on [ADR-450](ADR-450.md)'s precedent, `ADR-467` section 10's and `ADR-469` section 3's.

It takes `ADR-469` section 3's three prose forms (`` `:NNN` ``, `at :NNN`, `line NNN`) plus the adjacent `path.ext:NNN` form, applies the same neighbourhood requirement (a filename, an ALL-CAPS document name, or `its own` / `this file` within three lines at or above), and then does the one thing no previous sweep did:

**IT ASKS WHETHER THE MATCHED TEXT IS IN A COMMENT, BY RUNNING [`stripComments`](../../packages/tooling/checks/strip-comments.mjs) OVER THE FILE AND CHECKING WHETHER THE MATCH SURVIVES ON ITS OWN LINE INDEX.** That reader is this repository's own, `ADR-279`'s one-state scanner, and it is exactly right for the job for a reason it states in its own header: it **preserves string literals** and it **preserves newlines**, so a site that vanishes from its line was a comment and a site that stays was code.

**THIS IS A THIRD AXIS AND NEITHER PREDECESSOR CONSIDERED IT.** `ADR-467` section 9 ruled that **USE against MENTION** is not mechanically decidable and that **ADJACENT against NON-ADJACENT** is, and it is right on both. **COMMENT against LITERAL is a third, it is decidable, it costs nothing because the reader already ships, and it is the one that decides ELIGIBILITY rather than truth.** It does not say whether a pointer is dead. It says whether a repair is permitted to touch it at all, and on this file it separates 104 sites that no row may touch from 28 that a row may.

### 9. What is owed

1. **A REPAIR LIST IS NOT A REPAIR BACKLOG UNTIL SOMETHING HAS SAID WHICH OF ITS SITES ARE ELIGIBLE, AND NOTHING DOES.** Seven of the thirteen sites in this row's dispatch were string literals that no repair may touch, and the dispatch, the `ALLOCATION` row and `ADR-469` all carried them as one undifferentiated list. **The test that separates them is one call to a function this repository already ships**, and it is not a judgement: a site that survives `stripComments` on its own line index is code. **Price: an eligibility pass over any `file:line` list a decision entry publishes as repairable, dropping every site that survives `stripComments`, run when the list is compiled rather than when a row is dispatched against it. It would have cut this dispatch from thirteen to six.**

   **WHY IT IS PRICED AS AN INSTRUMENT AND NOT AS A GATE, WHICH IS [ADR-450](ADR-450.md)'s TEST APPLIED RATHER THAN CITED.** A gate over the tree asserting that published pointer lists name only comment lines **can** fire on its own motivating case, unlike the widening `ADR-467` section 8 withdrew. A counterexample against a money-path property that appears once in ten runs and cannot be reproduced is worse than one that fails every time: it is indistinguishable from infrastructure, and the corpus's own rule is that a failing test is never a flake. **Price: a decision about seeding, and the mechanism that follows from it.
