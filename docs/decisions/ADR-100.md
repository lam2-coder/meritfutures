## ADR-100: a route module contributes its routes as a unit and the directory listing is the module list  (2026-08-25, status: accepted)

**[P4](../plans/P4-portal-and-site.md) section 8's `P4-d` row is the only row in that plan whose money column carries a consequence instead of a yes or a no.** It reads *"no by content, and **high consequence**: the registry's SHAPE decides whether [M19's seven route slices](../sessions/2026-08-24-session-168.md) serialize."* [Session 168](../sessions/2026-08-24-session-168.md)'s own collision table states it in the direction that fails: *"`M19-1` must create a registry that is **per-module rather than one array**, or these seven serialize."*

**This entry is that decision, and the Fastify admission [ADR-083](ADR-083.md) deliberately left to whoever held the catalog.** ADR-083 ruling 3 chose the framework and installed nothing, because *"a manifest declaring `\"fastify\": \"catalog:\"` against an absent catalog entry does not install. So `apps/api/package.json` declares no runtime dependency ... and **the admission is the next holder's**, with the exact version and the `VG-12` approval that goes with it."* This is the next holder.

- **Origin:** [P4](../plans/P4-portal-and-site.md) section 8's `P4-d`, dispatched as session 209. **Four independent measurements proposed this same slice**: [M03's `M3-c`](../sessions/2026-08-24-session-157.md), [M06's `A`](../sessions/2026-08-24-session-160.md), [M16's `S4`](../sessions/2026-08-24-session-165.md) and [M19's `M19-1`](../sessions/2026-08-24-session-168.md).

- **Non-money by content.** No migration, no `SD-nn`, no schema change and no `packages/db` import. One route is served and it returns a constant.

### 2. The ruling

> **1. A route module is one file under `apps/api/src/routes/`. It default-exports `defineRoutes({ name, routes })`, where `name` is the file's stem, and it is the WHOLE of that module's contribution.**
>
> **2. The module list is the directory listing. Nothing in this repository writes it down, and no file outside `apps/api/src/routes/` imports anything inside it. Adding a route is adding a file.**
>
> **3. A module declares a path and never a surface. `compose` classifies every declared path with [`surface.ts`](../../apps/api/src/surface.ts)'s `classifyPath` and registers only what this process's surface serves, so [ADR-083](ADR-083.md) section 4's 404 stays the router's.**
>
> **4. Fastify enters `pnpm-workspace.yaml`'s catalog at `5.12.1`, the version ADR-083 section 5 measured, and `apps/api` is the only package that declares it.**

### 4. Why the module list is the DIRECTORY and not an array, which is the whole of `P4-d`'s consequence

**The obvious registry is an array in one file that every route module is imported into.** It is greppable, `tsc` checks it, and every registration is visible in one place. It is refused here, and the reason is arithmetic rather than taste.

**[P4](../plans/P4-portal-and-site.md) section 9 rows fifteen slices behind this file, by name, on 2026-08-25**: `P4-f`; [M03](../sessions/2026-08-24-session-157.md)'s `M3-i` and `M3-j`; [M05](../sessions/2026-08-24-session-159.md)'s `M5-5` and `M5-8`; [M16](../sessions/2026-08-24-session-165.md)'s `S4`, `S7` and `S8`; and [M19](../sessions/2026-08-24-session-168.md)'s seven, which that session's collision table names as `M19-2`, `M19-3`, `M19-6`, `M19-7`, `M19-8`, `M19-9` and `M19-11`. **The number is a fact about that row on this date and not a target**; what the ruling turns on is that it is many and that they are concurrent.

**Under an array, each of them adds one import line and one array element in the same two places in one file.** Each branch merges cleanly alone and none of them merges with another. That is not a prediction: it is [P3](../plans/P3-ledger-billing-identity.md) wave 1's finding on `pnpm-lock.yaml`, restated by [P4](../plans/P4-portal-and-site.md) section 9 as **SERIAL, three ways** for the same file, and reproduced across five branches on `schema.ts` in [session 204](../sessions/2026-08-25-session-204.md), where *"git aligns the hunk on lines two unrelated tables merely happen to share"* and a hunk-level keep-both spliced one declaration into another.

**So the module list is never written down.** `discoverRouteModules` reads `apps/api/src/routes/`, imports every `.ts` file in sorted order and validates what comes back. A slice that adds a route **adds one new file and edits nothing another slice edits**, so fifteen branches touch fifteen disjoint paths and merge in any order.

**This is the refusal this repository already makes twice, in the two places it has been checked.** [`repo-invariants.mjs`](../../packages/tooling/checks/repo-invariants.mjs)'s retired-constraint work is *"SEEDED FROM THE MIGRATION DIRECTORY AND NEVER FROM A HAND LIST, which is session 141's own design constraint: a hand-maintained list of retired names is the same defect one level up, stale on the day the next supersession lands."* [`pnpm-workspace.yaml`](../../pnpm-workspace.yaml)'s catalog makes it about versions: *"a number written in seven manifests is a hand-maintained count, and a hand-maintained count drifts."*

**And the array's own failure mode is the silent one.** A slice writes `routes/kyc.ts`, forgets the import line, and the route does not exist with nothing saying so: the file is on disk, the test that imports the module directly passes, and the endpoint 404s in an environment nobody is looking at. **A directory listing cannot have that failure**, because the listing is the definition.

### 5. What discovery costs, and what is bought back rather than assumed

An array is checked by `tsc`. A directory listing is not. **Three properties are therefore bought back deliberately, and each is watched working in [`registry.test.ts`](../../apps/api/test/registry.test.ts).**

| Property an array gives free | How it is bought back | Watched |
|---|---|---|
| The module's SHAPE is type-checked | every module writes `export default defineRoutes({...})`, and `defineRoutes` is typed `(m: RouteModule) => RouteModule`, so `tsc --noEmit` reports a malformed module **in the module's own file** rather than at an import site | `tsc` exit 0 |
| Nothing in the directory is silently ignored | `discoverRouteModules` THROWS on any `.ts` file that does not default-export a valid module, and on a module whose `name` is not its filename stem | five refusals asserted |
| Nothing is silently NOT registered | the suite asserts an **equality** between the discovered module names and the directory listing, not a count, so a module added by any future slice appears with no line of that test changing | one assertion |

**The third row is strictly stronger than an array and it is the collision fifteen concurrent branches make likely.** `compose` refuses a duplicate `METHOD /path` across the whole module set, **before** the surface filter so that a duplicate is a defect even when neither copy is served here, and refuses two modules answering to one name. **An array would have merged both copies**, and Fastify would have refused the second registration at startup, leaving the surviving handler to be whichever file sorted first.

**The exclusion list is the thing most likely to be added later and it must not be.** Every `.ts` file in `routes/` is a route module, with no exception, which is why the registry machinery lives one directory up in `apps/api/src/`. A list of files in `routes/` that are *not* routes is the hand-maintained list this whole ruling refuses, one directory over.

### 6. The surface filter is the PATH's decision and never the module's

[ADR-083](ADR-083.md) section 4: a process serves exactly one surface, chosen at startup, and the public deployment answers 404 for `/internal/*` **by having nothing there**. `compose` classifies every declared path with `classifyPath` and registers only what `surfaceServes` allows.

**A module has no field with which to declare a surface, and that absence is the ruling.** The contract already put the answer in the path; a second place to say it is a second place to say it differently. **What is withheld is never refused at request time**: it is not registered, so `surfaceServes` returning false is not a permission check and must never become one.

**Both directions were watched over a real socket, in two processes, on two ports, composing the SAME module set** (section 7's scratch run): `GET /api/v1/internal/jobs` answered **404** on `api` and **200** on `api-admin`, and the public process logged `"registered":["GET /health"],"withheld":["GET /internal/jobs"]`.

**The error model here is the transport's two and is not the contract's sixteen.** [API_CONTRACT section 2](../architecture/API_CONTRACT.md) defines sixteen canonical codes and fourteen of them belong to a handler that computes something: `payout_not_eligible` carries a gate breakdown, `idempotency_key_reuse` compares a stored body. What is the transport's is the 404 for a path nothing registered and the 500 for a handler that threw, and **the first of those is the one ADR-083 rests on**. Left to Fastify it arrives as `{"message":"Route GET:/api/v1/... not found","error":"Not Found","statusCode":404}`, which is neither section 1's media type nor section 2's shape and which echoes the requested path back to the caller. So the not-found handler is the smallest thing that makes ADR-083's structural claim a contract-shaped one, and a status this file has no canonical code for becomes `internal_error` with its real status in the log rather than acquiring an invented code.

### 7. What this forecloses, and the finding that is NOT this fence's

**Named because an entry that records only the winner leaves the next reader unable to tell whether an alternative was considered or never seen.**

| Foreclosed | What it costs to reopen |
|---|---|
| **A route array, a manifest file, or any list of modules kept by hand** | The whole of section 4. Reopening it re-serializes every slice in section 4's list and reintroduces the forgotten-import failure |
| **An exclusion list inside `routes/`** | Section 5's last paragraph. It is the refused design one directory over, and it arrives disguised as a convenience |
| **A module declaring which surface it serves** | Section 6. It makes ADR-083's 404 a thing a module author can get wrong, which is exactly what ADR-083 refused when it chose a second deployment over a permission check |
| **Nested route directories** | `discoverRouteModules` reads one directory and does not recurse, so `routes/kyc/session.ts` is invisible. Deliberate: a nested layout makes a module's name ambiguous and the filename-stem check unimplementable. Reopening it means ruling how a nested name is spelled first |
| **Fastify plugins as the unit of contribution** | `fastify-plugin`, encapsulation and per-plugin hooks are all still available INSIDE a handler's own module; what is foreclosed is a module contributing itself as `app.register(...)` rather than as data, because the surface filter must be able to read a module's paths **without running it** |

**One finding is reported rather than repaired, and it is not this session's fence.** `node --experimental-strip-types` resolves an import specifier to **the file it names**; it does not map `./index.js` onto `index.ts`. Every module under `apps/api/src` writes the `.js` form, because `tsc` under `moduleResolution: NodeNext` requires it. **So `pnpm --filter @merit/api start` has never run**, and neither has `apps/admin`'s nor `apps/worker`'s: all three declare `node --experimental-strip-types src/index.ts` and all three die with `ERR_MODULE_NOT_FOUND` on their own first relative import, measured in [session 209](../sessions/2026-08-25-session-209.md).

**ADR-083 is NOT edited and its ruling 3 is not weakened.** Its section 5 measured a `.ts` entry point serving 200 under this runtime and that measurement stands; what it did not measure is this tree's specifier convention, because at that time `apps/api` had one relative import and no way to run.

**The repair was executed in a scratch copy outside this repository, on ADR-083 section 5's own precedent, and it is two things together:** `./x.js` becomes `./x.ts` throughout the affected `src/`, **and** the tsconfig gains `allowImportingTsExtensions: true`, without which `tsc` reports `TS5097` on every rewritten line. With the specifiers rewritten by `sed` and **nothing else changed**, both surfaces started under `node --experimental-strip-types` and served. **`apps/api/tsconfig.json` is outside `P4-d`'s fence** and `apps/admin` and `apps/worker` are outside it entirely, so the finding is reported with its executed repair rather than reached for.

### 8. Consequences

- **[`apps/api/src/start.ts`](../../apps/api/src/start.ts) exists so that `index.ts` stays a module that exports.** An entry-point guard comparing `import.meta.filename` with `process.argv[1]` is a run-time string comparison that is invisible when it stops matching; a separate file has no such failure mode.
- **`VG-3` and `VG-6` are re-ruled and the gate was watched failing first.** Both waited on *"fastify present in the lockfile"*, which this entry delivers, so `CI-06/vg-inventory` went to 29 of 30 on the catalog commit exactly as [ADR-073](ADR-073.md) intends. Both now wait on **`scopedDb` named under `apps/api/src`**, which is [API_CONTRACT section 1](../architecture/API_CONTRACT.md)'s own mechanism for the thing each row is about: *"Every authenticated handler resolves the caller to an identity and reads through `scopedDb(identity)`."* **The new artifact is closer to each row's subject than a lockfile key was**, which is the direction a re-ruling should move. `VG_PROBES` loses its `fastify` entry and gains this one; **the register shrinks in the stale direction**, which is that gate's own stated property.
- **`VG-2`, `VG-10` and every other row of section 4.2 are untouched.** `VG-10` is the table's one conjunctive row and nothing here reads across to it.
- **`RI-09` needed no change and was not edited.** It reads `BASE_PATH` and `OPERATOR_PREFIXES` out of `surface.ts`, and this entry adds no vocabulary and keeps no second copy of either. It reports **8 of 8**.
- **`CI-06/gate-inventory` is not touched**: no `apps/*/package.json` gains or loses a `build` script here, so [ADR-099](ADR-099.md)'s repair of that clause is unaffected.
- **No migration, no `SD-nn`, no new `CI-06` letter, no gate change beyond the two `VG` rows and the register that reads them, and no `falsify` case.** `0048` stays free and the scope-case count does not move.

The half that stays is the one that matters: the refusal happens before anything is read off disk and before anything listens.
- **What `P4-f` and the fourteen module slices behind it inherit is a file to create.** `apps/api/src/routes/index.ts`, which [P4](../plans/P4-portal-and-site.md) section 9 names as the barrier, **is not created and is not needed**: under this ruling there is nothing for a slice to register into.   **What a founder read adds is the years-long half, and nothing here substitutes for it.** Section 4's decision is the one this project lives with for as long as `apps/api` has routes, and a delegated grant is weakest exactly there. It is named rather than absorbed.

  **ONE CHECKABLE CLAUSE, WITH NO COUNT IN IT, WRITTEN IN THE DIRECTION THAT FAILS.** Seven signed or proposed clauses in this corpus have drifted on an enumeration ([ADR-099](ADR-099.md) section 4 names six and `ADR-095`'s is the seventh), so this one names no number and is two commands:

  > **No file under `apps/api/src` imports from `apps/api/src/routes/`, and every `.ts` file in `apps/api/src/routes/` is composed by the server.**

  | Half | Command | Result on this tree, 2026-08-25 |
  |---|---|---|
  | Nothing imports a route module | `grep -rnE "from '\.\.?/routes/" apps/api/src --include='*.ts'` | **no match**, exit 1 |
  | Every file in the directory is composed | `pnpm vitest run --project unit apps/api/test/registry.test.ts` | **15 passed**, including the discovered-names-equals-directory-listing equality |

  **The first half is the direction that fails, and it is FALSE for every array-based registry**, which is the design section 4 refuses: under an array, `index.ts` imports every module in that directory and the grep returns a line per route. **Cost if it goes false:** one file has become the write collision the ruling exists to prevent, and the slices section 4 enumerates serialize on it. **Cost if the second half goes false:** a file sits in `routes/` and is not served, with nothing saying so, which is the array's silent failure arriving through the door that was supposed to be closed.

  **The reverse of the second half is deliberately not claimed.** That every composed module is a file in the directory is true today and is not asserted, because `compose` takes its modules as an argument on purpose: a test composes a synthetic operator module, and a clause forbidding that would forbid the only way ADR-083's withholding can be watched before an operator route exists.
