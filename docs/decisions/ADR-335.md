### 5. FINDING: [ADR-183](ADR-183.md) and `0054`'s own header report a word count this tree measures differently, and the cause was executed

[ADR-183](ADR-183.md) section 3 and [`0054`](../../packages/db/migrations/0054_identity_ledger_accounts.sql)'s header both state, of the schema at `0001`..`0053`, that there are **21 non-internal triggers over 19 distinct functions**, that **not one function body contains an `INSERT`, an `UPDATE` or a `DELETE`**, and that *"two match the word `UPDATE` and both matches are inside an error-message string"*.

**THE CAUSE IS WHAT COUNTS AS A MATCH AND IT WAS EXECUTED.** Stripping `--` comments and single-quoted string literals from each body and repeating the scan leaves **exactly one** function matching anything: `assert_adjustment_reversal_is_sound`, whose match is `FOR UPDATE;`, the row lock ending a `SELECT`. **THE CLAIM THE RULING RESTS ON SURVIVES AND THE INCIDENTAL COUNT DOES NOT.** No trigger function at `0053` executes a write statement, which is the fact `0054`'s precedent argument needs. *"Two match the word `UPDATE` and both are inside a string"* undercounts by one function and misplaces two matches that are in a comment and in a row lock. **NEITHER RECORD IS AMENDED**: both are dated, `0054` is merged and constitution `E2` makes it permanent, and both were true of the reading their author took.
