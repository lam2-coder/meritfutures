## EC-083: A parameter value burned into an image cannot be linted  (2026-08-14, module: M9, status: specced)
- Scenario: The MDX lint (VG-M9-2) prevents a plan parameter appearing in content prose, so every number a reader sees in text is read live from config. It cannot see a number rendered inside a hero image, a social card, a video thumbnail, a diagram, or a screenshot of the portal. Those artifacts are exactly where a launch-day cap or price is most likely to be written, and they outlive their configuration silently because nothing in the build can read them.
- Correct behavior: A standing content rule with no technical enforcement, stated as a rule precisely because it cannot be enforced: **no marketing image contains a parameter value.** Images carry mechanism, not magnitude. Where a number must appear visually it is composed at render from `<PlanValue>` over a background rather than baked into the asset. The quarterly content audit covers the image inventory explicitly, because it is the one class the lint can never cover, and an audit whose scope is "whatever the lint missed" is an audit of nothing.
- Golden scenario ref: GS-143 covers the linted half; the image rule is an audit item rather than a fixture, and saying so is part of the entry.
