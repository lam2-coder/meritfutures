## EC-140: A rejected mechanic returns as a roadmap item nobody re-prices  (2026-08-14, module: M14, status: specced)
- Scenario: [ADR-025](../decisions/ADR-025.md) rejects progressive cap release, and the `payout_cap_schedule` array survives it because the shape costs nothing and the publish-time validations should stay exercised. That combination is a trap with a long fuse. Some months from now a competitor ships a cap-release program, somebody looks at the schema, finds an array that already supports multiple steps and a publish path that already validates them, and concludes the feature is a config change that was simply never turned on. The arithmetic that made it a bad trade lives in an ADR nobody in that conversation is reading, the cohort argument lives in an adversarial scenario in a module plan, and the decision gets reversed by an afternoon rather than by an argument. The same shape applies to the retired `loyalty.cap_release_proposed` event and the retired `M14-P-nn` suite: a name that once existed in a design document is a name somebody re-implements from an old branch. **The general failure is that a rejection is invisible in the artifact while a deferral is visible in the backlog, so rejections decay faster than deferrals do.**
- Correct behavior: Three defenses, and they are cheap because they are all documentation with a test attached. **A publish-validation alarm**: a `payout_cap_schedule` with more than one step reaching publish validation **pages**, not because it is an error but because it is a decision that must not happen by accident, and the alarm text names ADR-025. **The rejected path stays documented as a negative flow** ([M14](../plans/M14-loyalty-retention.md) section 3.5) rather than being deleted, so the route a reversal would have to take is written down and the negative tests can assert against it by name. And **the golden file keeps the price**: GS-179 is rewritten to pin that no v1 plan version carries a second step, and it carries the full option arithmetic as a superseded counterfactual, which is the same discipline [GS-055](../testing/GOLDEN_SCENARIOS.md) uses for the cadence anchor. A reversal then costs an ADR arguing against a number that is sitting in the test suite, which is the correct price.
- Golden scenario ref: GS-179.
