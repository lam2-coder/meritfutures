### 1. The dispatch's two claims, checked at the source before anything was built

| Claim | Where it is settled |

### 2. The scope, and why it is the corpus's own rule rather than a new one

The measurement over every tracked `.md` under `docs/`, on this branch:

| Population | Count |
|---|---|
| Citations carrying a path of their own or a markdown link | 2,340 |
| ... of those, under a dated or session heading | **1,737** |
| ... of those, in scope | **603** |
| Bare `` `:12` `` with no path and no link | **1,123** |
| Documents read | 879 |
| Citations in scope carrying a bindable NAME | **5** |
| **Findings** | **4** |

**Exclusion 1 is `CI-06/derivable-counts`' rule, applied through its own recogniser.** That gate's header argues it at length over this same corpus: an entry headed `## ... (2026-08-24)` or `## Session 207: ...` *"IS A RECORD OF A MEASUREMENT MADE THAT DAY"*, and repairing it *"would REWRITE THE RECORD TO SAY SOMETHING IT DID NOT SAY, which is a worse defect than the one being repaired"*. It is read at heading levels 1 and 2 only, so an ADR's `### 3.` inherits the dated `##` its file opens with. Three consequences worth stating: it splits `STATE.md`, which no directory rule can; it puts a new session log out of scope and a new plan in scope on the day each is written, with nobody maintaining a list; and it is **one** rule this corpus keeps rather than a second that drifts from the first.

**Exclusion 3 is the one that diverges from `RI-15`, and it is measured rather than asserted.** `RI-15` lets a bare pointer inherit the nearest full path within six lines and names as its miss (6) that this *"is wrong wherever a nearer path was cited for something else -- across the rows of a markdown table"*. In this corpus that is not an edge. Inheritance adds fifteen findings inside this scope and every one of the fifteen is the reader guessing:

| Seen | What it actually is |
|---|---|
| `M05:214`, `M05:271`, `M03:311` | a PLAN and a section line |
| `0011:49`, `0026:157` | a MIGRATION NUMBER, which carries no extension |
| `open_ct 17:00` | a CLOCK TIME in a transcribed calendar row |
| a bare `` `:874` `` written inside a markdown link | a real citation whose path is in the LINK rather than above the line |

**The last row is the half that closes without guessing, and it is closed.** A citation written inside a markdown link takes the path the link states: 130 more citations in scope, a 27 percent gain over the path-carrying set, each resolved to ONE file rather than to every file in the tree whose name ends the same way. **Skipping the other 1,123 is declining to invent a target, not declining to look.** The two shorthands are named in `covers` as the growth path: a table mapping `M05` and `0011` to files would resolve most of them.

### 4. Three defects in the shared reader, all invisible on six source files

The citation grammar is now ONE reader used by both checks rather than two copies, and pointing it at 19 MB of markdown broke it three times.

| Defect | What it did |
|---|---|
| The `CITATION` regex, one pattern with a lazy backtick-bounded prefix | QUADRATIC on a document with long backtick-free stretches: every backtick is tried as an opener and each rescans the region after it. Replaced by a tokenizer that walks the backticks once |
| `flattenReasons`' line joiner | Every leading group optional, so it had no literal to prefilter on and was tried at EVERY index; and `[ \t]*` twice around an optional token is two greedy runs over one character class, which backtracks over every way to split a run of spaces. **A padded markdown table is one 13,000-character line of them.** Replaced by a hand scan from each end of a line |
| The path character class | Dropped a Next.js route group, so `apps/portal/src/app/(purchases)/ports.ts:50` resolved to `/ports.ts` and reported a path nobody could follow |

**`docs/decisions/ALLOCATION.md` did not finish in five minutes and the whole of `docs/` now reads in 0.38 seconds.** `RI-15`'s ten cases assert its finding text character for character and are unchanged, which makes them the equivalence oracle for all three repairs.
