### 4. What was measured and NOT taken

- **A door built on `pool.query`.** The obvious design, and the one this row expected to ship. Refused on a measurement: `pg`'s pool hands the same backend to the next caller, so a bare `BEGIN` outlives its statement and reaches whatever checks that connection out next, which on this pool is a money write. Watched failing on the new case.
- **Destroying the connection unconditionally.** It closes the same hazard and costs one connection per statement against the money database forever. Refused: connection churn is the outage-shaped mistake, and [ADR-327](../decisions/ADR-327.md) section 3.3 already ruled which direction of error is worse.
- **Reading `pg`'s private `_txStatus`.** Written first, then replaced: `getTransactionStatus()` is on `@types/pg` and returns `"I" | "T" | "E" | null`, so the door reads a published API and needs no cast and no probe.
- **A member naming a SERVICE**, `'queue-supervisor'` or `'detector-service'`-shaped. Refused on [ADR-165](../decisions/ADR-165.md) clause 3's rule: the vocabulary names KINDS OF ACCESS, and what this member names is a LIFETIME.
- **Widening `SqlExecutorReason` without partitioning it.** That would have handed every transaction handle in the file a word for an executor that must outlive a transaction, which is the door [ADR-331](../decisions/ADR-331.md) section 4 clause 2 refused by name.
- **Amending `RI-35`'s register.** The sentence this row retires was never registered, so the invariant did not go red and the dispatch's conditional grant did not fire. The binding is hand-built in `surface.test.ts` and the register entry is named as owed.
- **The queue's one door under `apps/worker/src`.** Trivially writable now. Left, on [ADR-331](../decisions/ADR-331.md) section 4 clause 4.
