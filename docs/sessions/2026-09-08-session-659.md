### 8. Landmines

**THE REGISTER'S STATE COLUMNS ROT SILENTLY AND NOTHING WILL SAY SO.** A price marked `OPEN` whose work landed yesterday stays `OPEN` until a reader moves it. The checker asserts presence, anchors, paths and vocabulary; it asserts nothing about whether a state is current. This is stated in the register, in the checker's header and in [ADR-464](../decisions/ADR-464.md) section 4, and it is the thing most likely to be misread as a stronger guarantee than it is.

**THE ANCHOR IS A LINE NUMBER IN A DATED RECORD.** That is stable by [ADR-386](../decisions/ADR-386.md):169 and it is the reason a moved line goes red rather than silently wrong. **It was demonstrated by accident on this row**: adding one paragraph to [ADR-464](../decisions/ADR-464.md) moved its seven anchors twice and leg A reported all seven both ways each time. A row that ever legitimately rewrites an entry's body will have every anchor in it to answer for.

**LEG C SEES A PATH ONLY WHERE THE PRICE LINKS IT.** 23 citations over 15 of the 55 prices. A clause naming a file in a bare code span is invisible to it, which is the same hole [ADR-461](../decisions/ADR-461.md) section 7 item 1 found in the citation discipline at large.

**PRETTIER PADS MARKDOWN TABLE CELLS.** A test asserting a table row as a literal string passes before the formatter and fails after it. One case in this row's own suite had that defect and it was found by a seed rather than by review.
