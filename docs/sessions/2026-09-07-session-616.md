### 4. One thing this row got wrong and fixed in the open

The fourth census case, `limit 4 is UNSPENT in the door itself`, was written to search 200 characters past each verb for `Promise<unknown`. `ScopedTx.rows` sits one line above `insert`, whose return is `Promise<unknown[]>`, **so a fully narrowed `rows` still passed the case by matching its neighbour's return.** The RED watch is what caught it: seeded with the narrowing, the run reported `rowsWhere` failing where `rows` should have failed first. Rewritten to read the first `Promise<` after each signature's own parameter list closes, the same seed reports `rows` narrowed at **12 of 12** declarations. **A control watched red only where it is expected to go red is a control half tested**, and the discrepancy in WHICH case fired is what exposed this one.
