### 1. The objective

Improve the precision of the `enumeration` kind in `packages/tooling/checks/dependants.mjs`, **or establish that it cannot be improved without going quiet, and say which**; reduce the standing figure for directory reads that do not fold; make the test runner's computed configuration answerable; and decide, or decline with a reason, whether the closure default should ever be more than one hop. **Not to retire the compatibility module**, which row 425 holds and which this row did not go near.

### 2. Done

- **The `retention` tier**, four values, attached to every `enumeration` site and removing none. `selected`, `excluded`, `unfiltered`, `unreadable`. **The kind's precision is unchanged at 1 in 18 because nothing was dropped; the `selected` tier is 1 in 2.**
- **The walker recogniser now keeps the whole directory expression** and folds it at the call site with the parameter bound to what was passed. **171 unresolved directory reads become 137**, of which **5 are this row's own fixtures**, so the figure with this module's own suite set aside is 167 before and 132 after. A declaration is no longer counted as one of its own call sites.
- **`scripts/corpus/gates.mjs` found as a dependant of the compatibility module that no row has named**, and `apps/site/src/content/lint-cli.ts` returned to `undecided` as a false positive. **21 delete-breaking files before and after.**
- **The test runner's configuration folded**, both `include` and `exclude`, to **0 undecided** entries.
- **The one-hop default decided and kept**, with the size of the second hop derived and named on every ordinary run.
- **`packages/tooling/test/dependants.test.ts` at 58 cases**, up from 43. **Eleven mechanisms watched RED**, section 4.

### 3. Refused, and not attempted

- **The retirement, and any edit to any file row 425 holds.** Forbidden by the row and not attempted. The deletion was performed only in a throwaway worktree.
- **Turning the tier into a filter.** It is the one thing this row was told not to do, and the seed that does it is in section 4 so that a later row cannot do it by accident.
- **Reading NAME predicates as well as content predicates.** It would need the module to decide which side of the walk each predicate sits on, and deciding that wrong in the quiet direction is the failure ADR-422 named. Recorded in ADR-427 section 3 as a limit rather than attempted.
- **Widening the closure default.** Decided against, with the reason written, rather than left open a second time.
- **Repairing anything outside the fence.** `scripts/corpus/gates.mjs` is named and not touched.

### 6. Landmines

- **A READER WHO TREATS `excluded` AS `absent` HAS DEFEATED THIS ROW.** The tier cannot remove a site and the suite watches that it cannot, but nothing can stop a person from reading a word as a verdict. `excluded` means a DELETION is not felt through that file's content predicates and a CHANGE to the target's bytes would be.
- **THE INSTRUMENT'S ANSWER FOR `apps/api/src/events.ts` CHANGED WHILE ROW 425 HOLDS THAT FILE.** One name in, one name out, no count moved. ADR-427 section 5 is written for that row to read.
- **`unreadable` HAS NEVER OCCURRED ON THIS TREE**, which makes it a second instance of the question ADR-422 put to a founder about a register entry nobody has paid for.
- **137 UNRESOLVED DIRECTORY READS REMAIN, AND 5 OF THEM ARE THIS SUITE'S OWN FIXTURES.** A fixture that spells a directory read inside a string literal is counted as one, which is ADR-422 section 8's finding in a second shape and is recorded rather than repaired.
