### 4. The three things worth carrying forward

**FIRST, NONE OF THE THREE HAS A PROBE, AND THE WAY THAT WAS ESTABLISHED IS THE USEFUL PART.** A removal counterfactual says whether a reader NOTICES a file; it cannot say whether a reader ever ENTERS the code the file installed. Both trigger functions were replaced with instrumented bodies in scratch copies of the fully applied database and every probe was run against each. `0070`'s fired **zero** times. `0072`'s fired **four**, all on the arrow it permits. **So the committed coverage of the withdrawal approval chain checks that the schema installs and nothing else.**

**SECOND, A MIGRATION HEADER THAT DESCRIBES THE SURROUNDING TREE HAS A HALF-LIFE, AND THIS ROW FOUND TWO EXPIRED.** `0068`'s four-route grep and `0070`'s *"IT DRIVES NO EDGE"* were both true when written and are both false now, and constitution `E2` means neither can be corrected in place. **`0072`'s conditional is the counter-example worth noticing**: it named a condition rather than a state, the condition has since been met, and the file was already there to catch what the condition let in.

**THIRD, TWENTY-SIX LINE-NUMBER CITATIONS OF THREE FROZEN MIGRATIONS AND NOT ONE HAS DRIFTED.** Over the same period the one line-number citation of the delta manifest has drifted twice. `E2` is what makes the first number possible, and it is the argument for pinning a claim to a frozen file rather than to a living one.
