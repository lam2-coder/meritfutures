### The two things the mechanisms cannot do, named rather than implied

**No gate can check a transcribed value against the CME publication.** That is `OQ-SE-04`'s blind second transcription and `generate.mjs --diff`, and it is a procedure with a human in it. `CI-06m` checks that the file is internally coherent and that its generated output reproduces; **a coherent file can still be wrong about a Tuesday**.

**`merit/no-calendar-in-expiry-path` reads one file at a time with no type information**, so it sees the spelling of the dependency. A calendar value passed in as an argument, or reached through a re-export under another name, is invisible to it. That is `merit/engine-purity`'s declared boundary verbatim, and the answer is the same: **the rule closes the accidental door**. The deliberate one is closed by a reviewer who sees a `trading_day` in a freeze sweep and has a question to ask.
