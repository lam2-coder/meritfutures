**THE BASE PATH IS NOT WRITTEN IN THIS PACKAGE AND THAT IS `RI-04`.** [`surface.ts`](../../apps/api/src/surface.ts) declares `BASE_PATH = '/api/v1'` and its own `assertContractPath` says *"the base path is one string in one place and a path that carries its own copy is a second one"*. A deployable may not depend on a deployable, so `apps/site` cannot import it; writing the literal here would be the second copy that file refuses. **So the base URL is configuration** -- origin plus base path, supplied by the deployment -- and every path above is a contract path as API_CONTRACT writes it. A trailing slash is REFUSED rather than trimmed, because two configurations that differ only in a slash would request different bytes for one page and FM-M9-08 asserts a build digest after deploy.

**EVERY RESPONSE IS DECODED AND NOTHING IS CAST.** The decoders return the engine's own `PlanVersionSizeRow` and `PlanRulesJson`, so the object literals are compile-checked against the shapes the engine executes: the day the engine grows a column, this file fails to compile rather than silently dropping it. ### 6. Six gaps between the corpus and the wire, every one refused rather than filled

**NONE OF THESE IS REPAIRED HERE.** API_CONTRACT is `approved` and moves by ADR; [ADR-096](../decisions/ADR-096.md) section 10 puts the endpoints outside a session that is not amending the contract; and `docs/architecture/**` is outside this fence in any case.

1. **`public_slug`, `public_visible` and `superseded_by` are in NO response shape.** `PlansResponse` and `PlanVersionResponse` at [API_CONTRACT](../architecture/API_CONTRACT.md) section 4 carry neither, SD-M9-01 stores the first two, and INV-M9-11's permanent archive URL is unbuildable without the first. **The adapter refuses the response naming the field and the dependency**, and it NEVER derives the slug: [`types.ts`](../../apps/site/src/catalog/types.ts) says *"Never derived from `version`"*, and a derived permanent URL is the failure SD-M9-01 exists to prevent.
2. **`marketed_size_label` is DEP-M9-07's and is owed.** Same refusal. A missing key silently rendering the capital figure would be GS-310's default standing in for a contract nobody amended.
3. **`PlanSize` IS REFERENCED TWICE IN API_CONTRACT AND DECLARED NOWHERE IN IT.** `grep -n 'PlanSize' docs/architecture/API_CONTRACT.md` returns `:260` (`PlanVersionResponse.sizes`) and `:605`, and `grep -n 'PlanSize\s*='` returns **nothing**. The one response shape the site's whole pricing surface reads has an undeclared element type, which is why the size decode below is written against [`0004_catalog.sql`](../../packages/db/migrations/0004_catalog.sql)'s columns through the engine's `PlanVersionSizeRow` and not against a contract type that does not exist.
4. **The ARCHIVE half of `CatalogReadPort` has no address.** [`ports.ts`](../../apps/site/src/catalog/ports.ts) says the port "RETURNS SUPERSEDED VERSIONS TOO ... the build needs the archive and not only the shelf" (DEP-M9-01) and INV-M9-11 requires every version to keep a page forever, and **no document rows a list-the-versions-of-a-plan read**. So the adapter reaches the shelf, and the suite asserts `superseded_by === null` on every version it returns rather than letting a partial archive look like a whole one.
5. **Three of the five endpoints M9 consumes are in no contract**, exactly as [ADR-096](../decisions/ADR-096.md) section 7 measured; re-checked and unchanged. The adapter is a CLIENT of paths M9 section 4 rows, which is a different act from serving them.
6. **`listAll` and `readRestrictedCountries` have no address at all** and throw `UnservedEndpointError`. An empty country list would publish *"no country is restricted"*, which is a disclosure nobody wrote, and ADR-096 section 7 names that exact port as *"the shape that produces reading 1 under a deadline"*.

**AND ONE WIRE DETAIL WAS CHOSEN HERE, WHICH IS THE ONLY ADDRESS IN THE FILE NOT READ OFF A DOCUMENT.** `GET /public/content/:kind/:slug` carries neither the locale nor the version in its path template and no document says how either travels. Both are query parameters, declared as `CONTENT_LOCALE_PARAM` and `CONTENT_VERSION_PARAM` so the amendment that settles it is a two-line diff rather than a search across three call sites.

**MONEY ON THE WIRE INHERITS [SESSION 111](2026-08-21-session-111.md)'s UNRESOLVED DISAGREEMENT.** INV-02 makes money `bigint` at every boundary and API_CONTRACT declares the same quantities `number`. The portal routes around it by never computing; this adapter has to CONSTRUCT the `Cents` the renderers take, so it decodes: an integer `number` or a string of digits, and **a float is refused** with a message that says a fractional cent is a figure somebody computed. The string form is accepted because [ADR-031](../decisions/ADR-031.md) rules the public statistic surface `bigint` with a unit and JSON carries no bigint above 2^53.

A log describing this landmine must NAME the markers rather than write them, or fence them; the gate's own message says *"a document is quoting a closer outside a code fence"*, and it is right to.
