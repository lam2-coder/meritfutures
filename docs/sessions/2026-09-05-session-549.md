### 5. Landmines

1. **THE HAZARD THE ADAPTER CREATES IS LIVE THE MOMENT ANYBODY ADDS A CALLER.** `deliverOne` CATCHES a refusing port and writes `outcome: 'failed'`; `0040` REVOKES `UPDATE` and `DELETE` on `report_deliveries`. So a clock in front of the composed value appends one **uncorrectable** `failed` row per enabled schedule per window at climbing `attempt` ordinals, and on the day a transport lands every earlier window reads as a transport that existed and could not send. That is `DigestUnwired`'s own indistinguishability with the sign flipped. Case 5.1 measures it; case 5.3 watches for the caller.
2. **`git merge-base --is-ancestor` ANSWERS WRONGLY ON A SHALLOW CLONE WITH 645 DEPTH-1 TIPS.** It reported `origin/main` as NOT an ancestor of this branch until the two refs were deepened to 200, after which it answered correctly and `git log HEAD..origin/main` was empty. **Any row deriving ancestry in this environment must deepen first**, and a row that trusted the first answer would have merged a `main` that had not moved.
3. **The `why` fields of both blocker registers are checked by nothing.** The `cite` fields are, by cases 4.4 through 4.7. A blocker whose reasoning goes stale while its cited artifact stays put turns nothing red. ADR-342's landmine 1 already names the general repair.
4. **`postgresDigestIo` takes `tradingDayOf` as a bare `(at: Date) => string`**, so a caller may pass `() => '2026-01-01'` and the type accepts it. The pin is offered and is not enforced.
