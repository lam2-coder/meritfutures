**Objective.** Establish what the composition [ADR-256](../decisions/ADR-256.md) named actually is,
which of the two certificate ports it closes, and whether closing one without the other is
legitimate given [ADR-246](../decisions/ADR-246.md) ruled the two expire together. Then build it, or
establish it as not-yet-buildable and say what that costs.

---

### 1. What was done

**The composition exists.** [`apps/api/src/certificate-image-source.ts`](../../apps/api/src/certificate-image-source.ts)
holds `databaseCertificateImageSource(db, env)`, which is the three arms
[ADR-256](../decisions/ADR-256.md) section 7 named, put together:

- **the read**, `db.publicLookup` on `certificates` by `code`, narrowed through `toVerifyRow`,
  which is `GET /verify/:code`'s own reader rather than a second one;
- **the append**, `databaseVerifySource(db, env).record` delegated to rather than reimplemented;
- **the bytes**, `renderCertificateCard(toCardInput(row, copy))`.

[`start.ts`](../../apps/api/src/start.ts) installs it. `useCertificateImageSource` leaves the
`BLOCKED` list, and the wired count moves from **8** to **9**.

**Where it lives is an argument rather than a convenience.** Not in `routes/certificates.ts`,
because [ADR-256](../decisions/ADR-256.md) section 2 spent an assertion on that file not importing
the renderer, and what it buys is that `assertPng` there stays a VALIDATOR at the boundary rather
than a producer checking its own work. Not a workspace package, for that entry's reason unchanged.
**The renderer's own isolation is untouched and is asserted from both ends.**

---

### 2. The finding

**The trap the row named for `useCertificateBackend` has a second face on the port this slice
wires, and shutting it is most of the design.**

A deferred code never renders ([ADR-168](../decisions/ADR-168.md) foreclosure 4), so every refusal
the render makes is a refusal only a code whose row ISSUED can reach.
[ADR-256](../decisions/ADR-256.md) made `assertCopy` state-independent **across the five sentences**,
so a broken `fact_untrue` fails an issued card too. That is the half a renderer can shut by itself.
It cannot shut the other half, because a renderer never sees a code no row carries and never sees a
deferral.

**Left inside the render, one curly quote in `MERIT_VERIFY_DISCLOSURE` answers 404 for a deferred
code and 500 for an issued one**, and the difference between those two answers is a fact about
Merit's book handed to whoever holds the token. That is
[ADR-246](../decisions/ADR-246.md) clause 8's shape exactly, built out of configuration instead of a
half-wiring.

**So the whole configuration is read and refused before the database is touched**, which is
[`routes/verify.ts`](../../apps/api/src/routes/verify.ts)' timing control transcribed. The
assertion is on the RECORDER's call list being empty, not on the status codes being equal, because
a check that ran after the read would satisfy "all 503" today and be an oracle the moment a branch
was added below it.

### 3. The answer to the row's question about the other port

**`useCertificateBackend` is NOT wired and the slice does not fix its trap.** The row said saying so
is the correct outcome, and this is it, with the reason narrowed rather than repeated.

Four of its five absences have gone: the signer ([ADR-249](../decisions/ADR-249.md)), the column
([ADR-249](../decisions/ADR-249.md)), the renderer ([ADR-256](../decisions/ADR-256.md)) and **the row
its field addresses answering**, which is this session. The fifth is an ORIGIN, which a deployment
sets.

**What still refuses is not a piece at all.** `projectCertificate` never calls `links` for a
deferred row, so a live read beside a refusing `links` answers by the state of the caller's own
rows. Closing that needs a guard that reads the origin BEFORE the rows, and **a guard is code**, so
[ADR-226](../decisions/ADR-226.md) and [ADR-229](../decisions/ADR-229.md)'s rule does not fire. The
port is **one smaller slice from wireable rather than one variable from wired**. The shape of that
guard is settled in two files and only the writing is owed, which is why it is a slice and not a
ruling.
