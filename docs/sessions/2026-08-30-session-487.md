### 6. Landmines

- **`payout_requests.approved_at` AND `created_at` ARE BYTE-IDENTICAL ON EVERY ROW THIS SCHEMA CAN PRODUCE.** Same type, same `NOT NULL DEFAULT now()`, and neither is written by any file in any `src/` tree. Anyone reading `approved_at` today is reading `created_at` under a more confident name.
- **`status` IS NOT A SUFFICIENT DISCRIMINATOR FOR THIS FIELD AND IT LOOKS LIKE ONE.** `payout_requests_hold_is_complete` NULLs all five hold columns on exit, so **a released hold and a direct approval are the same row**. Any rule of the form "suppress when held" is correct on the state it names and silent on the three other paths where the column lies.
- **ON AN AUTO-RELEASED HOLD THE TRUE APPROVAL INSTANT IS RECORDED NOWHERE AT ALL, TODAY, BY CONSTRUCTION.** [`expiry.ts:190-192`](../../apps/worker/src/sweeps/expiry.ts) writes no `admin_actions` row on purpose, `hold_expires_at` is NULLed by the biconditional on the way out, and `payout.hold_released` has no producer in this tree ([ADR-290](../decisions/ADR-290.md) section 3.4). The operator arm keeps it in `admin_actions.created_at`; the clock arm keeps it nowhere.
- **TWO MERGED FILES SAY *"the repair is a superseding migration's"* AND A READER IN A HURRY WILL TAKE THAT AS A DISPOSITION OF THE READ.** It is a disposition of the WRITE. Neither file projects to a trader and neither ruled the projection.
- **THE BLAST RADIUS OF `0077` IS ZERO TODAY AND IT ONLY GROWS.** Nothing inserts a `payout_requests` row, so the table is empty in every environment and the supersession needs no backfill. **Slice 6 lands the first row that ends that**, and from that day the change acquires a data migration plus a decision about what to backfill for rows whose approval instant was never recorded.
- **`0010:212-213`'s INDEX SPANS THE COLUMN `0077` MAKES NULLABLE.** `(identity_id, approved_at DESC)` sorts `NULLS FIRST` by default, so without an explicit `NULLS LAST` **every held request sorts to the top of a trader's payout list.** Invisible until a trader with a held payout loads a page.
