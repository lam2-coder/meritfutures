### The failure was reproduced before anything was blamed

```
$ git log --oneline -1          # 421e52e, origin/main, no branch involved
$ node --experimental-strip-types scripts/demo/main.ts
Error [ERR_MODULE_NOT_FOUND]: Cannot find module
  '.../packages/rithmic/src/index.js' imported from .../scripts/demo/main.ts
```

**Three things kept that invisible, and all three are working as designed.** The `.mjs` wrappers register [`ts-resolve.mjs`](../../scripts/demo/ts-resolve.mjs), which maps the extension the tolerant way. Vitest resolves the same tolerant way, so both suites in `scripts/demo/test/` were green over a tree the node loader could not load. And `RI-10`, the one check whose entire subject is this defect, was scoped to `src/`.

### The scoping decision was the finding, not the specifiers

Rewriting the specifiers is transcription. The question worth a session was whether `RI-10`'s scope should move, and the answer had to survive the check's own history: its first draft **excluded a package by name**, its own new test cases then tripped it because they carried specifiers inside string literals, and the principled repair was the `src/` line now being revisited. Its header states the lesson it learned: *"A check that needs a name-based exception is usually scoped wrong."*

**So the widening was held to that standard rather than exempted from it.** The scope is two positive terms and one subtraction: `src/` under `apps/` or `packages/`, everything under `scripts/`, minus the segment `test/`. It names no package, no file and no area.

### The simplification that looks free, measured

| Candidate scope | Findings on this tree | Verdict |
|---|---|---|
| `src/` only, as shipped | **0**, and the 19 were sitting there | The state this session ended |
| `src/` + `scripts/`, minus `test/` | **19 across 5 files** | **Taken** |
| Every non-`test/` TypeScript file under `apps/`, `packages/`, `scripts/` | **19 across 5 files**, identical | **Refused** |

**The third row finds exactly what the second finds, so it reads as a free simplification.** It is not. It silently admits `apps/portal/e2e/slop-score.spec.ts` and `apps/site/e2e/slop-score.spec.ts`, which are Playwright specs, which are tests, which ADR-121 ruling 3 puts out of scope. Keeping them out costs a second name in the subtraction, and **a subtraction list that grows by name is the exact failure this check's history is about**. The `src/` clause stays because deleting it moves an exception from the visible side of the rule to the invisible side.

### The check was watched failing, because that is how the last latent bug in it was caught

`RI-10` once shipped with a `relative` used and not imported, a `ReferenceError` that could only fire on a real finding. Seeding is what found it. So the widened scope was seeded on the live tree in both directions before it was believed:

| Seed | Demanded | Got |
|---|---|---|
| `scripts/demo/main.ts` names `./render.js`, where `render.ts` is | **FAIL** | `FAIL RI-10 (1)`, naming file and target |
| The same defect inside `scripts/demo/test/` | **PASS**, ruling 3 | `PASS` |
| A `scripts/` specifier naming a genuine `.js` file | **PASS** | `PASS` |

All three are test rows now. **The first was confirmed load-bearing** by reverting the scope to `apps` and `packages` and watching only that row go red, 1 failed of 65.

### Session 148's landmine was checked one specifier at a time

The blanket `.js` to `.ts` rewrite of session 148 broke [`packages/eslint-plugin-merit/index.js`](../../packages/eslint-plugin-merit/index.js), which is genuine JavaScript. **The rewrite here refused to touch a specifier unless the `.js` target was absent from disk and a `.ts` was present**, and reported per site: 32 rewritten, **0 left ambiguous**. Sixteen would have been small enough to verify by hand; 32 was small enough too.

### The instruction that was refused, and why it was the right refusal

`nightly.yml` carried a standing note: *"WHEN THAT SWEEP LANDS, THIS LINE SHOULD MOVE TO THE `.ts` ENTRY."* This session is that sweep, and the line did not move.

**The instruction's premise was that the broken specifiers were the reason `CI-09`'s replay leg ran `seed-world.mjs` rather than `seed-world.ts`. The sweep disproved it.**

```
$ node --experimental-strip-types scripts/demo/seed-world.ts ; echo $?
0
$ node --experimental-strip-types scripts/demo/seed-world.ts | wc -c
0
```

**Exit 0, zero bytes.** `seed-world.ts` exports `main` and never invokes it; the `.mjs` wrapper registers the hook, wires `argv` and stdio, calls `main` and returns its code. [`run.mjs`](../../scripts/demo/run.mjs)'s own header said so all along: the wrapper is `.mjs` because *"the hook has to be registered BEFORE the first import that needs it, and an import is hoisted above every statement in its own module."*

**Moving the line would have replaced a self-audit that reports with a module-graph load that cannot, and CI would have gone green on it.** That is `FM-17`'s shape, and `seed-world.ts`'s own refusal handling names it: *"an audit that declines to report must never look like one that found nothing."*

**What changed in that file is the comment, and the `run:` line is byte-identical.** The comment had to change because the sentence it carried is now false: it said the directory *"carries 16 specifiers"* and that the `.ts` entry *"dies with ERR_MODULE_NOT_FOUND on this tree"*. Both were true when written and neither is true after this branch, and a stale comment that still reads as true is the drift [ADR-034](../decisions/ADR-034.md) exists to end.

### The same measurement, honestly

`main.ts` runs clean now, and **clean means the module graph loads**. It writes no output either, for the same reason `seed-world.ts` writes none: `run.mjs` is the executable. That is precisely the claim `RI-10`'s `covers` line makes for a green result and no more: *"A green result says the module graph LOADS, and says nothing about whether it behaves."* The behaviour is what the two Vitest suites and `seed-world.mjs` cover, and both were exercised: `node scripts/demo/seed-world.mjs` reports **PASS, the world seeded, the replay reproduced it, and the audit proved it can fail.**
