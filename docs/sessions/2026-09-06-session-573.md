### 4. The one repair this row refused, and the hazard it names

**THE DISPATCH ASKED WHETHER 376's REASON STILL HOLDS. IT DOES, AND THE ROW ADDS ONE.** `expirySweepIo` ([`sweeps/expiry-adapter.ts:193`](../../apps/worker/src/sweeps/expiry-adapter.ts)) takes the sink as a required positional argument with no default. Passing a sink is **WIRING**, forbidden by this dispatch in the same words as the last; defaulting it means the refusing `ExpiryEventPort` that case `6.1` asserts the ABSENCE of.

**AND THE REPAIR IS TWO EDITS RATHER THAN ONE, WHICH IS MEASURED HERE AND WHICH ADR-376's ACCOUNT COLLAPSES.** Seed 6 adds the refusing value alone and the arity pin stays **GREEN**, because a default VALUE is not a default PARAMETER. **Seed 6b adds the default parameter and `expirySweepIo()` becomes callable with no sink**, which makes the freeze expiry sweep's io composable in `src/` for the first time, over a sink that rejects. Every leg of that sweep emits inside its own release transaction, so the result is an hourly job that releases nothing while an **S1** dead-man switch watching for its ABSENCE reports it present.

**SO YES: REPAIRING THIS WOULD MAKE A JOB CONSTRUCTIBLE THAT IS NOT OTHERWISE CONSTRUCTIBLE, AND THAT IS A REASON FOR CARE RATHER THAN A REASON TO PROCEED QUIETLY.**

### 5. What the hole's real shape is

**IT IS AN ASYMMETRY BETWEEN TWO READINGS OF ONE NAME.** `unwiredPorts` INCLUDES on the `UNWIRED_` prefix; `constructorsOf` EXCLUDES on the same prefix. One name read with opposite polarity cannot have one direction of error, which is why [ADR-370](../decisions/ADR-370.md) section 9 is wrong in **both** halves: the renamed default is not invisible to both censuses, and the direction is not the safe one. Dropping the prefix removes a port from the safe reading and adds it to the unsafe one **in the same edit**.

**AND THE SILENT CASE IS NARROWER STILL, RE-DERIVED INDEPENDENTLY.** Seed 8 declares a renamed refusal for a port that **already has a constructor** and the suite stays entirely GREEN, which is 376's `10c` reproduced on a different port. **The unsafe census is pinned only over the domain the safe census produces**, and the renamed-default edit moves a port out of that domain, so the two are not independent witnesses.

**NOTHING WAS WIDENED.** No census grammar changed, no checker was opened for writing, and the two grammars were extracted only so `8.3` runs the censuses' own regular expressions rather than copies of them.
