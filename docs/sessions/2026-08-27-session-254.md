### 4. Two more findings, both from the contract meeting the schema

**`POST /affiliate/links` HAS NO TABLE AND `affiliate_clicks` IS NOT IT.** It is the only table in the schema carrying a `click_token`, and its rows are clicks: `clicked_at timestamptz NOT NULL DEFAULT now()`, indexed by `affiliate_clicks_affiliate_time_idx`, which is what `clicks_30d` is counted over. Writing a row when a link is ISSUED puts a click nobody made into that count, once per press of the button, and `AS-M8-03`'s cookie-stuffing arithmetic is a conversion rate over exactly that denominator. So the obvious implementation of this row would arm the detector against the honest affiliate and disarm it against the stuffer. **The route mints no click.**

**`campaign` REACHES NO COLUMN.** `CreateLinkRequest` carries an optional `campaign` and `grep -n campaign packages/db/migrations/*.sql` returns three lines, all three prose in [`0025_reserved_sequence.sql`](../../packages/db/migrations/0025_reserved_sequence.sql). It is validated and handed to the port, and where it lands is the same seam as the finding above.

| Decision | Taken here | Why |

| `landing_path` must be site relative | **yes** | The one validation here that is a control rather than a shape check. An absolute or protocol-relative path would turn a Merit-issued referral link into an open redirect wearing the affiliate's own code, and the affiliate program is the population with the motive |
| An out-of-range `limit` is refused, never clamped | **yes** | A clamp makes a client believe it read a hundred rows when it read twenty-five, and on a statement list that client stops paginating and shows an affiliate part of their history |
| The URL and the click token in `CreateLinkResponse` | **no, the port mints both** | The URL's shape is a protocol between whatever issues a link and whatever records the click, and this tree has no handler that reads a click token off a request. Inventing the query-parameter spelling writes half a protocol |
| Which statement statuses reach a trader | **no, the port's read decides** | A filter here would be this route answering a product question the corpus does not put to it |
