The port declares the return at [`payouts.ts:588-590`](../../apps/api/src/routes/payouts.ts), the route destructures at [`:1201`](../../apps/api/src/routes/payouts.ts) and writes the wire field at [`:1250`](../../apps/api/src/routes/payouts.ts). **Nothing supplies it**: `eligibility_snapshot` in `packages/db/migrations` is two lines, a `jsonb` column and a comment; the two spellings over `apps`, `packages` and `scripts` are seven lines in two files and every one is the port, the route or the port's own test fixture.

**The drift is a half-applied repair rather than an oversight**, and section 1.3 names it: [ADR-285](../decisions/ADR-285.md)'s build added 125 lines to `payouts.ts`, and session 478's repoint pass moved F2's first citation **by its start only**, turning `564-566` into `588-566`, a backwards range.

### 4. The ruling

[ADR-289](../decisions/ADR-289.md) section 3. **The contract moves.** The three refused shapes are priced with reasons rather than dismissed.

**The strongest argument against returning `payout_requests.id` is not that the value duplicates a field.** It is that [`payouts.ts:1168`](../../apps/api/src/routes/payouts.ts) generates the id with `randomUUID()`, [`:1172`](../../apps/api/src/routes/payouts.ts) hands it to the insert, and [`:1238`](../../apps/api/src/routes/payouts.ts) returns it. **The port would return its own argument to a caller that already holds it in a local.**

**And the removal breaks no client**: `usePayoutBackend` is `BLOCKED` and the live count assertion reads `{ declared: 24, wired: 10, blocked: 14 }` ([`wiring.test.ts:1402-1409`](../../apps/api/test/wiring.test.ts)), so nothing has ever served this field with a value a fixture did not invent.
