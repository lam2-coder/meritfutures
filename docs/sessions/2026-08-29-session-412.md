**That the carve-out is empty is the finding that matters.** The API sends no
CORS header at all, so a cross-origin `fetch` was never the vector: **the
vector is the plain HTML form `POST`, which is CORS-simple and needs no
preflight**, and which `Lax` permitted from the marketing origin.

### 2. What was ruled

**The `Origin` check, considered first as the row ordered, and taken.** It
needs no token, no state and no client change, and `ADR-219`'s own standard is
that a token nothing checks is not a control. The converse is this session's:
**a token this check makes redundant is a second copy of a control rather than
depth.**

**One mechanism.** A `Sec-Fetch-Site` check would call the marketing origin's
forged write `same-site` and admit it, which is the gap. A minted token refuses
exactly the same set and cannot be reached by the portal's server-side caller.
**A second mechanism that catches nothing the first does is the second-copy
defect, and one that admits the gap is worse than that.**

**Cloudflare is the wrong layer for this control and the ruling says why in two
grounds**, the first of which the row named: `INFRA` rules no origin lock, so a
direct-to-origin request bypasses the edge; and an edge rule is invisible to
every gate here, to `vitest` and to the founder's `E2` read.

### 3. What was refused

- **A minted token**, on a count rather than on caution.
- **A second mechanism of any kind.**
- **A `/webhooks/*` path exemption**, which is a bypass list. The cost is
  priced in `ADR-221`'s founder block rather than hidden.
- **A cookie-presence gate**, which would miss login forgery.
- **An environment-variable origin allowlist**, which would need a hostname
  [ADR-012](../decisions/ADR-012.md) keeps out of this repository and an
  `INFRA` edit this fence does not hold.
- **A new canonical error code** and **a `required_factor`** on the `403`.
- **`MERIT_BUILD_MASTER_PROMPT.md`**, which is frozen.
- **Any migration number.** The control holds no state, so **none was minted
  and none is owed.**

### 4. The fence, extended twice, both declared

**`SECURITY.md` and `API_CONTRACT.md`** on the row's own condition: a caller
that sends a mismatched `Origin` gets `403` and no handler runs, which is a
contract fact a caller must satisfy and which no other sentence in the corpus
carries.

**`apps/portal`, which the row forbids twice**, on citation-repair rights the
dispatch granted up front. It was **not avoidable**: `ADR-219` section 8 built
a guard to go red on exactly this slice and it fired on the first full run. The
repair keeps the guard live and points it at the invariant that still matters,
which is that the API's control reads **no token**, so the portal is still told
if it ever becomes the missing half. Separate commit.

### 5. Landmines

- **`inject` normalizes nothing for you.** A `Host` of `localhost:80` and an
  `Origin` of `http://localhost:80` do not compare equal through `URL.host`,
  because port 80 is default for `http` and is stripped from one side and not
  the other. Comparing `hostname` avoids it and is also the correct boundary;
  comparing `host` would have shipped a check that passes in tests and refuses
  the deployment, or the reverse.
- **`new URL('http://trusted@attacker')` reads `attacker`.** The `Host`
  delimiter check has to run **before** the parse or a header of
  `trusted-host@attacker-host` resolves to the attacker's half under a name
  that reads as the trusted one.
- **A header insertion moves every line citation below it in the file, and in
  every other file that points at one.** `RI-15` caught two here. Derive
  pointers last, after the final edit to the file above them.
- **`DISPATCH_PROTOCOL` section 4's invariant row still reads 18 against a
  runner reporting 19**, and is now eight sessions behind. Still outside every
  fence, reported again.
