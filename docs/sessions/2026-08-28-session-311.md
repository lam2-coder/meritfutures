**`D-11` is the one detector in this file whose join crosses ROWS rather than reading one**, the runner

threshold and no other identity"* -- so the sibling's account id is evidence the graph holds and not a

### 8. Findings reported and not repaired

1. **`sla_hours` has no row in the registry** and `OQ-M7-03` is open. Section 3. It blocks `D-09` and
   `D-16`, the only two whose severity `M07` states, and any future severity 4 or 5 detector.
2. **`payoutRequests` is not a member of `DETECTOR_READ_TABLES`**, so `D-09` cannot resolve
   `destination_ref` to an identity. This is `DEP-M7-04` arriving exactly where that row said it would.
   **It is NOT an accessor argument**: both tables are already `TableKey`s, `payout_requests` is already
   `owned`, and a detector reading both and joining in the runner is the shape
   [ADR-157](../decisions/ADR-157.md) section 5 granted. **The remedy is one member in
   [`ports.ts`](../../apps/worker/src/detectors/ports.ts)**, which is `P7-e`'s fence and not this one's.
3. **`canary.ts`'s `sharedDestination` mints `identityId` onto a `payoutTransfers` row and that column
   does not exist on that table.** The battery was written for the join the read union does not allow,
   which is finding 2 from the other side. Asserted against `schema.ts` so it cannot drift quietly.
4. **`CANARY_SHAPES` is a closed union of four and none of them is an identity-side shape.** Five of this
   file's batteries carry the nearest label, `shared-destination`, and say so at the site.
5. **A filter is ONE VALUE PER COLUMN, ANDed**, so `atLeast(a)` and `atMost(b)` on the SAME column cannot
   both appear in one `rowsWhere` call. [`ports.ts`](../../apps/worker/src/detectors/ports.ts) reads
   [ADR-157](../decisions/ADR-157.md) as granting `D-01`'s two-second window as a two-sided range, and a
   two-sided range on one column is not expressible through this filter. `D-11`'s marks window is
   one-sided and its upper bound is applied in memory; `D-01` is `P7-f`'s and will meet the same limit.
6. **`risk_flags.flag_type` has no vocabulary member for `D-09`, `D-11`, `D-16` or `D-18`**, and the
   column has **no `CHECK`**, so an invented value would insert and become the vocabulary by having been
   written. Those four read `flag_type` from their registry row and refuse when it is absent.
7. **`identity_links.link_kind` has no `CHECK` either**, which is why `D-16` reads the confidence ceiling
   rather than the kind: `INV-M7-01` names the ceiling as the discriminator, and a `link_kind` allowlist
   would be a vocabulary this file chose over the one the invariant names.
