### 1. The measurement, which is the entry's subject

**[ADR-212](../decisions/ADR-212.md)'s precedent is binding and it was followed
literally: every candidate was executed rather than argued.**

| Candidate | `RI-14`'s 3 files | 280 shipped `.ts` | 987 `docs/**.md` |
|---|---|---|---|
| **C1** `RI-14`'s shapes, name set widened to schema objects | **0** | **0** | 14 |
| **C3** absence phrasings over declared schema names | **0** | **26** (1 real, 25 honest) | 67 |
| **C4** any backticked snake_case token near a negation | **13** | **763** | 5,682 |
| **C2** a quoted command with a stated result is EXECUTED | **1** | **0** | 26 |

**C1 is the result worth keeping.** The obvious fix -- hand `RI-14` the column
names -- changes nothing at all, because the entry's three false clauses are an
anaphora (*"NONE of the three"*), a quoted grep, and a claim about the MEMBERS of
an exported union. **A session that had gone straight to it would have shipped a
check, watched it pass, and left the defect where it was.**

**C3's 25 false positives are the argument.** Every one names a real schema
object, says "absent", and is true -- because it is about a registry, a response,
a directory or an interface. **No rule over English recovers that**, so the rule
is not a name matcher.

### 2. The check caught its own repair, and that made a clause

The first draft of the rewritten header quoted the false sentence verbatim, in
live backtick-plus-result grammar, and `RI-20` failed it. **That is clause 5
being discovered rather than assumed.** `RI-14` lets a block quote a false
sentence when it marks it as history and that is right, *because a name is
inert*. **A command is not.** The sentence now reads *"a recursive grep for
lifetime_settled over the migrations directory returned nothing at all"* -- the
same claim, out of the shape that says run me, which is [ADR-212](../decisions/ADR-212.md)'s
rule for `file:line` pointers applied to a command.
