configuration, and turn each absence into something explicit and checkable
rather than a sentence in a test file.

**Outcome.** **One of the three was configuration and it is wired. The other two
were not, and saying which is which is the deliverable.** The number is spent
because the ruling was made three times, not because three ports moved.

### 3. What was ruled

**The horizon is an environment variable and no number lands here.**
[ADR-146](../decisions/ADR-146.md) clause 7 refused to invent the VALUE and that
refusal is untouched; what lands is the NAME.

**`stale` is a count of sessions and never a date comparison**, which is what
keeps [ADR-146](../decisions/ADR-146.md) clause 4 intact. Section 3 of the entry
carries the argument and the alternative it was taken over.

**An unwired port is a 503 and never a 500 on this route**, and an
`EconomicCalendarError` is still a 500.

**The URL signer does not belong in `apps/api`**, and naming a variable would
close the origin and neither of the other two missing things.

**One half of the card is configuration and the other is not**, so
`cache_max_age_seconds` is not named while the bytes beside it have no producer.

### 5. Landmines

- **A SIGNED URL AND A ROW THAT TAKES NO QUERY CANNOT BOTH BE SATISFIED, AND
  BOTH ARE IN ONE APPROVED DOCUMENT.** Section 6 types `image_url` as *"signed,
  time-limited"* and section 6.3 says the image row takes *"the path token only,
  no query, no body"*. Every reader of either row alone has been reading a
  consistent document. **The contradiction is only visible with the two rows
  side by side**, which is how it survived [ADR-168](../decisions/ADR-168.md)
  admitting both.
- **`db.test.ts` PINS THE `@merit/db` IMPORT MAP PER FILE**, so taking `atLeast`
  and `atMost` in a route module is a red test until the map records the
  decision. That is the control working, and the entry it produced says why
  neither name opens anything.
- **THE RECORDER ANSWERS EVERY `rows` CALL FROM ONE ARRAY.** An adapter reading
  three tables tested against it would agree with its own fixture about which
  table it read. The local fixture answers by key for exactly that reason.
- **A PROBLEM DOCUMENT CARRIES A PER-REQUEST `instance`**, so comparing two
  refusal bodies byte for byte fails on the request id and on nothing else. The
  case drops that member and asserts the rest.
- **A TEST THAT GREPS THE TREE FOR A NEEDLE CONTAINS THAT NEEDLE.** Session 424
  recorded the same class. Here it is avoided by scoping the sweep to `src`
  directories, and the exclusion is stated in the helper rather than assumed.
- **`useCertificateRevokeBackend`'s ENTRY STILL CITES `certificates.ts` LINE
  NUMBERS THIS BRANCH DID NOT MOVE**, and the two certificate entries this
  branch does touch were repointed by hand. Nothing checks a `file:line` inside
  a `BLOCKED` string, which is `RI-16`'s scope boundary rather than a gap in it.

### 8. Next, and blockers

**The economic calendar panel is served end to end and its threshold is the
deployment's.** What it owes is a check that the panel and the alarm read the
same value, and nothing in this tree can make one because the alarm is not in
this tree.

**The certificate card is the next real slice and it is [M11](../plans/M11-certificates-social-proof.md)'s.**
It needs three things and they arrive together: a renderer, a place for the
bytes to live, and a signer at whatever serves them. `certificates` holds no
image location column for any of them to address, so the slice starts at a
migration. **Two ports move the day it lands** and both now have a test that
goes red when it does.

**No blockers.** The half this fence held is ruled and wired, and the half it
did not is named with its fence and its argument.
