### 3. The method, which was the point of the session

Every absence in the review states the scope that produced it. Whole-repository
searches are written as
`. --exclude-dir=node_modules --exclude-dir=.git --exclude-dir=reviews`, the
third exclusion being the review's own directory **so that no count in it can be
satisfied by the sentence asserting it**. That is `RI-20`'s stated principle
applied to a document `RI-20` does not read.

The distinction that did the work is **absent from the tree** versus **absent
from the deployment**. [`INFRA`](../architecture/INFRA.md) puts Cloudflare in
front of every origin and scopes secrets per service in a platform vault, and
there is **no infrastructure-as-code in this repository at all**, so four rows
carry a deployment half nothing here can settle. An honest *"discharged at the
edge, unverifiable from this repository"* is a better row than a false
*"missing"*, and four rows take it.

### 4. Landmines

- **A grep for a header spelling is not a grep for a control.**
  `Content-Security-Policy` is genuinely nowhere and `CSP` is in seventeen
  files. The finding lives entirely in the gap between those two searches.
- **`INV-M6-02` is a module INVARIANT, not a comment**, and it asserts an origin
  separation *"even in principle"* on a header nothing sets. A binding invariant
  is a stronger false claim than a source comment, which is why the review ranks
  `D2-8` above `D2-4` and says so as the thing worth a founder's disagreement.
- **Four of the five `zod` citations are correct quotations.** Repairing the
  comments would leave the defect exactly where it is, in two migrations and two
  approved documents. **The repair site is an ADR, not a source file.**
- **`.gitignore` has no `.env` entry** and `INFRA` section 7 says it does and
  says CI verifies it. Both halves are false and neither is expensive to fix; it
  is deliberately not fixed here, because the fence is `docs/reviews/`.
- **`otp_send_budget` already models `('phone','ip','country','global')`.** The
  hard half of `D2-6` -- deciding the scopes -- is done, and it has no reader
  because `requestOtp` is blocked on delivery.
