### 5. Where this session is most likely wrong

**THE REFUSAL DESIGN ASSUMES THE TRADER HAS SOMEWHERE ELSE TO READ THE ROW'S STATE, AND THEY DO
NOT.** `conflict` names the machine and never the row, deliberately, so that an id naming nothing
and an id naming somebody else's row cannot be told apart. **Section 6.2 declares `GET /wallet` and
`GET /wallet/entries` and no read of a withdrawal at all**, so today a trader refused here has no
screen that says why. The row that lands the trader-facing read should re-open that paragraph.

**THE FACTOR IS A JUDGEMENT AND NO TEST SETTLES IT.** `passkey or dual_channel` on the release is
defended by the fact that the same factor gates the request, and the counterfactual costs a delay
an attacker with a stolen single-factor session can impose. It is one field either way.

### 7. Landmines for the next session

- **A COMMENT THAT IS TRUE OF THE NEIGHBOURING ARROW IS THE HARDEST FALSE SENTENCE TO SEE.** The
  suite's *"`0072` refuses leaving a terminal status, so a re-cancel would be refused at the
  statement"* is correct about `cancelled --> requested` and false about `cancelled --> cancelled`,
  and both halves are one word apart. **A trigger's `WHEN` clause is where this class hides**: read
  it before believing what the trigger body refuses.
- **`RI-15` FIRES ON INSERTIONS NEAR THE TOP OF A FILE OTHER FILES CITE.** Two constants added at
  `wallet-withdrawals.ts`'s head moved three live citations. **Derive pointers last**, which
  [ADR-232](../decisions/ADR-232.md) said and this session still paid for.
- **`RI-17` IS THE ONLY THING BINDING A ROUTE TO ITS CONTRACT ROW**, and it lives in
  `apps/api/test/` rather than in `repo-invariants.mjs`, so it runs in `CI-02` and a change that
  skips the test run is not refused by it.
- **A LOCAL POSTGRESQL NEEDS THE `postgres` USER.** `initdb` refuses to run as root and this
  container is root: `mkdir /tmp/<dir> && chown postgres:postgres`, then `su postgres -c
  '/usr/lib/postgresql/16/bin/initdb ...'`, then `pg_ctl -o '-p 5433 -k /tmp'`.
- **`pnpm vitest` IS NOT A SCRIPT IN THIS WORKSPACE.** `npx vitest run` or `pnpm test`.
- **DEPENDENCIES ARE NOT INSTALLED IN A FRESH CONTAINER.** `pnpm install` first.
