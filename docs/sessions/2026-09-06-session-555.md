| question | answer |

Full argument in [ADR-360](../decisions/ADR-360.md). The three findings worth carrying:

**THE INTERFACE HAS ONE MEMBER, SO THE QUESTION THE ROW WAS SENT TO ASK DISSOLVES.** ADR-356 ruled a half-install worse than none by measuring `200/500` against `503/503`. That needs two members. **This port cannot present a live arm beside a refusing one**, and its `null` default cannot return a plausible value at all.

**THE INSTALL'S HARM RUNS THE OPPOSITE WAY FROM THE ONE ANTICIPATED.** It is not that a wired port would answer something false. It is that it would answer **exactly what it answers now**, while deleting the only place the deployment's incompleteness is written down at run time.

**THE COUNT DISCREPANCY IS OWED.** Two live figures in `wiring.test.ts` say the SSO purchase blocks six entries; a live predicate in `admin-read-constructibility.test.ts` derives eight and agrees with ADR-312. The file belongs to a sibling this wave and was not touched.

### 6. Landmines for the next session

**THE HARNESS REFUSES TEST RUNS WHILE A TRACKED `src/` FILE IS DIRTY.** Reproduced four times this session and cleared the moment the file was restored byte-identical. **Source-mutation falsification is therefore not available in this environment**, and a row that needs one should say so rather than quietly skip it. Untracked new test files do not trigger it, and seeding a test's own expectations does not either. **The `cd`-prefix diagnosis that arrived mid-session is WRONG and is recorded here so it is not inherited**: the one successful run had a `cd`, and a bare invocation with no `cd` and no path argument was refused.

**`RI-15` IS EASY TO TRIP WITH AN HONEST CITATION.** Pointing at the line that *does the thing* fails when the sentence names a common word near it. Point at the declaration and say where in the body the statement sits.

**THE VACUITY IN SECTION 5 IS THE GENERAL SHAPE, NOT A ONE-OFF.** `adminHandler` reads the cookie before consulting the session source, so any case that installs a source and sends no cookie tests a path that never reaches the port. Assert the call landed.
