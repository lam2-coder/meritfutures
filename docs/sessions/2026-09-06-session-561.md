### 6. Falsification

**Eight seeds, every one watched RED and every one restored byte-identical.** [ADR-366](../decisions/ADR-366.md) section 11 carries the table. Three worth keeping here:

- **Seed 7 is the dispatch's own stop condition, tested.** Making the unwired `principal` resolve an owner rather than reject turns `operator` into a consulted member and reddens the case that says no write-capable member is reached. **The claim that no write path is reachable is therefore held by something that fires.**

### 8. Blockers and landmines

- **The `E2` read of [ADR-366](../decisions/ADR-366.md) is owed.** Money path: this is the admin wallet route. Its approval block names three decisions, the first of which (may the spend-limit endpoint and the correction endpoint become installable separately) is the one the finding creates.
- **OWED TO THE SIBLING HOLDING `apps/api/test/wiring.test.ts`, which was NOT touched.** The `useAdminWalletBackend` entry gains a **fourth** blocker, `operator`, and *"TWO METHODS THAT WIRING DOES NOT REACH"* becomes THREE. **`blocked: 14` does not move, `DEFAULTS` does not move, `LIVE_DEFAULT` does not move and `{blocked: 14, refusing: 13, live: 1}` does not move.** ADR-366 section 10 states each of the five precisely enough to be picked up.
- **LANDMINE: `AdminWalletUnwired` says it is answered as 503 and this deployment answers 401 to every request on every route.** The sentence is true of the class and of four of the five members; it is true of no request this deployment can receive. **It was not edited**, because it is accurate about the class and repairing prose is a money-path `src/` change this row had no other reason to make, which is the disposition ADR-362 took on the equivalent docblock in `checkout.ts`.
- **LANDMINE: nothing in this module gates on `identities.status`.** An admin correction against a `closed` or `restricted` identity is refused by nothing here. **`INV-M20-06` does not reach this surface** and that is ruled; whether such a correction should be refused anyway is a business question ADR-366's approval block asks and this row declined to answer.
- **LANDMINE: the interface slicer's member regex is a CLOSED SHAPE.** It reads method signatures at a two-space indent. A member written as a property holding a function type would be missed by the slice and caught only by the second measurement disagreeing with it, which is the direction the error should run and is still a cost.
- **LANDMINE: `csrf.test.ts` flakes on the base**, per [session 554](2026-09-06-session-554.md) section 7. **It did not present in either full run here**, both of which were clean.
