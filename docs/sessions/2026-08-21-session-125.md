### `OQ-F6`'s evidence was wrong, and the conclusion was right anyway

**`W8` recorded that `OQ-F6`'s only definition sites are table rows in [session 94](2026-08-20-session-94.md)'s log. They are in [ADR-067](../decisions/ADR-067.md)**, the entry that raises the question, at lines 251 to 253; the log carries a second copy and the copy is a citation. **The survey's own table said `docs/decisions` all along** and was read past.

**The conclusion still held, for a reason the evidence did not name.** An ADR is a registry ENTRY under [ADR-043](../decisions/ADR-043.md), and section 1 admitted only *"a corpus document or a package README"*. So the ruling really did have no register for a series it ruled in scope. **Two ways out and both are taken**, because either alone leaves the series unreadable:

- **Section 1's register class widens to a document that BINDS and can be REPAIRED.** A corpus document, a package README, an ADR-043 registry entry that binds, or a directory of them. **Never a session log and never a review record, and the two exclusions have one reason between them**: a session log is never amended, so a defect inside one can only be contradicted by a later log and the pending entry naming it could never close. A review record binds nothing by existing, which section 1 already said.
- **A table row is a row wherever it sits on the line.** `ADR-067`'s open-question table is **indented two spaces** inside its `- **Open questions for the founder:**` list item, and the gate's row test is `line.startsWith('|')`. **A parse anchored to column zero reads three perfectly good rows as prose.** Nothing in the ruling ever said a row starts at column zero; the runner narrowed it silently, which is the class session 115 itself warned about in its NUL-byte landmine.

**Measured before ruled.** Relaxing the row test over the whole declared scope adds **no site anywhere except the three it was written for**, across 1,084 members. It cannot create a double it does not also fix.

### A deliberate gap and an accidental one are different, and the ruling now says so

**`P-M6-11` is not a hole.** [Session 112](2026-08-21-session-112.md) records the decision in terms: *"a `P-M6-nn` written in application code is a claim on a series with no allocation table, made from a fence that cannot add the row to the document that owns it, which is `ADR-034`'s condition exactly."* The code cites `AS-M6-04` instead and its roster carries the eleventh number with the reason beside it.

> **A WITHHELD MEMBER is an identifier of an in-scope series that a recorded decision declined to mint.** It is excluded from its series' membership and the series stays IN SCOPE.

**It is DECLARED, never inferred**, in a third table beside the two the gate already carries, on the same terms section 2 demands of both: a closed list, one argued entry each. **It fails in both directions**, so it cannot become furniture: an identifier in it that has acquired a definition site is a finding, because the decision was reversed and the table was not told; an identifier in it that no longer appears anywhere is a finding, because the reason went with it.

**The trap here is the fix that looks cheaper.** Stopping the census at the corpus boundary would take `P-M6-11` out **by accident rather than by decision**, which is the whole distinction; it would take `OQ-F6`'s three members with it, since they live in an ADR entry; and it would not even work, because the session registry README is a corpus document and carries the number in its row. Measured, not assumed.

### Eight series that are named nowhere are not eight series

**Section 5's first pending class said 18 and named 10.** The tree offers **twelve** candidates that could be argued into the description, so reaching eighteen means picking eight of twelve on a session's authority. **The class is narrowed to the ten it names**, 156 members.

**An arbitrary eight would be a worse artifact than an honest ten**, and the reason is what a pending entry is for: it names one real defect and the repair that ends it, and it fails the day it stops naming one. Eight entries chosen to satisfy a total name neither, so they could never fail and would be furniture on arrival. **Nothing is exempted by this and nothing is repaired by it.** Any of the twelve joins the class with its own argument, which is the standard the ten met.

**Two member figures in the same paragraph were corrected against the survey rather than adjusted to fit**: the ten named hold **156** and not 190, the third class's six hold **20** and not 29, and the `OQ-M*` class's *"~100"* is exactly **105**. **A tilde in a count a gate is asked to reproduce is a target nothing can hit.**
