### 1. The objective

Derive the population of what depends on a file instead of widening a definition again, cover every kind the last three rows found, state plainly which kinds the instrument cannot see, watch it fail on a seeded dependant of each kind before making it pass, and report what it says about `apps/api/src/events.ts`. **Not to retire the compatibility module**, which three rows have attempted and two refused with measurements.

### 2. Done

- **`packages/tooling/checks/dependants.mjs`**, a derivation with a CLI and no exit code. Five kinds in a written `KINDS` register, seven entries in a written `BLIND` register, an `undecided` list of what it saw and could not resolve, and a `closure()` behind an opt-in `--hops=`.
- **`packages/tooling/test/dependants.test.ts`**, **43** cases. Each kind is seeded into a tree built for it, and one case reads `KINDS` against the set of kinds the seeds actually witnessed, so a kind with no detector and a detector with no entry are both RED.

### 3. Refused, and not attempted

- **The retirement.** Forbidden by the row and not attempted. Nothing under `apps/**` is in the diff.
- **Making this a gate.** It reports and does not judge. A gate needs a policy about what may depend on what and this tree states none; ADR-422 section 13 puts that decision to a founder rather than taking it.
- **Repairing anything the measurement reddened.** The worktree was removed; the working tree's copy of the subject file was present and unchanged throughout.
- **Narrowing `path-literal` to literals a runner then opens.** It would need to decide which reads are reads, and a kind that decides is a kind that can decide wrong silently. The false positive is recorded instead, in ADR-422 section 8.

### 6. Landmines

- **A DEFINITION ARRIVED AT BY WIDENING IS ALWAYS ONE KIND SHORT**, and the kind it is short of is the one nobody has been hurt by yet. Three rows in a row proved it. **Derive the population and write down what the derivation cannot see.**
- **A SHORT `sites` LIST IS NOT A COMPLETE ONE.** Read `undecided` and `BLIND` too. The module prints all three on every run for this reason.
- **`enumeration` REPORTS REACH AND NOT RETENTION.** On `apps/api/src/events.ts` its precision against the red set is **1 in 18**: the walks genuinely reach the file, none of those assertions happens to be sensitive to it today, and an insensitive assertion becomes sensitive the day somebody counts instead of filtering.
- **A FIXTURE THAT SPELLS A LIVE PATH IS A DERIVED DEPENDANT OF IT.** This module's own first suite made it report 59 path-literal sites where there are 9. Fixtures here use `apps/lantern/**` and `packages/alpha*`, which no tracked file uses.
- **A CONFIG GLOB FIRES ON A MOVE AND NOT ON A DELETION**, silently, by dropping a file out of typecheck, lint and format with every gate still green. Nothing in this estate has ever looked, and ADR-410 performed exactly that operation.
- **THE CLOSURE MUST NOT FOLLOW AN ENUMERATION.** A walk makes every file under a directory a first-hop dependant of every other one, so one composing step returns the tree.
- **`vitest.config.ts` COMPUTES ITS INCLUDE LISTS** through `.map` over a `SOURCES` array, so nothing in this tree can currently say which files it reaches. It is reported UNDECIDED on every run rather than silently absent.
