### 1. The objective

Decide the write-path question on ONE family with the argument written down, and either take it or refuse it. Re-derive [ADR-299](../decisions/ADR-299.md) section 5.1 item 5 and `ADR-112` foreclosure 4 and say whether they govern the write path as they govern the read path. If taken, delete a hand-written mapping and deal with `breaker-adapter.test.ts`'s verbatim assertion explicitly per `RI-14`. If refused, refuse with the measurement: what would have changed, what it would have bought, and which ruling or which absent evidence stops it. **Keep every runtime check either way, and stop on any finding that would let a non-integer reach a `*_cents` column.**

- **The base reproduced at `f2398953`** on a clean tree before the first edit, and **it is green**: gates **33 of 33**, invariants **35 of 35**, suite **341 files / 8,290 passed / 11 skipped / 0 failed / (8,301)**, typecheck, lint and `format:check` clean. [ADR-430](../decisions/ADR-430.md) section 2's load-dependent flake did not reproduce, on a 75.75-second run, which is that entry's own diagnosis confirmed rather than contradicted.

### 5. Landmines

- **FOUR DOCUMENTS TELL A NARROWING SESSION THAT NOTHING COMPARES A `schema.ts` TYPE AGAINST THE DDL, AND A COMPREHENSIVE COMPARISON EXISTS.** Two of the four are in the file such a session reads first. The cost is not that the sentence is wrong; it is that the next row's argument for keeping a guard gets built on the wrong reason.
- **THE RIGHT REASON IS NARROWER AND IS THE ONE TO CARRY FORWARD: THE DEFAULT IS NOT COMPARED ANYWHERE.** It is deliberately cut off the DDL text before the comparison runs. **337 columns carry one and 12 of them are `*_cents`.**
- **A CONTROL THAT READS A RETURN TYPE DOES NOT WATCH A PARAMETER.** `breaker.test.ts:1298` stays green under a values-only narrowing, measured. Any case in this corpus asserting a signature by one of its halves has the same defect.
- **NARROWING A VALUES PARAMETER MAKES A KEY-CAST CASE UNEXPRESSIBLE.** `DeclaredInsert<never>` is `never`, so `INV-M5-12`'s two refusal cases would each need a second cast. A row that met that by loosening the case rather than by paying for the cast would retire the control that proves the breaker cannot write a payout.
- **`live_account_state` HAS THREE `*_cents` COLUMNS AND IS TRANSCRIBED NOWHERE.** Fail-closed today, because a table `schema.ts` does not name is a table no accessor can address. It stops being fail-closed the day somebody transcribes it without reading its GENERATED column.
