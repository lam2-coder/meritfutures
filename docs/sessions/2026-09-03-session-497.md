### 1. The objective

Clear `CI-05 security static`, which was red on `main` and on every open pull request and belonged to none of their diffs.

### 2. What was done

`package.json`'s one `pnpm.overrides` entry moves `typed-rest-client>qs` from `6.15.3` to `6.16.0`; `pnpm-lock.yaml` regenerated by `pnpm install`. The `//pnpm.overrides` rationale beside it is rewritten, because it argued for `6.15.3` in the retired advisory's own words and had become a live recommendation of a vulnerable version.

**None reached.**

### 5. Landmines

- **A VERSION PIN IS A REMEDY WITH AN EXPIRY DATE NOBODY WRITES DOWN.** `6.15.3` was correct when chosen and became the vulnerability when two advisories published against the range containing it. **No `RI-nn` can hold this**: the property needs a live advisory database, which is `CI-05`'s job and already runs. What failed was the READING of a red check on a stale base, not the check.
- **`CI-05` GOING RED WITH NO COMMIT IS NORMAL AND WILL RECUR.** A base branch's last green run is evidence about the day it ran and nothing else. Reproduce on the base before concluding a failure is a branch's.
