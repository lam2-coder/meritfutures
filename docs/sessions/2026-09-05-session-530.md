- **A LINE-NUMBER CITATION INTO `gates.mjs` DRIFTS TWICE IF YOU REPAIR IT TOO EARLY.** [`data-model-columns.mjs:62-63`](../../scripts/corpus/data-model-columns.mjs) cite `EXIT` and `runGates` by line. - **`SPAN_QUERIES` HAD NO TEST OF ANY KIND BEFORE THIS ROW.** `grep -rln "SPAN_QUERIES\|adr_registry\|m06_delta_count"` over every `.ts`, `.mjs` and `.js` outside `node_modules` returns exactly one file, `gates.mjs`.
