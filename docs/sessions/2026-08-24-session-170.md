#### 4.1 Why the console itself is not a slice

**Two preconditions, neither of them in M21 and neither in any phase's contents**, which is [session 143](2026-08-23-session-143.md)'s finding recurring one module later.

1. **`apps/api` has no router.** It has `surface.ts`, which chooses a route set at startup, and `index.ts`. There is no HTTP server and no route registration, so all five endpoints have nowhere to be declared. Naming a route in API_CONTRACT does not create one.
2. **No ruling names a front-end technology.** [ADR-083](../decisions/ADR-083.md) made the API its own deployable and ruled nothing about a UI. A session that picked one would be taking an architecture decision from inside a build fence.

**Scheduling the console before either exists would produce a slice whose first act is an unwritten ruling**, which is the shape `M21` itself refuses in seven places.
