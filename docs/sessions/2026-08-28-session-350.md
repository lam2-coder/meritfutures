### 3. Eight states, not two

| | Deployment | Request | Answer |
|---|---|---|---|
| **A** | nothing composed | no cookie | **401** `unauthenticated` |
| **B** | nothing composed | a cookie | **500** `internal_error` |
| **C** | session composed | a token it does not know | **401** `unauthenticated` |
| **D** | session composed | a session that is not an operator | **403** `forbidden` |
| **E** | session composed | a role the contract does not declare | **403** `forbidden` |
| **F** | session composed, **read source not** | an admitted operator | **500** `internal_error` |
| **G** | both composed | the handler threw | **500** `internal_error` |
| **H** | both composed | no row | **404** `not_found` |

**A IS THE ONLY STATE A DEPLOYED CONSOLE CAN REACH.** Nothing in `apps/`, `packages/` or `scripts/` calls `setAdminSessionSource` outside a test, measured by a comment-stripped sweep that is now a case, so no deployment can mint the cookie and the 500 needs a caller who fabricated one. **F was in no document**: a slice that lands a session source moves every route from B to F and changes nothing an operator sees.

### 4. Why the 500 stays, and it was executed rather than argued

**Two experiments, both reverted, tree clean after each.**

| Experiment | Result |
|---|---|
| `AdminReadError` gains `readonly statusCode = 503` | **44 of 44 cases still pass and the wire answer is still 500.** `STATUS_CODE` has no 503 key |
| the same, plus `STATUS_CODE` and `TITLE` given their `service_unavailable` entry | **12 cases fail across 2 files** |

**The second experiment is the ruling.** Four of the twelve are the ones that decide it: a float in a cents field, an inverted flag queue, an evidence pack whose digest is not a SHA-256, and a float in a `_bp` field on the breaker's surface. **`AdminReadError` is not the wiring class.** Fifteen throw sites, two of them *"no source is wired"*, one an endpoint declaring no role, and twelve refusing the DATA a wired source returned. A 503 answers *try again shortly* to every one of the twelve, and retrying reproduces them.

**What would make a 503 right is a second CLASS rather than a second status**, and that is registered as ADR-190 section 7 item 2 rather than taken on an unsigned ruling.

### 5. The console rule, and why the obvious repair was refused

**Correcting `toAdminErrorKind(503)` to `toAdminErrorKind(401)` was considered and refused by name.** The home route performs no read. A page naming 401 because a suite measured 401 is still a page asserting a status it did not receive, and it goes stale in a file nobody is looking at the next time the answer moves.

**The rule is about provenance:** an `AdminErrorKind` is derived from a response this console received. `http/client.ts` computes it from `response.status` and pairs it with that status in `AdminApiFailure`; a constant cannot be traced to anything. `W6-f` and `W6-g` shipped under it before it was written down, and `M6-A-60` is what makes the fourth screen inherit it instead of needing the same judgement again.
