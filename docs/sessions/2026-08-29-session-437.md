### 2. The three findings, in the order they matter

**1. `apps/api/src/routes/checkout.ts` IS HOW MERIT TAKES MONEY AND NO ENTRY IN THIS CORPUS ARGUES
IT.** `git log --first-parent --diff-filter=A origin/main -- apps/api/src/routes/checkout.ts`
returns exactly one commit. That merge's only ADR file is
[ADR-113](../decisions/ADR-113.md), whose five rulings are about a single row for
`POST /affiliate/creatives` in [API_CONTRACT](../architecture/API_CONTRACT.md) section 7.
**662 executable money-path lines are attributed to it**, and the entry has said so about itself
since 2026-08-26: *"MONEY PATH by position rather than by content ... The `E2` line-by-line read is
owed on the session, not discharged by this signature."*
[ADR-227](../decisions/ADR-227.md) section 2 transfers an owed read to *"the entry that lands the
diff"*, and **there is no such entry.** Five later entries touch the file and every one rules
something else. **An entry for the handler is owed and is not written here**, because writing it is
a money-path slice of its own.

**2. A MERGED MIGRATION'S OWN LITERAL CAN DRIFT FROM THE CONSTANT THAT IS WATCHED.**
[`0056`](../../packages/db/migrations/0056_eighth_ledger_code.sql)'s seeded row made
identity-scoped leaves **20 of 20 green**; the same change to
[`accounts.ts:75`](../../packages/ledger/src/accounts.ts) turns **8 cases red**. The tree is not
defective and both say `firm`. **The suite holds the TypeScript copy and the migration's own literal
is watched only by a probe that needs a running PostgreSQL**, and a merged migration is never
edited, so a divergence introduced there is permanent.

**3. [ADR-244](../decisions/ADR-244.md)'s HEADLINE DOES NOT REPEAT.** That entry and
[ADR-243](../decisions/ADR-243.md) both found that *"what was missing was the record and not the
control"*. **`grep -rl "0059\|LEDGER-C3" --include='*.test.ts'` returned nothing**, so `LEDGER-C3`,
a trigger refusing a chained reversal on `ledger_transactions`, had no assertion anywhere. It was
watched executing against PostgreSQL 16 once, by the session that wrote it, and nothing re-runs
that. [`packages/db/test/reversal-chain.test.ts`](../../packages/db/test/reversal-chain.test.ts) is
written here, 7 cases, and was watched red three times.
