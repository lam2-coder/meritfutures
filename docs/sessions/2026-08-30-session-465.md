### 1. The objective, and the answer

**Row `274` asked what in this estate still depends on the process timezone after `RI-25`, and required that the answer be established by READING before anything was written.**

The ruling is [ADR-274](../decisions/ADR-274.md), seven clauses, `proposed` and UNSIGNED.

**The answer is nothing, in Merit's own shipped code, and it is a scan rather than a reading** -- because *"I looked and did not find one"* is exactly the claim a scan exists to replace. Six spellings, 356 files, zero.

**The row offered a `TZ=UTC` line in the deployment contract and warned against writing it as a reassurance. The warning is the ruling.** Nothing here can read a deployment's environment, so the line could never be checked; and `TZ` is not a property of the system but an input to a question code asks. **A tree that never asks is correct at every offset.** `RI-26` is that property held tree-wide.

### 2. The five clocks

| # | Clock | Set where | Reads it |
|---|---|---|---|
| 1 | Storage: **UTC** | nothing | every stored instant |
| 2 | The trading day: **CT** | `trading_calendar`, as data | every rule, every payout basis |
| 3 | The process: **`TZ`** | the platform, per service | **nothing** |
| 4 | The database session: **`TimeZone`** | the server | any SQL rendering an instant; `DateStyle` decides every `date` column's wire text |
| 5 | The **scheduler** | the platform scheduler, external | every expected-by time in the cron inventory, all of them CT |

**Clock 4 is not clock 3, and that was measured because the opposite is what a reader would guess.** `libpq` forwards `PGTZ`; `pg` is not `libpq`, and its `getStartupConf` sends neither `TimeZone` nor `DateStyle`.

**The live one is clock 5**, and it is the only one of the five where a careful, plausible setting is wrong.

### 4. The two findings this session added

**THE MULTI-ARGUMENT LEG COUNTS ARGUMENTS AND NOT COMMAS, AND THE SEED THAT SETTLED IT WAS A FALSE POSITIVE ON THE REAL TREE.** The admitted spelling `new Date(Date.UTC(y, m, d))` carries the same commas as the banned one. Counting top-level commas after nesting and quotes are respected still reported [`packages/kyc/src/fakes/provider.ts`](../../packages/kyc/src/fakes/provider.ts) as a local construction, because **prettier writes a trailing comma whenever a single argument spans lines.** A trailing comma is not an argument; that is a permanent case.

**AND THE COMMENT STRIP IS THE SAME LESSON AS [ADR-271](../decisions/ADR-271.md)'s, RUN BACKWARDS.** That entry's `RI-25` reported PASS on a restored defect because a comment satisfied a presence check.
