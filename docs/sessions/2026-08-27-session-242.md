- **Objective:** replace `M06`'s hand-maintained delta count with a `<!--gen:-->` span, which is the remedy the `OI-24` register row has named since session 95.

### Done

- **The count is derived.** [M06 section 2](../plans/M06-admin-ops-console.md) carries a `m06_delta_count` span, backed by a `SPAN_QUERIES` entry that counts the section's rows by first cell, which is `manifest_changes`' own form rather than a second way of reading a delta table.
- **The sentence and the table DISAGREED, by three.** The prose read *"Seven deltas"*. The query derives TEN. The sentence had already been corrected once, from *"Five"* to *"Six"* by session 89, and `SD-M6-10` made it wrong again three sessions later, which is what session 95 filed rather than repaired.
- **Two opening paragraphs, not one**, both entered in `f6f8e58`, both opening with the same 90-character clause and diverging after it. That is the keep-both merge shape `OI-10` records, and `CI-06u`'s dedupe cannot see it because it dedupes byte-identical lines only. **The surviving paragraph carries the union of both**, so the `SD-M6-07` failure-mode note the newer paragraph had dropped is back.
- **`SD-M6-11` was OUTSIDE the table.** It sat past the table's terminating blank line and past a prose paragraph: a pipe run of length one, under `CI-06v`'s minimum orphan length of two and therefore invisible to it. It rendered as prose full of pipe characters. Moved back in, boundary checked by hand after the move.
- **[ADR-130](../decisions/ADR-130.md), and the CONDITIONAL reservation fired.** `CI-06/derivable-counts` was silent on the site while it read *"Seven deltas"*, and **silent again with the span removed and the count retyped in prose at the value the table actually holds**. Both runs are in the entry's evidence table. The gate's declared false negative does not cover it: *"a count that has already drifted is invisible here"* is about the drifted value, and this site is invisible at every value the sentence can hold.
- **The ruling:** a vocabulary entry may carry a `file` predicate and is then asserted only over the documents it matches; an entry with no predicate stays corpus-wide, which is every entry that existed before. A scoped entry is declared BEFORE any global entry sharing its noun, because declaration order is what lets it escape the shadow. Value-anchoring is untouched.
- **`OI-24` closes** in [ALLOCATION](../decisions/ALLOCATION.md), which is the authoritative `OI` register under [ADR-074](../decisions/ADR-074.md) section 7.
- **Verification.** `typecheck` exit 0. `repo-invariants` 10 of 10. `gates.mjs generate && check` 32 of 32. `falsify.mjs` clean and dirty on all 32 gates, 80 scope cases, 10 loader cases. `pnpm vitest run` 150 files, 2656 passing, 1 skipped, which reproduces `main` exactly. `pnpm run verify` exit 0.
- **The counterfactual was run and both outputs are in the pull request.** The generated count hand-edited to a wrong value takes `CI-06g` RED, naming the file, the span, what it reads and what its query gives; `generate` restores it and the tree returns to 32 of 32. The tree was restored by `generate` and never by `git checkout`.
