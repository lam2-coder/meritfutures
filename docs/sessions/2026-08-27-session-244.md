### 1. WHICH HALF WAS RIGHT, established before anything was touched

The dispatch named two repairs pointing opposite ways and said the original intent decides. **It is recoverable, it is unambiguous, and it is one paragraph long.**

[ADR-043](../decisions/ADR-043.md), the ruling that asked for this gate, in its Context section:

> **`CI-06n`, the registry-index gate**, asserts in both directions that every entry file has a **row** in its registry README and every README **row** resolves to a file.

**Neither use is loose.** The same entry rules `GOLDEN_SCENARIOS` per section rather than per entry because *"257 identifiers in 301 **table rows**"* and *"**a row is not a document**"*. ADR-043 was reasoning about table rows throughout, so nothing here rests on a modern reading of an old word.

**The gate itself held both claims and its `covers` line was the honest one.** At `cce89de` the title said *"has a README row"* and `covers` said *"is linked from"*, and the parser performed the second: one `matchAll` over the whole README body, with no notion of a line, a row or a fence. **A gate carrying two different claims about itself will be cited for the stronger one**, which is the failure `OI-09` was opened about and is exactly how it was found.

**The defect fired, on the entry that wrote the gate.** [Session 32](2026-08-16-session-32.md) found [ADR-043](../decisions/ADR-043.md) with no row in the ADR registry table, linked from a sentence in [that README](../decisions/README.md)'s preamble, with twelve gates green. One ADR of 43 sat outside the registry it belongs to, and it was the ADR that wrote `CI-06n` to pay for its own `CI-06c` exemption.

### 4. A NARROWING, NOT A WEAKENING, and why the distinction is not a word game

Rule 1 of [`gates.mjs`](../../scripts/corpus/gates.mjs) forbids a gate that *"returns PASS for a check it did not perform"*. **The test is directional and this change points the safe way**: an entry indexed only by a sentence was green and is now a finding. **Nothing that failed before passes now, on any input.**

**The forbidden move is the mirror of this one**, and it is worth naming so the two are never confused. Had the evidence run the other way, the repair would have been to weaken the TITLE to match the parser: title and behaviour would agree, every gate would stay green, and the corpus would have quietly lost a claim it is entitled to make. **Both repairs end with the gate agreeing with itself. Only one ends with the corpus knowing more.**

**One check does change owner and it is stated rather than left to be found.** `CI-06n`'s resolve direction now reports only ROWS, so a prose link that does not resolve is no longer its finding. `CI-06a` runs over every markdown file in the tree, registry READMEs included, and catches it under the title that covers it. **What `CI-06n` keeps is the registry-shaped half**: a row claiming an entry that is not there is a registry claiming coverage it does not have, which is a different failure from a broken link.
