### 6. Landmines

- **AN EXIT CODE IS NOT A REPORT, AND A CORRECT EXIT CODE WILL HIDE A LYING ONE FOR AS LONG AS NOBODY READS BOTH AT ONCE.** This runner has ALWAYS exited non-zero on a crash. The transcript said `29 of 30 invariants hold.` for three sessions anyway, and the number is the part a session quotes into its own log.
- **THIS FILE IS CITED BY LINE NUMBER AS HIGH AS `:7060` FROM DOCUMENTS THAT ARE NOT IN ANY TOOLING FENCE.** Inserting a paragraph into its header shifts every one of them, and `RI-15` and `RI-16` will find it. Edit at the foot, or replace lines one for one.
- **`scripts/corpus/gates.mjs` HAS THE SAME BUG RIGHT NOW.** A crashing gate is reported as a gate that did not pass, in the runner that guards the corpus. It is out of this row's fence and it is not fixed.
- **A CHECK THAT RETURNS `[]` WITHOUT LOOKING IS STILL INVISIBLE HERE.** The report can only tell a throw from a return. The sentinel idiom inside the checks is the only thing standing between this tree and a check that measures nothing quietly, and nothing in this row reduces the need for one.
