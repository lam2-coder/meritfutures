### 4. The count, and why the answer is a list of names

The derivation is [ADR-313](../decisions/ADR-313.md) section 7. **Two choices in it are judgements and both are put to the founder in that entry's approval block rather than buried here.**

**The first is that the eight are asserted BY NAME rather than as a floating length.** The dispatch asked for a figure that "moves on its own"; this session read that as asking for the PREDICATE to be derived, and then took the named list on two grounds already written into this corpus. `viaPrincipal`'s own comment in the same file says a set member should fail "with its own name in the diff". And [ADR-236](../decisions/ADR-236.md)'s rule, three cases up in the same file, is that a derived figure compared only against itself "is an identity and passes on any tree". **A set that can silently grow is how the six survived eight sessions.**

**The second is the predicate itself.** `AdminSessionSource` as a substring catches both spellings: `setInternalOpsSource` reduces through [ADR-171](../decisions/ADR-171.md) clause 1 and names the INTERFACE, `useCheckoutBackend` names the SETTER, the four `principal(request)` backends name both.
