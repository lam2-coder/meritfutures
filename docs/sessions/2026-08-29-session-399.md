### Findings

1. **`affiliate_commissions` IS NOT IN `schema.ts` EITHER.** The dispatch, the
   `ALLOCATION` row, `wiring.test.ts`'s `BLOCKED` entry and
   `routes/affiliate.ts`'s `STATEMENTS_UNREACHABLE` all draw a distinction between
   the two affiliate relations that does not exist. The last of them says
   `affiliate_statements` is *"one registration short of the position
   `affiliate_commissions` is in"*, in a runtime error message. Both were in the
   same position. It changes nothing about what is registered and it changes what
   registering the other one would COST: a ruling **and** a transcription.
2. **`RI-15` IS GREEN ON CITATIONS THAT POINT AT THE WRONG RULE, and they were
   wrong on `origin/main`.** Derived at reporting time, with true lines:
   `wiring.test.ts` cites `scope.ts:979` for *"`payoutRequests` is `owned`"* where
   that rule's class is at `1056`; `scope.ts:644,649` for
   `planVersions` and `planVersionSizes` where the true lines are `702` and `707`;
   `scope.ts:1307` for `ScopedTableKey`'s definition where the true line is `1423`;
   `payouts.ts` cites `scope.ts:675,684` for
   the two ledger rules where the true lines are `742` and `733`;
   `worker/provisioning/payload.ts` cites `scope.ts:909` for a sentence whose true
   line is `1226`; `admin-source/graph.ts` cites `scope.ts:403` for one whose true
   line is `1333`. The check verifies a NAME within two lines of the citation, and
   `firm`, `owned` and `identity_id` are the commonest tokens in that file. **Each
   was wrong on `origin/main` at `743cd04` before this branch existed**, measured
   there rather than inferred: `979` held `class: 'firm'` for another table and
   `1307` held `otpChallenges: {`. The line numbers above are this tree's.
3. **`CI-06i` REQUIRES A DESIGN RECORD PER `CREATE TABLE`, NOT PER RELATION.** A
   record for a view fails it in the second direction. The dispatch's fence assumed
   otherwise. The tree had already answered it, four hashes deep in
   `economic_calendar.md`.
4. **A GUARD WRITTEN HERE CLAIMED MORE THAN IT DOES.** Both directions of a broken
   table/view split were seeded and neither is silent. Narrowed rather than kept,
   in its own commit.
