### 1. The ruling, and why the strongest answer was the one that adds nothing

The dispatching brief was right that the first admin route rules the surface selection and wrong about how much would have to be built. Measured on this branch's base:

| Claim | Measured | Result |
|---|---|---|
| No route had been written against the admin origin | `grep -rn "'/admin" apps/api/src/routes` | **zero** |
| `/admin` is already an operator prefix | [`surface.ts`](../../apps/api/src/surface.ts) | `OPERATOR_PREFIXES = ['/admin', '/internal']` |
| The module list is a directory listing | [`registry.ts`](../../apps/api/src/registry.ts), [ADR-100](../decisions/ADR-100.md) rule 2 | every `.ts` file in `routes/`, no exclusion list |

**So the whole of what an admin route has to do is exist in that directory with paths that begin `/admin`.** `start.ts` is untouched, and the brief's "only if surface selection forces it" was not reached.

**Three candidates were refused and the reasons are in [ADR-144](../decisions/ADR-144.md) section 3.** A second `buildServer` reopens what [ADR-083](../decisions/ADR-083.md) closed; a `MERIT_API_SURFACE` check inside a handler is [P1](../plans/P1-monorepo-scaffold.md) section 2.1's "silently converts a security control into a URL convention" exactly; a `routes/admin/` subdirectory is a second list, and the first thing a second list does is disagree with the first.

### 3. The guard, exercised where it must REFUSE

**A guard that admits everything passes every admission test ever written against it**, and all seven of these endpoints admit all three roles because API_CONTRACT section 8 does. So admission is asserted last and is not the point:

```
(no cookie at all)   -> 401 unauthenticated       the session source is never consulted
tok-trader           -> 403 forbidden             "This session is not an operator session."
tok-norole           -> 403 forbidden             "This session carries no admin role."
tok-readonly         -> 200
tok-ops              -> 200
tok-owner            -> 200
```

**The 401 without consulting the source is load bearing.** No cookie means no token, so there is nothing to look up, which is what lets a deployment with nothing wired still answer 401 to an anonymous caller instead of 500.

**The role set is written twice and bound to the CONTRACT rather than to the other copy.** `RI-04` refuses a deployable that imports a deployable, so `apps/api` cannot import [`apps/admin/src/roles.ts`](../../apps/admin/src/roles.ts). The suite parses API_CONTRACT section 8's own `Roles:` line and asserts both transcriptions against it, which is stronger: the primary source is what either of them could drift from.

### 4. The finding, which runs the other way from the one the brief expected

The brief expected pressure on `SystemReason`. There is none: `'operator-console'` was accepted by [ADR-102](../decisions/ADR-102.md) for exactly this dashboard, so no member is proposed and none is needed.

**What the accessor lacks is a query SHAPE.** Its read vocabulary is `rows` / `rowsWhere` / `rowAt` over typed equality ([ADR-112](../decisions/ADR-112.md)), and none of the seven bodies is a projection of one table: `LiabilityResponse` is six aggregates over the whole book, the account search is a join across four tables, and the identity graph is a walk. **The only way to write a live adapter today would be `sqlExecutor`, whose vocabulary has one member and it is not this**, so the source is a PORT and nothing wires it. That is [ADR-110](../decisions/ADR-110.md)'s shape one route over, taken for the same reason: a port with nothing behind it is honest and a widened vocabulary is permanent.

### 5. Money swept by name, and the two calibrations execution caught

Every response member whose name ends `_cents` or `_bp` must be a safe integer and every `_day` or `_on` must be a `YYYY-MM-DD` trading day, walked over the NAME so the rule holds for fields nobody has added yet.

| Calibration | Why the first pass was wrong | Why it matters |
|---|---|---|
| `cusum.statistic` and `cusum.threshold` are floats | They carry neither suffix, so they need no exemption and get none | A CUSUM statistic is a standardised deviation. Rounding it is the calibration defect [M06](../plans/M06-admin-ops-console.md) `FM-M6-07` names |
| `by_day` is a CONTAINER named for a day | A name-only rule refused a valid `LiabilityResponse` | **Watched refusing the contract's own shape before it was fixed.** The rule is type directed now: an object or array under a day-shaped name is walked |

### 7. [ADR-012](../decisions/ADR-012.md), made mechanical

```
git diff origin/main -U0 | grep '^+' | grep -oiE '\b[a-z0-9-]+\.(com|net|org|io|dev|app|xyz|cloud|...)\b'
  -> ZERO.
every scheme-bearing literal added -> https://storage.example.invalid/pack-1
```

`.invalid` is reserved by RFC 2606 and can never be somebody's host. **The rule is a test now as well as a habit**: the suite reads the module and its own source as text and asserts neither carries a host-shaped token, with the needles assembled rather than spelled so the test is not the first thing it has to fail on.
