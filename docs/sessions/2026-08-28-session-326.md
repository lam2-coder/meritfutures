### Landmines

1. **THE RULING IS A JUDGEMENT AND THE ENTRY SAYS SO EVERYWHERE, INCLUDING IN THE SCHEMA WATCHER.**
   [ADR-177](../decisions/ADR-177.md) drew the line between what is writable and what is not at
   *"is there a posting"*, and this code sits on the far side of it: both readings are internally
   coherent and a founder can overturn this one in a sentence. **A session reading `0053` for a
   precedent about deriving a kind is reading the wrong file**; `0052`'s four arms are the
   derivations and this file's one arm is a choice.

2. **`0052` IS BYTE FOR BYTE UNCHANGED AND THAT IS WHAT MADE THIS SHAPE COST ANYTHING.** A CHECK
   cannot be extended in place, so the arm arrives as a DROP and an ADD under the same name in a
   later file, which is `0052`'s own stated succession and `SD-M5-08`'s idiom. **The failure mode
   is silent**: a superseding constraint that forgets an arm drops that code back through
   `ELSE true` and the database accepts every kind for it again with nothing saying a ruling was
   lost. One of the new cases exists only for that.

3. **THE AMENDED ROWS ARE UNPOSTABLE AND SAY SO, WHICH IS NOT THE SAME AS REPAIRED.** Only the leg
   naming `firm_treasury` moved. The counterparty slot in each is
   [ADR-174](../decisions/ADR-174.md) section 3's, and a session that reads the amended `LT-07` as
   a posting it can build will build half of one.

4. **[`0052:115-116`](../../packages/db/migrations/0052_chart_of_accounts.sql) IS BACKWARDS AND
   CANNOT BE FIXED.** It warns the next reader against asset-shaped prose on the ground that such

   now inverted in an unamendable file**, and the two codes it is warning about are exactly the two

   nothing posts against it and nothing reads it.

5. **A WATCHER PINNED TO FILE NAMES WATCHES THOSE FILES AND NOT ITS CLAIM.** Both of this session's
   misses were that, in two different shapes, and one of them stayed green through the session's
   own ruling. Recorded below.

nothing posts these three transactions yet**. That price only rises, which is an argument for
answering now and not an argument for answering this way.
