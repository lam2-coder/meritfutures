### 7. Landmines

- **`git log -S` does not name a commit until it names a traversal.** Four defensible readings of [ADR-396](../decisions/ADR-396.md)'s six-word rule disagree, and the `--first-parent` reading names a different commit on **all 493** pointers. **Three entries now rest figures on that rule.** State the traversal and the search string or the figure is not reproducible.
- **The reader's `cited` field is SYNTHESISED and is not the string in the file.** It is target plus coordinate, so for any pointer written inside a markdown link it differs from what `git log -S` must search. **A first pass here searched it and produced 42 undecidables in the dated records alone, more than [ADR-400](../decisions/ADR-400.md) reports for the whole corpus.** The arithmetic caught it, not the care: a subset cannot exceed its superset.
- **`IDENTIFIER_GLUE` admits at most one of `at|in|is|see` between the name and the pointer.** Three seeds written as *"The `firm` classifier is read at ..."* came back green because the binder returned `null` and `RI-16` never saw a named citation. **A seed that goes green for the wrong reason reads exactly like a finding.** Diagnose the binder before believing a green seed.
- **Two consecutive rows have proposed amendments to `G1` on instances `G1`'s own reader cannot see.** [ADR-399](../decisions/ADR-399.md)'s four `:35` sites and [ADR-398](../decisions/ADR-398.md)'s surviving `sites: 7` site contribute **0** between them to the 495 every figure is measured over.
- **A stricter gate can lose true verdicts.** The uniqueness condition would have converted **42 correct born-wrong classifications into undecidable**. Price a strengthening against what it stops the corpus from saying, not only against what it starts catching.
- **A registry insertion is not automatically below every pointer into the registry.** This row's first draft of the moved-citation audit asserted that and was wrong: the three [ALLOCATION](../decisions/ALLOCATION.md) rows land at **393** and the deepest pointer into that file names **638**, so **seven move**. All seven were already wrong, so nothing went stale, **but the sentence was written before the audit was run** and that is the order [ADR-388](../decisions/ADR-388.md) section 13 exists to reverse. **Resolve the target with the checks' own `citationTargets` and not by suffix**: a first pass here matched `docs/decisions/README.md` and `docs/sessions/README.md` to each other and reported five phantom moved pointers in each.
