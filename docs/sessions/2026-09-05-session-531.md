**BLOCKERS.** Per-ASN resolution needs a data source this tree has none of and the egress refuses. Named in the entry, owed, not worked around.

**LANDMINES.**

- **THE PER-IP DIMENSION CHANGES MEANING SILENTLY THE DAY AN EDGE LANDS, AND NOTHING IN THIS REPOSITORY CAN SEE IT HAPPEN.** `server.ts` configures no `trustProxy`, so `request.ip` is the immediate peer. Today no edge is operated and the peer is the caller. Behind a proxy the same counter is a GLOBAL limit with a per-IP name, and an edge is a deployment fact rather than a file, so no check is writable. `auth-backend.ts` refused to build this dimension on the identical fact; this row built it because the values are data rather than prose. **Read that paragraph before sizing the numbers.**
- **THE LIMITER MAKES THE ANOMALY DETECTOR SEE LESS THAN IT DID.** `certificate_verifications` records every ADMITTED request and none that is refused, because `result`'s CHECK has four members and none of them is a refusal. Past the threshold the table shows a rate capped at the limit rather than the true one. `AS-M11-04`'s signature still fires up to the cap. **If the detector work later finds the cap blinds it, the fifth member was a prerequisite rather than a follow-up.**
- **A LINE-NUMBER CITATION INTO A FILE YOU ADD IMPORTS TO DRIFTS, AND `RI-15` ONLY SEES IT WHEN THE CITED LINE CHANGES SHAPE.** Seven import lines in `routes/certificates.ts` turned a seventy-two-line-old stale pointer red, because it landed on a bare closing brace and the vacancy rule fired. The same diff moved a second pointer, in `apps/portal`, that **no check reported at all**: its cited line was a comment marker and no backticked name binds ahead of the citation, so resolution and range were all that was ever asserted. **A green `RI-15` is not evidence that a citation resolves to what it names.**
- **EVERY SUITE THAT INJECTS A CERTIFICATE ROUTE NOW HAS TO SAY WHICH LIMITER IT RUNS UNDER.** The port's default refuses, which is correct and turned 43 cases in six files red on landing. They install `admitEveryRequest` from `test/support/`, which counts nothing; a real limiter with large numbers was refused, because it would give each file a hidden request budget and the case that eventually crossed it would fail for a reason having nothing to do with what it asserts.
- **`wiring.test.ts`'s PORT SCAN NOW READS `src` AS WELL AS `src/routes`.** A `use`/`set` export anywhere in `apps/api/src` is a declared port that must be wired or blocked with a reason over eighty characters.
