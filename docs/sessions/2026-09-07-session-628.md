### 1. The objective

Take [ADR-431](../decisions/ADR-431.md) section 10 row 3: `RI-35`'s value-position proxy misses assignment. **Re-derive the miss at source before repairing it**, because that entry's own headline overturned [ADR-415](../decisions/ADR-415.md)'s account of this same probe and a sibling's measurement can be wrong. **Demonstrate the miss firing before widening**, widen the probe to catch assignment position **and no further**, carry both directions in the suite with the sabotage seed, **price what it now catches that it should not, measured over the tree rather than asserted**, and write ADR-433. **Widening a probe to catch a real install is a repair; widening it until it catches things that are not installs and then loosening the assertion to compensate is weakening a gate, which is forbidden outright.**

### 2. Done

- **The container measured and reported.** No repository on arrival, eighteenth consecutive row; `/home/user` held `.` and `..`. Cloned with no depth flag, `pnpm install --frozen-lockfile` **8.5s**, exit 0, tree clean after it. **`git push` refused `403` by the proxy** until `add_repo` was called with `access: "push"`.
- **The base reproduced at `9eb52656`** on a clean tree before the first edit: `generate` reported *every span already matches its query* and left the tree clean, gates **33 of 33**, invariants **35 of 35**, suite **341 files / 8,272 passed / 11 skipped / 0 failed**. **This is not [ADR-431](../decisions/ADR-431.md)'s base and none of its figures were carried across.**
- **The dispatch's quotation of ADR-431 section 10 row 3 checked against source** at [`ADR-431.md:157`](../decisions/ADR-431.md) and found faithful.
- **The miss demonstrated, with its counterfactual**, in a throwaway `git worktree` and never in the working tree: three assignment shapes all `absent` with `RI-35` at 0 findings, and one character turning the same file `present` with leg 2 RED. Worktree clean between every seed and after the last.
- **`prettier --write` watched producing the wrapped assignment**, which is what decided the read spans the newline instead of being line-scoped.
- **Both punctuation-proxy probes widened with one shared helper**, on [ADR-431](../decisions/ADR-431.md) section 10 row 4's own precedent for the same pair, and all four caller probes measured identical on the real tree before and after.

Named and priced, not taken.

### 4. Owed

- **A founder read on [ADR-433](../decisions/ADR-433.md) section 12**, three decisions, of which the first is the one this row exists to put: [ADR-431](../decisions/ADR-431.md) asked when a change that makes a check EASIER to satisfy is safe, and this row is its mirror. **When is a change that makes a check HARDER to satisfy a repair rather than a new gate nobody asked for?** The answer taken here is that a widening is a repair when the probe's registered `names` field already claims the thing it was missing, and this one does.
- **The second is whether a measured-empty false-positive surface is acceptance or deferral**, since the check now has an input its authors do not control: one refusal string phrased differently turns a true absence into a red that instructs its reader to retire a true claim.
- **The third is whether the next row on this file may spend itself on the stripper unification alone**, because three rows have now each declined it for the same good local reason and no dispatch will produce it as a side effect.
