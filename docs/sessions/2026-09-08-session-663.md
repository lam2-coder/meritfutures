### 5. Landmines

- **A default parameter makes a whole-tree scan invisible to a search for the root.** `derivedSet(root = REPO_ROOT)` and `derive(dir = DECISIONS)` are called with no argument, and a suite that walks four hundred files can contain no occurrence of any root identifier. **Any future derivation over "what reads the repository" that is a grep is wrong by three of eight files here.**
- **And the same feature makes a non-scan look like one.** `transcript(checks, root = REPO_ROOT)` passes the real root to fixture checks that ignore it. A population derived by search over-counts and under-counts in the same file.
- **A wall-clock threshold is not a population.** It worked for `ADR-466` because its file held two kinds of input separated by a factor of twelve. Over eleven files there is no gap, because one `test.each` reads one input at thirty-five depths.
- **The second loaded run is where the defect appeared.** A single loaded run at the base would have reported this row's motivating failure as absent. **Run the load twice.**
- **A budget factor rounded in the comfortable direction is a budget that is too small.** `ADR-466` rounded 2.16 to 2.0 and measured contention from one case; both choices push the same way and together they account for most of the gap between 30000 and 60000.
