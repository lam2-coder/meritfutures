### 2. The central question was live, and it was answered rather than defaulted

**The dispatch's own warning was the right one: the plan is named for a transport and a plan's name is not an argument.** So the question was put properly.

> **Should `apps/admin` serve HTTP at all?**

**It is a real question, because the deployable that would absorb it already exists and already has everything.** `api-admin` is `apps/api` at `MERIT_API_SURFACE=operator`, on `ADMIN_ORIGIN` under `/api/v1` ([`INFRA:44`](../architecture/INFRA.md)), it has a framework, and it registers **27 routes today**. One fewer Railway service is a real saving.

**THE ROUTE COUNT WAS RE-DERIVED AND NOT INHERITED**, because the plan's own section 6 records that a grep over route files has been wrong twice here. `compose(Fastify(), 'operator', await discoverRouteModules())`, read off [`CompositionReport.registered`](../../apps/api/src/registry.ts):

```
operator  modules= 26  registered= 27  withheld= 45
public    modules= 26  registered= 46  withheld= 26
```

**27 is 26 operator-prefixed plus `GET /health`**, and the union is `46 + 27 - 1 = 72`. The dispatch's figure held.

**THE ANSWER IS YES, AND IT DOES NOT REST ON [`INFRA:43`](../architecture/INFRA.md) SAYING SO.** The row does say so and an entry whose whole argument was _"the row exists"_ would be citing rather than defending. What defends it is [P1 section 2.1](../plans/P1-monorepo-scaffold.md), written at the first commit, about this exact deployable: _"`apps/admin` is a separate deployable from the first commit, and it will look like waste for weeks ... The tempting scaffold is one application with three route groups. That choice is invisible for months, is a re-platform to undo, and it silently converts a security control into a URL convention."_ **The corpus anticipated this question before there was any code to ask it about.**

**AND THE LOSING SHAPES WERE PRICED.** Section 4 of the entry is the table. The short form is that folding the console into `apps/api` costs an amendment to an `approved` architecture document, [`ADR-083:49`](../decisions/ADR-083.md)'s back door taken deliberately, and, because **`RI-04` forbids `apps/api` declaring `@merit/admin`**, a move of 2,802 lines out of a directory that [`P5-l`](../plans/P5-payouts-and-wallet.md) and [`P6-j`](../plans/P6-live-tier.md) both hold right now. It buys one Railway service.

### 3. THE ARGUMENT THE PLAN DID NOT MAKE, AND IT IS THE STRONGEST ONE HERE

**The alternative worth taking seriously was never `apps/api`. It was NO FRAMEWORK: `node:http` plus [`renderLiabilityHome:630`](../../apps/admin/src/page.ts)'s string lines, which already exist and already pass 200 tests.** It costs zero dependencies, which is the honest thing on its side, and [ADR-095](../decisions/ADR-095.md)'s own refusal of that shape for `apps/portal` and `apps/site` leaned on `INV-M9-04`'s cache, which has no counterpart here.

**IT IS REFUSED ON A PROPERTY OF THE CONTROLS RATHER THAN ON TASTE.** [ADR-095](../decisions/ADR-095.md) ruling 3 forbids a UI serving `/api/v1` or any operator path, and **exactly two mechanical checks enforce it**:

| Check                                                                                                | What it reads                                                                                                         | What a hand-rolled `node:http` console gives it                                                                                                                                                                                                             |
| ---------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`RI-09`** ([`repo-invariants.mjs:1318`](../../packages/tooling/checks/repo-invariants.mjs))        | PATHS, in three shapes, against `apps/api/src/surface.ts`'s own `BASE_PATH` and `OPERATOR_PREFIXES`                   | **Nothing.** Its own `covers` at [`:1334-1335`](../../packages/tooling/checks/repo-invariants.mjs) names the shape: _"a route reached by a catch-all segment, a rewrite, a middleware or a hand-written router table declares nothing this check can find"_ |
| **`RI-11`** ([`ui-server-endpoints.mjs:128`](../../packages/tooling/checks/ui-server-endpoints.mjs)) | A Server Action directive, and a routing config matched by `/^(?:src\/)?(?:next\.config\|middleware)\.[cm]?[jt]sx?$/` | **Nothing.** There is no config file to read                                                                                                                                                                                                                |

**So the no-framework console is the single shape in which BOTH halves go silent, in the one deployable [SECURITY](../architecture/SECURITY.md) treats as total loss when owned.** A different framework is a weaker version of the same defect: `RI-11`'s config half and `RI-09`'s `ROUTING_ROOTS` half each become an entry somebody has to write, while `RI-09`'s base-path shape survives because it is framework-independent, which that file says of itself at [`:1337-1339`](../../packages/tooling/checks/repo-invariants.mjs).

**AND THE FRAMEWORK COSTS NOTHING TO ADMIT.** Section 4.
