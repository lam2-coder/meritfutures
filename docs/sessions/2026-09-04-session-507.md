### 3. What the ruling turned on, which is not what the row expected

The row expected a session to arrive at a lock primitive it did not have. **It has one.**

`lockScope` is declared on `WithdrawalTx` under the sentence *"No method takes an identity"*, which is what makes [ADR-305](../decisions/ADR-305.md) section 4's finding true. But the accessor underneath does not implement it as an advisory lock: [`scoped-db.ts:1302`](../../packages/db/src/scoped-db.ts) records that `pg_advisory_xact_lock(bigint)` is what the invariants' prose names and that sending it would mean widening a one-member raw-SQL vocabulary, and takes a **row lock on `identities`** instead. `SystemTx` carries the same verb, `lockAt`, for a stated reason about `INV-M5-07`.

**So the answer to "what does a clock take instead of `lockScope`" is "the same lock, through the door that was built for a batch".** That collapsed the largest open question in the port and is section 2 of [ADR-316](../decisions/ADR-316.md).

---

### 4. Why the home question is answered as a refusal

The row warned that a session meeting this unprepared would either duplicate a money-path decision function or invent a package inside an adapter. **The measurement made a third answer available**, and it is the one taken.

`decideApproval` has **no live caller in `apps/api/src`**, its only call sits inside `driveApprovals`, which has none, and the contract declares no operator approval endpoint. So the premise [ADR-286](../decisions/ADR-286.md) reasoned from, two deployables needing one predicate, **is not the premise here**.

**And the two arms are not one function.** With no hand, `dualControlRequired` returns `false` on its first line, so a clock reaches seven of the eight terms and can never reach the eighth; and the driver needs one more that `APPROVAL_HOLDS` does not carry, because it posts `LT-06` and `driveApprovals` posts nothing.

**The refusal is therefore not "it is too expensive to share".** It is that there is no second reader today, that the shared part is seven terms of a function that would have to be split three ways to share them, and that two live gates read the file for the half that can never leave `apps/api`. **What replaces the code is a census**, on [ADR-286](../decisions/ADR-286.md) section 6's own remedy, and the trigger that makes the new package right is named so it can be checked rather than re-argued.

### 5. Where this session is most likely wrong

1. **The directory name.** `apps/worker/src/withdrawals/` is the one judgement in the port section; every other line is derived from `sweeps/ports.ts`'s idiom or from the accessor. A slice that places it elsewhere with a reason is not overruled by this entry.
2. **The refusal itself.** If the founder expects an operator approval endpoint within the next few slices, the new package is the better call **today** and the entry says so in those terms in its own approval block rather than defending itself.
3. **The per-identity transaction.** It trades an all-or-nothing run for a night in which the request leg is not blocked behind the batch. A reader who weights the ledger's tidiness above the trader's door would choose the other one, and the trade is stated rather than assumed.
