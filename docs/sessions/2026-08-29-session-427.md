**Objective.** Build Merit's operator directory and role model, so that six admin
ports wait only on an identity provider and not on a missing table.

**Outcome.** **The split is the deliverable and it moved the line.** The half
that was a table is built and tested. The half that is a purchase is a named
function, three named variables, and a refusal that no environment file can turn
into a pass.

### 1. What the row claimed, and what the tree says

| Row `237` and the dispatch | Derived before a line changed |
|---|---|
| `admin_actions.actor` is `text NOT NULL` with no foreign key at `0017:77` | **HOLDS EXACTLY**, at `:77` |
| No table in the registry holds an operator, a role or an operator session | **HOLDS.** Nothing in 66 migrations, nothing in `TABLES` |
| `0002:280` says there is no password table in this schema by design | **HOLDS EXACTLY**, in those words |
| `API_CONTRACT:516` closes the role set at `owner`, `ops`, `readonly` | **THE SET IS CLOSED AND THE POINTER IS NOT.** It is at **`:896`**; `:516` is a field of `PayoutListItem` |
| The role set exists in three places | **REFUTED. FOUR**, and the fourth was found while writing the comparator |
| Nothing models an operator anywhere in the schema | **REFUTED. `0042:57` DOES**, as a trader-side `users` row |

**The two premises that did not survive are both about places nobody looked.**
One made the comparator wider by a copy; the other is a finding on a merged
money-adjacent migration.

### 2. What was ruled

**`C-08` covers two questions and only one is the provider's.** [ADR-237](../decisions/ADR-237.md)
section 3 carries the exact replacement text and section 2 explains why four
files restated the compression without any of them being wrong given the one
above it.

**The directory is Merit's and the role is never asserted by a provider.**
`OperatorAssertion` carries an issuer, a subject and an assertion id, and no
role. A role in a vendor console is unversioned, invisible to `admin_actions`,
and changeable by whoever administers the tenant.

**An operator is not a `users` row**, refused on a credential rather than a
taste. See section 5.

**The seam is a function and it stays blocked.** `refusingAssertionVerifier`
answers `unconfigured` when any variable is absent and `unavailable` when all
three are set, so **the configuration is necessary and is not sufficient**.

**No port is wired.** Nothing can write an `operator_sessions` row, so an
installed `AdminSessionSource` would answer 401 to every operator on a door that
is not shut against them.

### 3. What was built

[`0073_operator_directory.sql`](../../packages/db/migrations/0073_operator_directory.sql):
two tables, one `ALTER TABLE`, no trigger, no grant revocation, no enum type.
`0017` is superseded **by addition** rather than edited, which is `0028`'s and
`0068`'s mechanism on this estate.

[`operator-identity.ts`](../../apps/api/src/operator-identity.ts): the port, the
three variable names, the refusing verifier, and **two decision functions that
take rows rather than fetch them**, which is what makes both testable one slice
before either supplier exists. It is `csrf.ts`'s split with `server.ts`.

[`operator-role-vocabulary.test.ts`](../../packages/db/test/operator-role-vocabulary.test.ts):
the role set across four copies, **compared against the contract as the
authority rather than against each other**, because two transcriptions that
drift together would agree. Plus two DDL properties: no credential column on
either table, and `token_hash` rather than `token`.

[`operator-identity.test.ts`](../../apps/api/test/operator-identity.test.ts):
the seam pinned shut over all eight subsets of the configuration, and both
decisions exercised to totality, with the eight-combination case naming the one
that admits.

### 4. What was refused

- **Wiring any port.** See section 2.
- **Taking `systemDb('operator-console')`.** [ADR-171](../decisions/ADR-171.md)
  section 9's condition is *"the slice that lands an `AdminSessionSource` a
  deployment can install"*, and this slice does not land an installable one.
  **The condition is unmet and is not reinterpreted.**
- **A password, a secret, an API key or any local credential.**
- **A third value for `operators.status`.** A departure and a suspension are the
  same fact to an authorization decision.
- **A ceiling on `operator_sessions.expires_at`.** The corpus states none and a
  number here would be the setting M06 warns about.
- **A provisioning route.** A route that mints the first `owner` is precisely
  the shape a login takes when it is written by accident.
- **Editing `0017`, `0042`, `0002`, [ADR-171](../decisions/ADR-171.md) or
  `MERIT_BUILD_MASTER_PROMPT.md`.**
- **Sweeping the 427 citations the invariants did not catch.** Section 7.

### 5. The finding on `0042`, and it is three declarations rather than a judgement

`impersonation_sessions.admin_user_id uuid NOT NULL REFERENCES users(id)`
([`0042:57`](../../packages/db/migrations/0042_impersonation_sessions.sql)).
`otp_challenges.email_normalized citext NOT NULL`, which `0002` says is keyed
that way *"before a user may exist"*. `sessions.user_id` references `users(id)`
and `POST /auth/verify` writes it. **So an operator holding a `users` row
already holds a login this deployable can mint**, over a factor
[`SECURITY:134`](../architecture/SECURITY.md) forbids on this surface in terms.

**Latent rather than live**, and the entry says so rather than overstating it:
nothing writes an `impersonation_sessions` row. `0042` is merged and is not
edited. `operators` declares no such column, which is also why `scope.ts`
registers it `firm` with `derived via users` named as the available mistake.

### 6. Landmines

- **A SENTENCE THAT COMPRESSES TWO CONTROLS INTO ONE ROW GETS READ AS ONE
  CONTROL.** `C-08` names four things and three of them are edge controls on
  `ADMIN_ORIGIN`. RBAC is not, and nothing in the row said which was which, so
  two route modules, a test and an ALLOCATION row each read all four as the
  provider's. **This is [ADR-236](../decisions/ADR-236.md)'s lesson arriving from
  the other end**: there a true sentence went false, here a short sentence was
  read as a complete one.
- **A `Roles:` LINE CONTAINS MORE BACKTICKS THAN ROLES.** The comparator's first
  run read five members, because the paragraph continues past the role set into
  the `admin_actions` obligation and backticks both identifiers it names there.
- **A `COMMENT ON` STRING IS NOT A COMMENT TO A GREP.** The first credential
  check stripped `--` lines and matched *"NO PASSWORD, NO SECRET"* inside the
  table's own `COMMENT ON`. It reads the declared column names now.
- **A SYNTHETIC FIXTURE IS A COPY OF A MOVING TREE AND IT CANNOT DERIVE THE
  NUMBERS IT COPIES.** `RI-16`'s known-findings register names literal line
  numbers, so moving the register without moving the fixture reports every
  registered finding as vacant. It went red exactly that way.
- **`scoped-db.test.ts` COUNTS TABLES AND COUNTS REGISTRATIONS SEPARATELY**, and
  a new table moves one number and not the other. Both were updated, and the
  `SQL_NAME` map is a third hand-written statement the suite requires to be
  total.
- **`DISPATCH_PROTOCOL` section 4's invariant row still reads 18** against a
  runner reporting **21**. Outside every fence, reported again, the third session
  in a row to report it.
