### 3. The finding that made the ruling worth writing, and it was not predicted

**Intersecting the 227 with every `GS-nnn` a test file in this tree names returns 21 rows.** Seven of them are discharged today.

`ADR-072` refused `no-module-code` on one sentence: *"a module whose code landed tomorrow would still have nowhere to write."* **Tomorrow came four times.** `apps/portal`, `apps/admin`, `apps/site` and `packages/harness` each landed since that entry was signed, and **every one of them arrived with a suite that runs in an ordinary `pnpm exec vitest run`**. Seven registry rows are asserted by those suites and passing. **The number of fixture formats written to discharge them is zero.**

That is why the entry is a ruling rather than a repair. The prediction was that the format half would outlive the code half; it did not outlive it once, and the counterexamples are executable.
