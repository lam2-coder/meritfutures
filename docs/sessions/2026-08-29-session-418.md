**Objective.** Land the founder's dual-control threshold, and find out whether
the constraint it feeds guards the path they were thinking of.

**Outcome.** **Landed, and it does not.** The number is `500000` integer cents.
The constraint it feeds is real, is on the admin adjustment table, has no
writer, and was **satisfiable at any amount** until this session bounded it. No
payout route in this tree carries dual control at all.

### 4. What was ruled

**A constant for the value, a ceiling in DDL for the bound.** The value is
`DUAL_CONTROL_THRESHOLD_CENTS = 500_000n`; the bound is
`account_adjustments_dual_control_threshold_ceiling`, `<= 500000`, in
[`0068`](../../packages/db/migrations/0068_dual_control_threshold_ceiling.sql).
Lowering the threshold is free, raising it is a migration, and **that asymmetry
is the control.**
