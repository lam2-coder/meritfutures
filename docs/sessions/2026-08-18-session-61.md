- **Landmines:**

  - **HALF THE BRIEF'S ASSERTION IS FALSE OF THIS CORPUS, AND CHECKING IT BEFORE BUILDING IT IS THE WHOLE OF THIS SESSION'S VALUE.** The brief asked for a symmetric pair: a `proposed` heading may not carry an acceptance, **and** an `accepted` heading must carry an approval line. The first found exactly the three entries the audit named. **The second fails on thirty-four**: `ADR-005`, `ADR-018` to `ADR-032`, `ADR-034`, `ADR-037` to `ADR-049`, `ADR-051` and `ADR-D1` all head `accepted` and carry no approval line, and every one is legitimate because their approvals live in the [gate-closure files](../decisions/gates/) where batch sign-offs have always been recorded. **Shipping it meant a gate red on arrival on thirty-four files whose only available repair is to invent thirty-four founder signatures**, which is fabricating a signature and is not available at any price. The brief's own sentence, quoting STATE, is that a gate which fails on arrival is a gate somebody switches off, and its own instruction about the five unsigned entries is "if it does not pass on them, your assertion is wrong, not theirs". That instruction is what was applied to the thirty-four.

  - **AN ENTRY WITH NO APPROVAL LINE CLAIMS NOTHING, WHICH IS WHY THE ASYMMETRY IS A FACT RATHER THAN A GAP.** A contradiction needs two statements. One statement and a silence is a record with a silence in it, and this corpus fills that silence in a different file on purpose. The `covers` line says so, and the scope case is what stops the claim being quietly widened later.

  - **THE LETTER WAS RESERVED ON A BRANCH THIS ONE CANNOT SEE, AND THE BRIEF'S PREMISE WAS TRUE OF THE WRONG REF.** `r` is claimed in [ALLOCATION](../decisions/ALLOCATION.md) on `claude/merit-futures-briefing-7auoor`, open as PR #96 against this exact base and unmerged. **`CI-06p`'s second assertion, that every implemented letter is claimed by a row, fails the moment `CI-06r` exists in the runner.** So "do not claim it again" and "18 of 18 pass" could not both be satisfied, and the tie went to the gate: a duplicate row is tracked as `OI-11` and a red gate on `main` is the thing the corpus says gets switched off. **The row is #96's verbatim but for one link** it carries to a plan document that lands with #96 and fails `CI-06a` here, so the two rows are one claim by one claimant. **Whoever merges second keeps one row and it should be #96's.** Third instance of the two-ref gap this file documents at length.

  - **THE SEED WAS WRITTEN AGAINST A NEW ENTRY RATHER THAN AGAINST ONE OF THE THREE REAL ONES**, and the reason is that the three are repaired in this same branch. A seed that edits a file the next session can legitimately delete is a seed with an expiry date nobody records. Both `CI-06r` seeds also add the entry's README row, or `CI-06n` reports the seed first and the case fails on a neighbour's finding, which is the defect this harness exists to refuse.

  - **THE SCOPE CASE AND ITS CONTROL SHARE ONE SEEDING HELPER, SO THE TWO TREES DIFFER IN EXACTLY THE APPROVAL LINE.** Written separately they drift, and a control that fires on an unrelated difference proves the seed rather than the boundary. That is the same lesson `RE-D-02`'s first seed taught one package over.

  - **THE HARNESS IS INSIDE THE TREE THE GATE SCANS, SO THE APPROVAL LINE IS ASSEMBLED FROM FRAGMENTS.** `['ACCEP','TED'].join('')`, on `RI-02`'s idiom and the same reasoning `CI-06q`'s seed states in its own comment. A spelled-out approval line in `falsify.mjs` would make the harness its own finding.

  - **A VERDICT IS A CLOSED UPPERCASE VOCABULARY AND THE NEEDLE ALONE IS NOT ENOUGH.** [`ADR-047`](../decisions/ADR-047.md) line 26 reads "**Founder approval as an `admin_actions` row**", which is a step in a protocol the ADR specifies rather than a verdict on the ADR, and four entries carry a bare `**Founder ruling.**` as a section header. A needle-only match reads all five as signatures. Uppercase-only also keeps `ADR-018`'s lowercase "`w=3` approved" from reading as one.

  - **`CI-06p` PICKED UP A BETTER IN-SCOPE EXAMPLE FOR FREE.** Its `unclaimed-letter` case now demonstrates on `CI-06r` itself, which is the first time that seed has had a real letter to point at rather than a synthetic one.
