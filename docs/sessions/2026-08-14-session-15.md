## 2026-08-14 - Session 15: two rulings on the transparency surface (ADR-031, ADR-032)
- **Done.** Both rulings landed on `published_statistics` on the schema-delta branch. No new files: `0001`, `0021`, `0027` amended, and the corpus follows.
  - **[ADR-031](../decisions/ADR-031.md): `value_numeric numeric` becomes `value bigint` with a mandatory `value_unit`.** The no-floats exemption it held is **retired**. All seven ruled statistics are exactly representable as integers under conventions the corpus already fixed (ST-01/02/07 rates in **bp**, ST-03/04 money in **integer cents**, ST-05/06 durations in **whole seconds**), so the exemption bought nothing, and **for ST-03 and ST-04 the column held money on a public surface**, which is the case DATA_MODEL section 1 names directly. **An authorized exemption covering a money column is not an exemption, it is a hole with a ruling attached.** The rename is load-bearing: `value_numeric` holding a `bigint` is a lie that survives every grep.
  - **One vocabulary, and it is a type.** `value_unit` and `numerator_unit` are both `statistic_unit` (`count`, `bp`, `cents`, `duration_seconds`), declared once in `0001`. Two `text` columns with two `CHECK` lists are two vocabularies for one concept, which is how they drift. `numerator_unit` lost its standalone `CHECK` list in the process.
  - **[ADR-032](../decisions/ADR-032.md): `measure` on `published_statistics` and in the window unique key, closing OI-02.** ST-04's median, and ST-05's and ST-06's p95, were **unwritable**. The rejected alternative is recorded because it is the one that looks cheaper: separate `stat_code`s per figure need **no schema change at all** and are worse, because they make the pair independently publishable and **delete the invariant by making it unstateable**.
  - **STAT-C1, and it is the ruling rather than the column.** `measure` makes the second figure writable and does nothing to make it **required**. A deferred constraint trigger in `0027`, **same shape and same file as the ledger zero-sum check**, asserts that a publish run emitting one measure emits every measure its definition declares, plus that the measure is declared and the definition exists. `statistic_definitions` gains `measures`. Scoped to `restatement_of IS NULL`, so a correction to one figure of a published pair stays legal.
  - **Every constraint carrying a ruling is now probed against the database**, one perturbation each, tabulated in [DELTA_MANIFEST section 10](../../packages/db/DELTA_MANIFEST.md). Full set re-verified: **96 tables, 326 indexes, 347 check constraints, 6 triggers.**
- **Next.** The founder's **E2 line-by-line read**, now on seventeen money-path files: `0021` is not a money-path file but `0027` carries STAT-C1 and `published_statistics` now holds cents in a typed column. Then items A and B, then the DATA_MODEL table-by-table rewrite.
- **Blockers.** None.
- **Landmines.**
  - **A `CHECK` that evaluates to `NULL` passes, and `array_length` on an empty array returns `NULL`.** `statistic_definitions_measures_nonempty` was first written `array_length(measures, 1) >= 1` and **admitted the empty array, the single value it existed to reject**. An empty declared set makes STAT-C1 vacuous: a statistic could publish nothing and satisfy "every measure it declares". Now `cardinality(measures) >= 1`. **It was caught by executing the constraint, not by reading it**, and the same trap is live in every array-cardinality `CHECK` anyone writes against this schema from here.
  - **The founder's first instruction said the exemption set goes to zero, and it was corrected mid-session to two.** Asserting zero would have **failed migration `0027`**, because `correlation_groups.statistic` and `.threshold` are still `numeric`. Worth recording for the shape rather than the error: **an instruction that names a set by its size is checkable against the schema, and this one was checked before it was applied.** The founder's own reason is now in the file: **a plain integer `rho` of `0.30` is `0`, and `rho = 0.30` is the reserve-critical figure**, the level where CVaR99 nearly doubles while mean payouts stay flat.
  - **A third hand-maintained tally was found stale, in the document that recorded the last one.** [STATE](../STATE.md) carried "342 check constraints, 5 triggers" while DATA_MODEL carried 345 and 5 for the same migration set. Both corrected to the measured 347 and 6. [INDEX](../INDEX.md) separately read "25 ADRs" with 30 in the file. **This is the exact drift [ADR-026](../decisions/ADR-026.md)'s manifest gate was built to kill, and the gate does not cover these counts.** The CI check should assert the schema-object counts and the ADR count from the artifacts, not from memory.
  - **DATA_MODEL's header said "Three rulings changed a column" above a list of four.** Corrected in place to four. A count and its own list disagreeing inside one sentence is the cheapest possible version of this failure and it still survived a gate.
  - **ADR NUMBER COLLISION, live and unmerged. Two open pull requests both claim `ADR-031`.** This branch (PR #4) carries **ADR-031 (accepted)**, the `value bigint` ruling, and **ADR-032 (accepted)**. `claude/builder-reviewer-loop-rykvhs` (PR #5) carries **ADR-031 (proposed)**, "The reviewer subagent is a citation check, not an adversarial one".
