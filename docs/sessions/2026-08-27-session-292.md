### 2. Why the door count is not a style question

The four tables [P7 section 3.2](../plans/P7-risk-and-abuse.md) names, plus the one the runner writes, read out of [`scope.ts`](../../packages/db/src/scope.ts):

| Table | Class | `scopedDb` | `firmDb` | `systemDb(reason)` |
|---|---|---|---|---|
| `fills` | `derived` | reaches it | **refuses** | reaches it |
| `daily_marks` | `derived` | reaches it | **refuses** | reaches it |
| `identity_signals` | `owned` | reaches it | **refuses** | reaches it |
| **`identity_links`** | **`pair`** | **refuses** | **refuses** | reaches it |
| `detector_runs` | `firm` | **refuses** | reaches it | reaches it |

**No two of the three doors cover that set and one of them does.** `scope.ts` states the consequence at `PairTableKey` in words written about a different caller: *"REFUSED BY BOTH NARROW DOORS AND SERVED BY THE ONE THAT TAKES A REASON ... `systemDb(reason)` is generic over `TableKey` and is the only door left."*

**The one decision here that is a choice rather than a consequence is the absent reason parameter.** `system(reason, fn)` would have been shorter and would have left `'operator-console'` one string literal away from a scheduled job. [`apps/api/src/db.ts`](../../apps/api/src/db.ts) reaches the same conclusion from the other side and writes *"a door declared here is a door somebody uses"*; this file makes that sentence true of an ARGUMENT.

### 3. The assertion that was written wrong, and why it is recorded

The acquisition-point case tested whether a file under `src/` **contained** the accessor's name. It failed on [`src/provisioning/ports.ts`](../../apps/worker/src/provisioning/ports.ts), whose header names `@merit/db` in order to state that it does not import it.

**A prose mention of a package a file deliberately does not reach is the opposite of the property being asserted.** A substring instrument would have passed on the day it was written and gone red on the first file that documented its own restraint, which is the shape of a check that trains its readers to ignore it. The instrument is the import statement, and the same correction applies to any future grep for this property, including the one in [ADR-165](../decisions/ADR-165.md)'s approval clause.
