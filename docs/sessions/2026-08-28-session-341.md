### 1. THE COUNT, AND IT IS THE FINDING RATHER THAN THE WORK

**[ADR-184](../decisions/ADR-184.md) section 5 says "Three files must move together and two of them are named by no fence in this wave". It is SIX, and the three it missed were found by seeding the method and reading what went red.**

| # | File | What breaks | Named by |
| --- | --- | --- | --- |
| 1 | `src/routes/admin-reads.ts` | the declaration itself | ADR-184 section 5, and this dispatch |
| 2 | `src/admin-source/index.ts` | **TS2741**, `listEvents` missing from `composeAdminReadSource`'s return | ADR-184 section 5, and this dispatch |
| 3 | `test/admin-source-flags.test.ts` | **two cases**, the six-name list and the four-name missing list | ADR-184 section 5, and this dispatch |
| 4 | `test/admin-reads.test.ts` | **TS2741**, `const base: AdminReadSource` at `:180` | **NOBODY** |
| 5 | `test/admin-breaker.test.ts` | **TS2322**, `sourceOf(): AdminReadSource` at `:102` | **NOBODY** |
| 6 | `test/admin-source-evidence.test.ts` | a **THIRD** hardcoded six-name list at `:1166` | **NOBODY** |

**File 6 is the sharpest of the three, because it says in its own comment what it is for**: *"The count is read off the port rather than typed, so a seventh method added to `AdminReadSource` is a red test here rather than a silent gap."* It is a control written for this exact event, in a file no fence in this wave or the last names, and ADR-184 finding 9 enumerated the hardcoded lists and found two of three.

**Why finding 9 missed it, which is the checkable part.** File 6's list goes red only once the COMPOSITION follows the declaration: it reads `Object.keys(composeAdminReadSource({}))`, not the interface. Seeding the interface alone leaves it green, which is what a session measuring "what does a seventh method break" sees if it stops at the suite and never runs `typecheck`. **Files 4 and 5 are invisible to `vitest` for the same reason in reverse**: they are compile errors in test files, and `vitest` does not type-check.

**So the honest statement of the fence error is that it was measured with one tool.** Both halves of this session's red set needed both.

### 5. The control nobody predicted, and the prose moved rather than the control

**[`admin-source-flags.test.ts:1222`](../../apps/api/test/admin-source-flags.test.ts) asserts that `admin-reads.ts` does not contain the substring `admin-source`.** The new method's doc comment cited the composition file by path, and the suite went red. The obvious repair is to make that assertion read imports rather than text, **which the same file argues for in terms twelve lines above it** about its own `@merit/db` check.

**It was refused, and the refusal is the point.** Loosening a control in order to land a comment is weakening a gate to pass it; the comment is worth less than the control. The sentence was rewritten to describe the composition without naming its path, and the reason is now IN the file, so the next editor meets the explanation before the red. **The second red was the funnier one and is why the note is there**: the first rewrite cited the test itself, whose filename also contains the substring.
