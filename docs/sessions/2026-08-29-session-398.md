### 2. The state hash, which is what this entry declines

`ADR-026` C-07 fixes nineteen inputs. `0035` added a column and ruled it
**excluded**, on `ADR-047`'s own reason. **The four existing exclusions each
carry a reason of a kind that does not reach these three**: not replayable, a
version-like input, a version-like input again, wall clock. All three new
columns are replayable facts the fold produced, which is what `phase` and
`payouts_settled_count` are, and both are hashed.

**On the merits they belong in the hash and this session did not put them
there.** `HASHED_COLUMNS` is in `packages/rules-engine`, outside the fence, and
moving the list is also an amendment to `ADR-026`. Declaring a hash input set no
code computes would be worse than the gap, so the column comment says
**UNRULED** in those words. **The decision is free today and stops being free
with the first row**, which is the same argument `ADR-047` makes from the other
direction.

### 3. Watched failing: eight seeds, and a ninth that fired on its own

Seven red, one green control, tree byte-identical after every one with SHA-256
checked both ways and no seed restored with `git checkout`. Seed 3 (the two
floor types swapped in order) is red to the ordered case and **green to the set
case**, which is that case's stated blindness measured rather than described.
Seed 8 renames `BreachKind` and the derivation **throws** rather than comparing
two empty sets and reporting PASS.

**The ninth was not seeded.** `EVIDENCE_COLUMNS.ruleStates` is total over its
table by assertion, and `0065` turned that case red and named the three columns.
That is the most useful result of the session that nobody arranged: a control
written for a different reason caught a schema change one package away.

### Landmines

- **A default on a money column is a writer that forgets the field getting a
  zero.** `lifetime_settled_cents DEFAULT 0` is forced by five CI probes and is
  the engine's own opening value, and `rule_states_no_settlements_no_lifetime_total`
  only catches the omission when the settled count is zero. **An account with
  three settlements whose adapter drops the field writes a lifetime total of 0
  and nothing refuses it.**
- **The `CHECK` vocabulary is a copy of a TypeScript union.** It has a
  comparator; do not add a second copy anywhere without one.
- **`probe_rule_states_calendar_revision.sql` SUCCESS 6 reads a literal
  substring of the `state_hash` comment.** `0065` rewrites that comment and
  preserves it. Anyone superseding it again must too, and a `vitest` case now
  fails where the edit is made rather than only in the install job.
- **Do not read `0015` for this table's shape.** Three migrations have corrected
  it since and two of its constraint names are no longer in the catalogue.
