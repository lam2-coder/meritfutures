- **Objective:** rule `OI-28`. `simulation_runs.calibration_observed_at` is a `date`, `CI-06m` requires it to declare one of exactly three closed unit tokens, and [session 120](2026-08-21-session-120.md) declared `rail clock` while saying in the same breath that a calibration vendor is not a rail. Widen the vocabulary, widen the definition, or accept the noun.
- **Done:** **[ADR-082](../decisions/ADR-082.md), `status: proposed`, approval line UNSIGNED.** Shape **(b)**: the vocabulary stays at three tokens and `rail clock`'s **definition** widens to any third party's clock Merit quotes and never derives, `rail` naming the class after its commonest member. Shape (c)'s conclusion about the column is taken and its disposition of the definition is refused. **[`gates.mjs`](../../scripts/corpus/gates.mjs) carries the widened definition, a `CI-06m` note line and the token definitions printed with both unit findings; [`falsify.mjs`](../../scripts/corpus/falsify.mjs) carries `CI-06m/widened-definition-is-not-a-fourth-token`, in the same commit.** The [`simulation_runs`](../architecture/data-model/simulation_runs.md) argument is amended from open to ruled, [ALLOCATION](../decisions/ALLOCATION.md)'s `082` row is amended in place, and [STATE](../STATE.md) carries the entry.

- **Blockers:** **nothing is signed.** ADR-082 amends the definition inside a frozen `accepted` ADR and waits for the founder's read.
- **Landmines:**

  - **THE COMMENT ARGUING AGAINST A FOURTH TOKEN IS RIGHT, AND "FOUR IS A SMALL NUMBER" IS NOT AN ANSWER TO IT.** `UNIT_TOKENS`'s comment says an open vocabulary would turn *"the unit is named"* into *"some words about time are present"*. A fourth token is not an open vocabulary, and it is a step in the direction the sentence names, so the sentence still decides the question. **The answer that works is structural**: three tokens partition on *who answers this date, and may Merit compute it*, which has exactly three answers, and **a fourth would partition on who the counterparty is, which has none.** `vendor clock` today, then a KYC provider's, then a market-data feed's, each meaning "not Merit's, quoted" under another name. **A vocabulary is closed only when it partitions on a question with finitely many answers**, and that is the whole difference between three and four here.

  - **THE DISTINCTION A FOURTH TOKEN WOULD DRAW IS ENFORCED NOWHERE, AND THAT WAS READ IN [ADR-042](../decisions/ADR-042.md) RATHER THAN RECALLED.** That ADR wired three mechanisms against computing a date Merit does not own: the `packages/eslint-plugin-merit` import ban, the SQL shape check over the migrations, and `CI-06m` itself. **Not one treats a payment rail differently from a data vendor.** A token whose only content is a distinction the corpus never acts on gets chosen by feel, and choosing by feel is the failure `UNIT_MARKER`'s own comment records: three rows passed this check by accident before the marker was tightened.

  - **`why` HAS BEEN DEAD DATA FOR AS LONG AS THE VOCABULARY HAS EXISTED, AND THAT IS THE MECHANISM UNDER `OI-28`.** Every token carried a definition beside it and the gate rendered none of them: the refusal offered `trading day | wall clock | rail clock` and no definition of any, so a session standing at a failing column had to open `gates.mjs` to learn what it was choosing between. **Session 120 did exactly that, and `OI-28` is what it opened.** Widening a definition nobody is shown would have changed nothing that a session actually reads, so the definitions are printed with the finding now. **That is ADR-042's own rule applied to its own gate**: prose is not a control.

  - **A GATE THAT REPORTS `PASS` AND NO FIGURE CANNOT SHOW THAT A VOCABULARY CHANGE RE-CLASSIFIED NOTHING.** The objective required the `date`-column count before and after, and `CI-06m` had no note line, so the only way to get the figure was to read 57 markers by hand. **The note was added first, as instrumentation, and the definition moved second**, which is why "54, and 34/18/2" are two runs of one parser rather than one run and an inference. **Identical output is the evidence**: no token string moved, so nothing could resolve differently.

  - **THE SEED IS `vendor clock` AND THAT IS NOT AN ARBITRARY BAD TOKEN.** It is the nearest correct-sounding guess available to a session that has read the widened sentence and taken *"a calibration vendor's"* for a licence rather than for a definition. **It is seeded onto a row that declares `rail clock`**, the class this ruling touched, rather than onto whichever row sorts first: any declaring row produces the same finding and proves less. **Derived and not literal**, on the neighbouring case's recorded lesson, and the anchor throws if no row declares `rail clock`, which is [session 139](2026-08-22-session-139.md)'s finding that an empty anchor starves a seed.

  - **A RENAME WAS NEVER AVAILABLE AND WOULD HAVE BEEN THE WRONG REPAIR ANYWAY.** Renaming `rail clock` moves every declaration on disk, and this fence held neither design record that carries it. More to the point, **a vocabulary change that silently re-classifies an existing column is the failure the objective named**, and widening a definition while leaving every token string alone is the only one of the three shapes that structurally cannot do it.

### The three shapes, and why the ruling takes one and a half of them

The objective put three and asked which. **The answer is (b), and (c) is right about the column while being wrong about what it costs to leave the definition alone.**

Under (c) the definition still reads *"the rail's own clock"*, so a careful reader arriving at a vendor column reads it as refuted, **exactly as session 120 did**. That session then argued the token in the open inside a design record and opened an item to get the argument ruled. **The next vendor `date` column repeats that in full**: same refutation, same argument, same item under a new number. A definition that has to be re-argued each time it is applied is a defect in the definition, and (c) leaves it where it was found.

**What (c) gets right is kept**: the column is `rail clock`, it was correctly declared on the day it landed, and session 120 made no error that needed correcting. **The noun survives as a wart**, and it is recorded as one rather than accepted in silence.
