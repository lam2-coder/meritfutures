## 2026-08-18 - Session 67: `CI-06o`, the money-path model ban, and the half that keeps it from going vacuous (non-money)

- **Done:** **[`CI-06o`](../../scripts/corpus/gates.mjs) is written and both of its assertions have been watched failing.** [ADR-044](../decisions/ADR-044.md) section 8 specified this gate in 2026-08-16 and said in the same breath that it did not exist: "until it runs and has been watched failing on a seeded violation, prohibition 1 is prose". It runs now. **19 of 19 gates pass**, `falsify.mjs` is green with **21 scope cases**, and `pnpm vitest run` is **908 pass, 40 skipped, 60 files**. The letter `o` was reserved by ADR-044 and is not re-claimed; its [ALLOCATION](../decisions/ALLOCATION.md) row already existed.
- **Next:** Nothing follows from this gate. `CI-06s` and `CI-06t` are sessions 68 and 69 and their letters and anchors are theirs.
- **Blockers:** None.
- **Landmines:**

  - **ASSERTION 1 IS NEARLY VACUOUS TODAY AND THAT IS THE ARGUMENT FOR WRITING IT, NOT AGAINST.** `packages/` holds db, eslint-plugin-merit, golden-loader, rithmic, rules-engine and tooling; **there is no ledger, payout or auth package**, so the model-SDK scan reads one package and finds nothing. ADR-042 made the same argument for its SQL shape check: a gate written while its subject is empty is a gate nobody has to argue with later. **What stops it staying vacuous is assertion 2**, which discovers money paths independently of the gate's own scope list and reports any the list does not name. A scope list is a coverage claim, and a coverage claim nothing checks decays the first time a directory is added.

  - **SCANNING FOR `cohere` MATCHES "COHERENT" IN FIVE FILES OF THE ENGINE'S OWN TEST GENERATORS.** Measured before the ban list was written rather than discovered by a false red. The list therefore matches **import specifiers exactly or as a package prefix** (`openai` matches `openai` and `openai/shims` and never `openai-ish`) and never as a loose substring. Endpoint hosts are dotted, so they need no such guard. **A gate whose first run is a false positive is a gate somebody switches off**, and the cheapest place to find that out is before it exists.

  - **`CI-06o` WOULD HAVE BEEN A FOURTH SPELLING OF `RI-07` IF IT HAD BEEN WRITTEN WITHOUT READING IT.** `RI-07` walks the engine's transitive module graph and reports "a bare specifier that is neither" a Node builtin nor relative, so `import ... from '@anthropic-ai/sdk'` inside `packages/rules-engine/src` **already fails there**. Three things are outside it and they are what this gate is: **scope** (RI-07 starts at the engine's `index.ts` and says nothing about the payout, ledger or auth paths), **endpoints** (RI-07 reads specifiers; a model reached by URL is a string literal in a file that imports nothing unusual), and **the list** (ADR-044 requires the banned identifiers in one declared place, which is what a reader adding an SDK looks for). `merit/engine-purity` is not it either: one file at a time, early return on relative specifiers, attached to one glob.

  - **THE SCOPE CASE'S SEEDED PACKAGE IS DELIBERATELY CLEAN, AND THAT IS THE ASSERTION.** `packages/payout` arrives importing no model SDK, so assertion 1 has nothing to say about it and would report **nothing**. The finding is the scope gap itself: an unscoped money path is a hole whether or not anybody has walked through it yet. A seed that also imported an SDK would have fired assertion 1 and looked like it had tested assertion 2.

  - **ADDING ANY GATE MOVES A GENERATED SPAN IN TWO FILES OUTSIDE THIS SESSION'S FENCE, AND ALL THREE CONCURRENT GATE SESSIONS WILL COLLIDE ON IT.** `gate_count` is a `gen:` span in [INDEX](../INDEX.md), [STATE](../STATE.md), [STRATEGY](../testing/STRATEGY.md) and [session 38's log](2026-08-16-session-38.md), and `CI-06g` goes red until it is regenerated. The remedy is the one the gate itself prints, `node scripts/corpus/gates.mjs generate`, and **all eight changes are the single character `18` -> `19`** and nothing else, verified by diffing. Sessions 68 and 69 produce byte-identical changes in the same eight places. **Whoever merges second and third should re-run `generate` rather than resolve the conflict by hand.**

  - **THE GATE STATES WHAT IT CANNOT DO IN ITS OWN `covers`, BECAUSE THE ROW TWO ABOVE IT DOES.** A host built at runtime from concatenation or an env var is invisible to a static scan; so is a model call a dependency makes inside its own package, because `node_modules` is never walked; and **discovery is BY NAME**, so `apps/worker` runs the nightly batch today and is not found by assertion 2. `CI-06q` and `CI-06r` set that precedent explicitly: a gate implying coverage it does not have is worse than its absence.

- **Files touched:** [`scripts/corpus/gates.mjs`](../../scripts/corpus/gates.mjs), [`scripts/corpus/falsify.mjs`](../../scripts/corpus/falsify.mjs), [STRATEGY](../testing/STRATEGY.md), [STATE](../STATE.md), [sessions/README](README.md), this file, plus the `gate_count` span in [INDEX](../INDEX.md) and [session 38's log](2026-08-16-session-38.md), which are the fence exception recorded above.
