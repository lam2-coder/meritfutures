### 6. Landmines

1. **A NEEDLE MEASUREMENT CANNOT PRICE A REGISTRATION.** It reports what a needle reaches, and a claim phrased in a verb nobody wrote down is invisible to it. [ADR-384](../decisions/ADR-384.md) did everything right and its conclusion was still incomplete for this reason. **The argument does not stop applying now**: a third site in a third verb would be as invisible today as the second was yesterday.
2. **A TEST FIXTURE CAN CONTAIN THE DEFECT THE SUITE IS BLIND TO.** [ADR-384](../decisions/ADR-384.md)'s own case had written the second site's exact sentence into a seeded tree and gone green over it. **When a fixture is copied from a real site, it inherits whatever that site is doing wrong.**
3. **A MECHANISM NAMED IN PROSE IS NOT A MECHANISM WITH THE RIGHT SCOPE.** Three false absolutes each name a real, green control whose glob or file list is narrower than the sentence. [`eslint.config.js:42`](../../eslint.config.js) ignoring `packages/db/**` is the sharpest case: the rule cited as making a claim *mechanical rather than a convention* is switched off in the package the claim is about.
4. **`git ls-tree` PLUS `git show` MEASURES ANOTHER COMMIT WITHOUT CHECKING IT OUT.** That is how this row validated its regex against the previous row's tree with the working tree untouched, and it is cheaper and safer than a worktree for a read-only sweep.
5. **THE `apps/worker` SITES NEEDED NO EDIT.** A claim entry quotes an existing line, so a registration is a diff in `packages/tooling` alone. **Registering is not repairing**, and the fence question that stopped three prior rows was about the wrong file.
