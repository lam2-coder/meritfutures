### Landmines

1. **A `ledger_transactions` row with no entries commits clean.** The zero-sum trigger is `AFTER INSERT ON ledger_entries` and fires zero times when there are none. `posting()` refuses the shape and the database does not, and the round trip left one such row standing so the count could be reported.
2. **`ledger_halts` is honoured by exactly one code path and by nothing else.** Round trip case 8: the same posting with the path bypassed commits with the halt live.
3. **`assertBalanced` is unreachable through `entriesOf` by construction.** A guard with nothing to find looks exactly like a guard finding nothing wrong. The approval clause's first command is the one that catches a fold that stopped emitting entries, because it fails on the claim rather than on the guard.
4. **`pnpm-lock.yaml` is a shared file and the plan says a library slice collides with nothing.** Session 217's `packages/psp` is a new package too. The conflict is resolved by re-running `pnpm install --lockfile-only` on the merge result, never by hand-editing.
5. **`scripts/` is OUTSIDE the root `format` script's glob**, which covers `*.{js,mjs,ts,json}` at the root and `{apps,packages}/**`. Running Prettier over [`gates.mjs`](../../scripts/corpus/gates.mjs) by hand reformatted **156 lines** of a file whose one-line change is the whole reason for touching it, and `format:check` says nothing in either direction. Caught, reverted from the index, the one-word correction re-applied.
6. **A renumber after a merge cannot be a blanket substitution.** The tree now holds session 214's `ADR-103` citations and this session's `ADR-104` ones in three of the same files, and `sed -i s/ADR-103/ADR-104/` over [`scoped-db.test.ts`](../../packages/db/test/scoped-db.test.ts) would have renumbered fourteen of session 214's citations inside its own work.
7. **`LEDGER-C1` forbids chained transfers.** `A -> B` plus `B -> C` in one posting is refused, and three test fixtures in this session were written that way before the refusal caught them. Real postings are star-shaped and this is the refusal working.
