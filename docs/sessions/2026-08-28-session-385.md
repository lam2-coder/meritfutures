### 3. Which one yields, and the arithmetic that decides it

**The shape yields**, on the principle that **a shape may not promise a value a ruling forbids producing**. Rule A protects the operator from a number that means nothing and its protection is unconditional; rule B protects the client from a missing field and its protection is conditional on the field carrying a true value.

The deciding fact is that rule B can be satisfied today only by a non-control. Three exhaustive classes, against `FM-M6-07` at [M06:282](../plans/M06-admin-ops-console.md):

| Class | Verdict |
|---|---|
| zeros, the only object inventing nothing | **not a control, both halves, no data needed.** `mu_0 = 0` and `k = 0` give `S_t = max(0, S_(t-1) + x_t)` with `x_t >= 0`, so the statistic is non-decreasing and unbounded and alarms forever from the first passing account; a literal `0` with any `h > 0` alarms never, and `alarm: false` is an affirmative all-clear from a chart that never looked |
| an invented `mu_0` and `sigma` | **not a control.** The sign of `E[x_t] - mu_0 - k` decides the whole chart, and `FM-M6-07`'s control column names an invented pair *"not a constant someone picked"*. **And `threshold` is undetermined even given a perfect calibration**: [M06:97](../plans/M06-admin-ops-console.md) and [GLOSSARY:260](../GLOSSARY.md) state the alarm point as a RANGE, *"4 to 5 sigma"* |
| a calibrated pair | **not available.** Wave 4 |

**The elimination is total, and that is what separates `B3` from `B2`.** [ADR-201](../decisions/ADR-201.md) eliminated two of three readings and one survived, so a definition closed the gap. Here every available class is eliminated and the survivor is unavailable, so only a shape closes it.
