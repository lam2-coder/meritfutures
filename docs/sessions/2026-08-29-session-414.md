### 2. What was ruled

**Three patterns and one exception**, derived spelling by spelling in
[ADR-224](../decisions/ADR-224.md) section 2 rather than copied from a
template. The two facts that force the shape: a pattern with no slash matches
by BASENAME at any depth, and `.env` does not match `.env.local`.

**The exception set has exactly one member.** `.env.example` is committable and
`.env.sample` and `.env.template` are not, on the argument that each further
spelling is another name under which a real value gets committed and waved
through.

**`.envrc` is outside the rule and is asserted so**, which is the difference
between a decision and an oversight in a file made of one-line entries.

### 3. Why the check runs a command

**A grep for `.env` in `.gitignore` asserts that a line exists, which is not
the claim.** Two seeded cases settle it and both are in the suite: a
subdirectory `.gitignore` that re-includes the path with the root entry present
word for word, and a `*` catch-all that makes every subject ignored for a
reason that is not this rule and would read green after the `.env` lines were
deleted.

**Leg 2 exists because an ignore rule reaches no tracked file.** A `.env`
committed before the rule landed is in every clone and in the history, and leg
1 goes on truthfully reporting that the rule holds.

### 9. Next / blockers / landmines

**Next.** The founder's read on [ADR-224](../decisions/ADR-224.md), which ships
`proposed` and **UNSIGNED**. Three questions are put: the size of the exception
set, what `RI-21` does NOT claim, and whether direnv is likely.

**Blockers.** None. The branch is mergeable and the check is green.

**Landmines.**

- **`RI-21`'s population is fourteen typed strings**, which is the shape `RI-05`
  refuses when it is a COPY of something. It is not a copy of anything today and
  the entry says so; **the day a manifest or a config enumerates environment
  files, this population must be read out of it** rather than left typed.
- **`cleanTree()` now spawns `git init`.** Any future case in that file that
  measures wall-clock, or that runs in an environment with no `git` on the
  `PATH`, inherits that dependency. It is roughly 7ms per call over 113 calls.
- **Adopting direnv turns `RI-21` red** on the first developer who writes a
  `.envrc`. That is the good direction for a check to break in and it is still
  a session's work at a moment nobody planned it.
- **`RI-21` proves the dotenv naming convention is ignored and nothing more.** A
  key pasted into a source file, a `config/secrets.env` or a hyphenated
  `.env-local` is outside it. The sentence it replaces over-claimed and that is
  what made it dangerous; **the replacement must not be read the same way.**
