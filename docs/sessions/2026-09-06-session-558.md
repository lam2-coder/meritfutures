### 4. Where this row found something ADR-357 did not

**`UNWIRED_WITHDRAWAL_BACKEND` holds `now: () => new Date()`**, a working clock, and it is the only unwired default in this deployable whose members do not all refuse. The four sibling defaults that carry a `now` all throw from it.

**The ruling is that the port still refuses**, measured at both doors: the creation door reads the clock and the next statement rejects because the idempotency store refuses, and the cancellation door reads it and `transact` refuses, both answering 503. **A timestamp computed and discarded is not a request served**, so the count does not move and the derived set equals the recorded one.

**It is reported because the derivation is what surfaced it**, and because a name was doing the classifying work in a table that ADR-357 had written specifically to stop names doing classifying work.
