### 1. The objective

Rule two findings the dispatcher made while integrating PR #745, stated in that pull request's body and deliberately in no row's voice. Finding 1: a factual error in live source at [`write-guard-set.mjs:191`](../../packages/tooling/checks/write-guard-set.mjs), where the tension is that [ADR-386](../decisions/ADR-386.md) repairs a live pointer but the same claim also sits in [ADR-462](../decisions/ADR-462.md), which nobody may edit. Finding 2: correcting a dead pointer in prose multiplies it, which argues against the price [ADR-461](../decisions/ADR-461.md) section 10 item 3 sets. **Derive all of it from `git show <ref>:<path>`; neither the dispatcher nor any sibling ADR is a primary source.**

### 2. Done

- **Derived finding 1 across three refs and one blob hash.** `9dd770a`, `447121c` (`ADR-459`'s own parent) and `bbb9e22d` are the **same blob**, `0806c240`, 503 lines with the literal at 270. `aa6d0d12` is 497 lines at 264. The move is [`6678885`](../../packages/tooling/checks/write-guard-set.mjs). **Both halves of the comment's claim are false and `ADR-459` was right at its own base.**
- **Found the third falsehood.** `:264` and `:278` were already false in [`fe20954`](../../packages/tooling/checks/write-guard-set.mjs), the commit that wrote them, which grew the file 497 lines to 838 in the same diff.
- **Ruled finding 1 for REPAIR** on [`ADR-386.md:169`](../decisions/ADR-386.md), and repaired the comment so that it **restates no line number**. Six lines for six; the file is 838 lines at base and head and `CONVENTION` stays at `:198`. Located in `git diff -U6`, not by grep.
- **Re-derived the sites.** Not seven: **23 at base, 21 after the repair**, one live-source site left. The mechanical citation set for the file went **from zero (when `ADR-461` ran it) to three**, six of whose eight pairs are the dead `270`.
- **Implemented and measured the priced widening**: **54 pairs against 7**, adjudicated 11 USE / 28 MENTION / 13 CROSS-ATTRIBUTION / 2 NOT-A-POINTER, **1 of 54 correct**, and it **cannot see its own motivating case** at `:193`.
- **Ruled the price WITHDRAWN**, proposed no replacement, and **ruled that no mechanical use-versus-mention test exists**, naming the ref-qualified use as the class that defeats one and adjacency as the axis that is actually decidable.
- **Wrote [ADR-467](../decisions/ADR-467.md)**, `proposed`, approval line UNSIGNED, `E2 READ OWED`, and this log. Regenerated the registries.

### 5. Landmines

- **A correction to a stale pointer is itself a pointer, and this file grew 341 lines in one commit.** Any future entry tempted to write the current position of that literal should write `CONVENTION` instead. The name is the repair; the number never was.
- **The mechanical citation set for a file can be created out of nothing by writing about it.** `write-guard-set.mjs` had **zero** enumerable cited numbers and now has three, all of them minted by prose reporting that a pointer was wrong. **A row that "fixes" a dead pointer in prose adds a dead pointer.**
- **A sentence in this corpus names several files.** Any derivation that drops the filename-adjacency requirement will harvest numbers belonging to whichever other file the sentence cites. Thirteen of 54 in the one measured file.
- **The dispatch's own list of seven sites contained a stale pointer.** `ADR-461:152` does not carry `:270`. Re-derive a handed list even when the hand-off exists to warn you about stale lists.
