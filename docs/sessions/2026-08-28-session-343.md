**Landmines:**

1. **`probe_ledger_constraints.sql`'s `K1c` fixture is `withdrawals_payable`, one underscore away from the code that now exists.** It is deliberately left undeclared and untouched, and `NEGATIVE_FIXTURES` in [`in-flight-obligation.test.ts`](../../packages/ledger/test/in-flight-obligation.test.ts) now goes red the day anybody mints it. Every guard on the vocabulary is a test or a database constraint, and a session that measures the price of a ninth code with `typecheck` alone will conclude, wrongly, that nothing has to move.
4. **`0056` is the first migration to move three guards in one transaction**, and the `E2` read's subject is that its three statements agree rather than that any one of them is right.
