### 5. Two defects found by RUNNING it, and neither was visible to any gate

**1. A TypeScript parameter property does not load.** The first draft wrote the two error
classes with `constructor(readonly column: ..., readonly path: ...)`. `ADR-083` rules that
every deployable runs under `node --experimental-strip-types`, which erases types and
rewrites nothing, so the module is `ERR_UNSUPPORTED_TYPESCRIPT_SYNTAX` **at load time**.
Section 6 finding 2 is what that costs.

**2. The `23505` guard did not fire.** `isUniqueViolation` read the top-level `code`. Live,
a second insert for one account-day arrives as a `DrizzleQueryError` whose own `code` is
`undefined` and whose `cause` carries `23505`, so the caller got a 700-character `Failed
query:` dump with neither the account nor the day in it. The walk is now bounded over the
cause chain, case 5.1 is the seed that found it, and seed S3 restores the defect and is
**RED** on that case.
